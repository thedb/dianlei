## 1. 参考画面

Yoan 给的是合金弹头 3 的 **SOLDIER SELECT**（横屏，四栏）。对着那一帧，用电雷的竖屏改，不靠印象重画。

那一帧里和选机有关的部分：

- 顶上是一块铆钉金属铭牌，字是立体的 **SOLDIER SELECT**。
- 铭牌下面有一排小槽。最左是红字 P1，其余是空的暗槽。这是多人位，电雷不搬。
- 主体是四个一样高的竖栏并排。
- **选中的栏**（最左，Marco）：栏内是全彩的局内全身小人，站在一块小屏幕里；栏底有黄黑斜警示条；背后有淡的编号字。
- **没选中的三栏**：每一栏是一张灰色的大头特写，占满栏宽，没有警示条，没有全彩。
- 每栏底下另有一块金属名字牌：MARCO、ERI、TARMA、FIO。没选中的名字也看得清。
- 截图底下的 PLEASE WAIT、CREDITS、播放器按钮是录像界面，不是游戏画面。

电雷要留下的：金属标题牌、选中为全彩可动的机体、未选中为灰色特写、名字在金属牌上、特点写在旁边。

电雷要改掉的：四栏横排改成 **三行竖排，一行一架**。不画 P1 空槽。不画四个人的头像，灰色特写改成该机自己的机头。

## 2. 布局

飞机按真实像素的同一倍数放大，不拉成一样大。Mandy 的 32×36 会比 Jason 的 22×26 占更多空位，这就是体积差。

### 2.1 选中行

- 画该机平飞到侧倾的 **局内 11 帧**，最近邻 **3 倍**。Eagle 84×96，Mandy 96×108，Jason 66×78。都进得了 132 的井。Mandy 最高，上下余量最小，这是故意的。

- 井的底边 8 像素是黄黑斜条，只用 `EXPLOSION_YELLOW` 和 `BLACK`，静止，不滚动。只有选中行有。
- 名字牌亮边用 `WHITE`，字是白色的 Eagle / Mandy / Jason。
- 身份用玩家青，特性用白色。

### 2.2 未选中行

- 取该机平飞帧的 **上半截**（机头、座舱、翼根）：高度为精灵高的 55%，四舍五入。Eagle 28×18，Mandy 32×20，Jason 22×14。

## 4. 演出节奏

选中机开场在平飞帧，然后慢侧倾，让人看见 11 帧，而不是在井里满舵甩。

| 时间 | 侧倾 |
|---|---|
| 0–0.40 秒 | 平飞 |
| 0.40–1.00 秒 | 缓到右侧约 0.45（不到满舵） |
| 1.00–1.40 秒 | 停住 |
| 1.40–2.00 秒 | 回到平飞 |
| 2.00–2.60 秒 | 缓到左侧约 0.45 |
| 2.60–3.00 秒 | 回到平飞，循环 |

帧号用现有的 `getBankFrameIndex`。尾焰每帧跟该帧喷口，长度按该机的焰参数抖动。

换行是硬切，对齐参考图里全彩小人和灰色头像的切换，不做交叉淡化：

- 离开的那一行立刻换成灰色机头，尾焰和黄黑条消失。
- 进入的那一行立刻换成 3 倍全彩，侧倾循环从平飞重算。
- 行的位置和高度不变。

点某一行：先变成选中。点已经选中的行，或点「确认」，或按确认键：带着这架离开。上下键在三行里循环。返回键和「返回」按钮回到打开选机的那一层。

选机打开时，标题后面的 attract 暂停。关掉以后，若还停在标题，attract 继续，并且仍是 Eagle。

## 5. 入口

选机是所有进战路径的 **第一步**。attract 和标题演示不进这个画面，固定 Eagle。

```
标题
 ├─ 开始游戏 → 选机 → 难度 → 战斗
 ├─ Boss连战 → 选机 → 难度 → 从 Boss 1 开战
 └─ 设置（不选机）

调试面板
 ├─ 关卡选择 → 选机 → 关卡列表 → 难度 → 战斗
 ├─ 挑战 Boss → 选机 → Boss 列表 → 普通/困难 → 战斗
 ├─ 武器测试 → 选机 → 武器测试
 ├─ 地图预览 → 选机 → 地图列表 → 预览里画选中的那架
 └─ 调试开关（不进战斗）

attract、标题演示：不选机，固定 Eagle
```

返回：

| 从 | 回到 |
|---|---|
| 选机 | 标题菜单，或调试面板 |
| 难度 | 选机。难度是选机之后的一步 |
| 关卡列表、Boss 列表、地图列表 | 选机 |
| 挑战 Boss 的普通/困难 | 仍回 Boss 列表（这一步的返回维持现状） |

关卡交接黑卡和结算 Retry 不重新打开选机，沿用 `shipId`。回标题时清掉。地图预览用刚选的机体画精灵，不生成敌人。最高分仍是全局一张榜。
