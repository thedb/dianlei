### 1.1 Mandy 主炮为什么是这组数

Yoan 的弹道是：

- 一开始 2 发向前。
- P 升 1 级：3 发向前。
- P 再升 1 级：同样 3 发，弹体加粗。

原先「射速 4、单发 2.5、DPS 与 Eagle 持平」是按 1 / 2 / 3 发算的（4×1×2.5=10，4×2×2.5=20，4×3×2.5=30）。套到「一开始就是 2 发」上，Lv1 会变成 20，等于 Eagle 的 Lv2。弹道描述优先，所以单发不再全程 2.5。

已确认的一版：

- 射速三档都是 4。比 Eagle 的 5 慢，保留轰炸机的顿挫。
- 薄弹伤害 1.5。Lv1、Lv2 用薄弹。
- 加粗弹伤害 2.5，只在 Lv3。命中宽从 4 加到 6，精灵从 4×12 换成 6×14。
- 全部 `vx = 0`，向前，不带 Eagle Lv3 的夹角。
- Lv1：`x = ±12`（间距 24，Eagle 双发间距是 10）。
- Lv2：在 ±12 中间加 `x = 0`。外弹位置不动。
- Lv3：位置仍是 −12 / 0 / +12，三发都换加粗弹。
- 弹速 720，与 Eagle 相同。
- 满伤 DPS：4×2×1.5 = **12**，4×3×1.5 = **18**，4×3×2.5 = **30**。

Lv1 比 Eagle 高两成，宽弹幕是轰炸机的第一眼。Lv2 略低于 Eagle 的 20，因为三发仍是薄弹。Lv3 用加粗打回 30，和 Eagle 满级持平，避免后期压过关卡。

### 1.2 Jason 弹速

射速 10、单发 1、弹形沿用 Eagle（1 发，Lv2 间距 10，Lv3 ±15°），所以满伤 DPS 仍是 10 / 20 / 30。差别在密度和飞行时间。

弹速已确认 **1.25 倍**，720 × 1.25 = **900**。竖穿 640 像素从约 0.89 秒变成约 0.71 秒。弹形不改，仍是 Eagle 的 1 发、Lv2 间距 10、Lv3 ±15°。

## 3. Mandy

轰炸机。同一套滚转规则，轮廓换成更宽、更钝、翼更厚。画布 32×36，中线第 16 列。不画红脊。

### 3.1 平飞轮廓

行号从机头往下数。半宽是中线向一侧的像素。

| 部位 | 做法 |
|---|---|
| 机头 | 行 2 才开始有像素，半宽 1.6。到行 8 收到约 4.9。比 Eagle 短、钝，第一眼不是针 |
| 机身 | 行 8–28 半宽 5.2（Eagle 是 3.5）。腹部更肥 |
| 机尾 | 行 28–31.5 收到喷口 |
| 机翼 | 根在 x=4.5。前缘 (4.5, 14) → 翼尖 (14.6, 22)，后缘回到 (4.5, 29)。弦更厚，翼尖仍留在画布内。位置比 Eagle 更低 |
| 弹舱 | 行 22–28、`|x| < 3.2` 盖一层 `DARK_GRAY`，中线 1 像素 `PALE_GRAY` 当分缝。只是机身上的舱门，没有单独零件 |
| 座舱 | 中心 (0, 11)，半径约 1.6×3.2。比 Eagle 小，更靠后，像缩在装甲里 |
| 进气 | 只留一截，行 16–18，`PLAYER_MED_CYAN`。不要 Eagle 那种两截亮青 |
| 发动机 | 双发，间距 ±4.0，半宽 2.0。从行 24 到喷口行 33。喷口比 Eagle 宽 |
| 中线 | 不用红。行 18 和行 26 各一条 `LIGHT_GRAY` 分段线 |
| 描边 | 同样 1 像素 `PLAYER_DARK_CYAN` |
| 静态炮口点 | 翼根附近 (±12, 行 12) 各 1×2 像素 `PLAYER_CYAN`。一直亮着，不是射击动画。用来在不动的时候看出双炮 |

侧倾参数和 Eagle 用同一组公式（机身变窄、远翼缩短、近翼下掠、顶部细节往低翼滑）。只换上面的几何。左 5 帧镜像右 5 帧。

平飞时从左到右大概是：厚翼几乎贴边，机身约占 10 像素宽，中间一条灰舱缝，座舱小而暗。和 Eagle 并排时，Mandy 更宽、更长、翼更靠后。

### 3.2 射击和弹形

没有射击帧。薄弹继续用现有的 4×12 青白激光。加粗弹是新的一格，仍只用玩家青和白：

- 6 列 × 14 行。
- 左右各 1 列 `PLAYER_DARK_CYAN`，往里 1 列 `PLAYER_MED_CYAN`，中间两列 `WHITE`。
- 头尾各收成透明，避免切成方块。
- 命中宽 6、高 14。只给 Mandy 的 Lv3。Eagle、Jason、Mandy 的前两档仍是宽 4、高 12。

发射点相对机心：

| 档 | 发数 | x | 伤害 | 精灵 |
|---|---|---|---|---|
| Lv1 | 2 | −12，+12 | 1.5 | 4×12 |
| Lv2 | 3 | −12，0，+12 | 1.5 | 4×12 |
| Lv3 | 3 | −12，0，+12 | 2.5 | 6×14 |

`y` 用炮口距机心 18（36 像素高的机头附近）。速度 720，方向正上。这组数已确认。

### 3.3 尾焰、死亡、僚机、飞离

| 环节 | 方案 |
|---|---|
| 尾焰 | 双喷口跟侧倾帧。长 10、宽 5，闪烁量 2。颜色仍是白芯、青边，和 Eagle 同一套色，只是更粗。胜利和弹射乘共用加力 |
| 受击 | 不新做 |
| 死亡 | 仍是 4 帧小爆炸。5 段偏移略拉开：`(0,0)`、`(-8,-6)`、`(7,5)`、`(-5,8)`、`(6,-9)`，延迟与 Eagle 相同 |

## 4. Jason

高速战斗机。更短、更窄、机头更尖、翼更短。画布 22×26，中线第 11 列。不画红脊。

### 4.1 平飞轮廓

| 部位 | 做法 |
|---|---|
| 机头 | 行 1 就有像素，半宽 0.4。到行 12 才约 2.9。前半段是针，不是 Eagle 那种很快变宽的鼻 |
| 机身 | 行 12–20 半宽 2.6（Eagle 3.5）。整机更瘦 |
| 机尾 | 行 20–22.5 收到喷口 |
| 机翼 | 根在 x=2.2。前缘 (2.2, 10) → 翼尖 (8.4, 16)，后缘 (8.4, 18) → (2.2, 18.5)。翼展停在机身外侧约 8 像素，画布左右各留空。弦短，位置靠前 |
| 座舱 | 又长又窄，中心 (0, 8)，半径约 1.2×3.6。亮部多用 `PLAYER_PALE_CYAN` |
| 中线 | 行 10–18 用 `WHITE` / `PLAYER_WHITE`，不用红 |
| 进气 | 行 13–14.5 各一小块 `PLAYER_CYAN` |
| 发动机 | 双发收紧到 ±1.5，半宽 1.0。行 18 到喷口行 24。不要画成两团大发动机 |
| 翼前缘 | `PLAYER_PALE_CYAN`，让短翼在缩小后还能看见 |
| 描边 | 1 像素 `PLAYER_DARK_CYAN` |
| 炮口 | 不另加点。针尖本身就是炮口 |

侧倾公式与 Eagle 相同。翼本来就短，深倾时远翼会收成几乎看不见的一条，这是要的。

平飞并排时：Jason 最短、最窄，翼尖离画布边还有空，机头占掉前半张画布。

### 4.2 射击和弹形

没有射击帧。弹形与 Eagle 相同：4×12，Lv1 一发，Lv2 间距 10，Lv3 中间一发加 ±15°。伤害 1，射速 10。弹速已确认 900。炮口距机心 13。

不把 Mandy 的平行宽弹套到 Jason 上。Jason 的「更快」只在射速和弹速。

### 4.3 尾焰、死亡、僚机、飞离

| 环节 | 方案 |
|---|---|
| 尾焰 | 双喷口。长 6、宽 3，闪烁量 1.5。颜色仍是白芯、青边。短焰，避免拖成轰炸机 |
| 受击 | 不新做 |
| 死亡 | 4 帧小爆炸。偏移收紧：`(0,0)`、`(-5,-4)`、`(4,3)`、`(-3,5)`、`(4,-6)`，延迟与 Eagle 相同 |
| 僚机 | Jason 的 11 帧缩到约 7×9。间距 20。尾焰用短焰按缩放去贴。弹仍是伤害 2、每秒 5 发、弹速 720 的直射。不跟主机的 10 发/秒，也不用 900 的弹速 |
| 胜利飞离 | 共用演出，平飞中间帧，短焰乘共用加力 |

1. 并排看轮廓。Mandy 最宽最长，Jason 最短最窄，Eagle 在中间。只看外轮廓也能分开。
