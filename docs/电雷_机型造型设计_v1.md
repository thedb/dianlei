### 1.1 Mandy 主炮为什么是这组数

Yoan 的弹道是：

- 一开始 2 发向前。
- P 升 1 级：3 发向前。
- P 再升 1 级：同样 3 发，弹体加粗。

原先「射速 4、单发 2.5、DPS 与 Eagle 持平」是按 1 / 2 / 3 发算的（4×1×2.5=10，4×2×2.5=20，4×3×2.5=30）。套到「一开始就是 2 发」上，Lv1 会变成 20，等于 Eagle 的 Lv2。弹道描述优先，所以单发不再全程 2.5。

已确认的一版：

- 射速三档都是 4。比 Eagle 的 5 慢，保留轰炸机的顿挫。
- 薄弹伤害 1.5。Lv1、Lv2 用薄弹。
- 加粗弹伤害 2.5，只在 Lv3。命中宽从 4 加到 6，精灵从 4×12 换成 6×14。
- 全部 `vx = 0`，向前，不带 Eagle Lv3 的夹角。
- Lv1：`x = ±12`（间距 24，Eagle 双发间距是 10）。
- Lv2：在 ±12 中间加 `x = 0`。外弹位置不动。
- Lv3：位置仍是 −12 / 0 / +12，三发都换加粗弹。
- 弹速 720，与 Eagle 相同。
- 满伤 DPS：4×2×1.5 = **12**，4×3×1.5 = **18**，4×3×2.5 = **30**。

Lv1 比 Eagle 高两成，宽弹幕是轰炸机的第一眼。Lv2 略低于 Eagle 的 20，因为三发仍是薄弹。Lv3 用加粗打回 30，和 Eagle 满级持平，避免后期压过关卡。

### 1.2 Jason 弹速

射速 10、单发 1、弹形沿用 Eagle（1 发，Lv2 间距 10，Lv3 ±15°），所以满伤 DPS 仍是 10 / 20 / 30。差别在密度和飞行时间。

弹速已确认 **1.25 倍**，720 × 1.25 = **900**。竖穿 640 像素从约 0.89 秒变成约 0.71 秒。弹形不改，仍是 Eagle 的 1 发、Lv2 间距 10、Lv3 ±15°。

## 3. Mandy

黑色飞翼轰炸机。轮廓必须和 Eagle 明显不同，禁止把 Eagle 的白青机身拉宽。画布仍是 32×36，中线第 16 列。无红脊。移速 240、判定 3.0、主炮弹道不因改色改数。

主色是近黑和炭黑：大面用 `BLACK`，暗部用 `SHADOW`，分缝和舱门边用 `DARK_GRAY` / `MEDIUM_GRAY`。座舱可以留一小块现有玩家青，作为黑机上唯一的亮点，对应气氛稿里的青色座舱。机身不再使用 `PLAYER_WHITE` 当主色。

### 3.1 平飞轮廓

行号从机头往下数。半宽是中线向一侧的像素。外轮廓是一块飞翼，翼和机身连成一片，不是细机身加两片后掠翼。

| 部位 | 做法 |
|---|---|
| 机头 | 钝。行 2 起笔，半宽很快到 3 以上。不要 Eagle 那种针尖 |
| 飞翼 | 前缘从钝鼻向两侧张开，大约在行 16–20 贴到画布左右边（半宽约 15）。后缘收到尾部两台发动机外侧。翼厚，翼尖不单独翘成战斗机小翼 |
| 机背 | 中脊是炭黑上的暗灰分缝，不用红，也不用一条白脊 |
| 弹舱 | 腹部中线可见两扇舱门。门比机身亮一档（`DARK_GRAY` 门、`MEDIUM_GRAY` 缝），从座舱后一直铺到发动机前。这是 Mandy 的独有标记 |
| 座舱 | 小，嵌在钝鼻后。填 `PLAYER_MED_CYAN` / `PLAYER_DARK_CYAN`，不要做成 Eagle 的大椭圆座舱 |
| 发动机 | 仍是双发。间距约 ±5，半宽约 2.2，比 Eagle 的 ±2.4 / 1.4 更宽。喷口在第 33 行附近，口沿 `MEDIUM_GRAY` |
| 描边 | 1 像素 `SHADOW` 或 `DARK_GRAY`。不用 Eagle 的青描边包一整圈 |

侧倾仍用 Eagle 那组公式（机身变窄、远翼缩短、近翼下掠）。几何换成飞翼之后，深倾时看到的是整块翼面变窄，不是细机身加一片大翼。左 5 帧镜像右 5 帧。

平飞第一眼：一块黑三角，尾下两只粗喷口，腹中一条舱门。和 Eagle 并排时，宽、长、黑，翼和身子分不开。

### 3.2 射击和弹形

没有射击帧。薄弹继续用现有的 4×12 青白激光。加粗弹是新的一格，仍只用玩家青和白：

- 6 列 × 14 行。
- 左右各 1 列 `PLAYER_DARK_CYAN`，往里 1 列 `PLAYER_MED_CYAN`，中间两列 `WHITE`。
- 头尾各收成透明，避免切成方块。
- 命中宽 6、高 14。只给 Mandy 的 Lv3。Eagle、Jason、Mandy 的前两档仍是宽 4、高 12。

发射点相对机心：

| 档 | 发数 | x | 伤害 | 精灵 |
|---|---|---|---|---|
| Lv1 | 2 | −12，+12 | 1.5 | 4×12 |
| Lv2 | 3 | −12，0，+12 | 1.5 | 4×12 |
| Lv3 | 3 | −12，0，+12 | 2.5 | 6×14 |

`y` 用炮口距机心 18（36 像素高的机头附近）。速度 720，方向正上。这组数已确认。

### 3.3 尾焰、死亡、僚机、飞离

| 环节 | 方案 |

## 4. Jason

紫金高速战斗机。画布仍是 22×26，中线第 11 列。无红脊。移速 420、判定 2.0、射速 10、弹速 900 不因改色改数。僚机弹道数值仍锁 Eagle。

主色是湖人紫金：深紫机身，金色前缘、描边和脊线高光。这四色加在原 48 色之后（索引 48–51），不挪动 0–47。不能用敌弹品红或爆炸黄代替。

尾焰是代码绘制，可以用半透明的紫金，跟机体走。焰芯允许紫金，不再用 Eagle 的白芯青边。

### 4.1 平飞轮廓

| 部位 | 做法 |
|---|---|
| 机头 | 尖，但比旧稿的针短一截。金色包边，深紫色填心 |
| 机身 | 半宽约 2.4–2.6。比 Eagle 瘦，仍要能放下一条金脊 |
| 脊线 | 中线用金 / 浅金，不用白，不用红 |
| 机翼 | 短后掠，翼尖留在画布内。翼面深紫，前缘和翼尖是金。左右留空，避免贴边 |
| 座舱 | 窄，深色底加一圈金 |
| 发动机 | **单发。** 只在中线一只喷口，大约半宽 1.6，行 18 到喷口行 24。禁止左右各一台 |
| 描边 | 1 像素金。不用青描边 |

侧倾公式与 Eagle 相同。单喷口留在中线，深倾时可以跟着机身底部略偏，但不能裂成两个口。左 5 帧镜像右 5 帧。

平飞第一眼：小、紫、金边、尾巴只有一根粗焰。和 Eagle 的白青双发、Mandy 的黑飞翼都拆得开。

### 4.2 射击和弹形

没有射击帧。弹形与 Eagle 相同：4×12，Lv1 一发，Lv2 间距 10，Lv3 中间一发加 ±15°。伤害 1，射速 10。弹速已确认 900。炮口距机心 13。

不把 Mandy 的平行宽弹套到 Jason 上。Jason 的「更快」只在射速和弹速。

## 6. 怎么确认

栅格已经进代码。用本文对三张平飞：

1. 并排看轮廓。Mandy 是黑飞翼，Jason 是小紫金战斗机，Eagle 是白青双发。只看外轮廓也能分开，Mandy 不能看成拉宽的 Eagle。
2. 红脊只在 Eagle 上。Mandy、Jason 没有红像素。
3. Mandy 腹部看得到弹舱门。颜色是近黑和炭黑，分缝是暗灰。
4. Jason 只有中线一个喷口。脊线和前缘是金，机身是深紫。尾焰比 Eagle 的单根更长更粗。
5. 侧倾抽第 0、5、10 帧。远翼变细、机头仍朝上。Mandy 的两个喷口还在左右发动机上，Jason 的喷口仍是一只。
6. 选机画面放大的是这些帧，不是气氛稿，也不是另一张立绘。

气氛稿只锁定风格。验收对着栅格出来的平飞像素，那一份字节就是确认稿。
