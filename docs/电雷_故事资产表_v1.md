## 0. 总设定

| 项 | 定稿 |
|---|---|
| 行动代号 | **电雷**（「雷电」谐音，非机体名） |
| 玩家身份 | 政府正规军飞行员 |
| 反派（前段） | 反叛军：表面上夺权，暗地打捞外星残骸炼黑科技 |
| 反派（后段） | 外星人「原主」：第 4 关末现身回收残骸，第 5 关正面对抗 |
| 调性 | 合金弹头式：前 3 关人打人（军武/赛博），第 4 关世界观转折，第 5 关外星夸张 |
| 第 5 关结局 | 前四关 Boss 残核合体为临时联合舰，与玩家齐射击溃旗舰——**纯演出**，不多操作阶段；可有短暂伤害加成窗口 |
| 地图资产 | 现有陆地 A/B、河流 A、宇宙 A 仍是 MVP 图。Boss 场地原则：跟**当前关主题**过渡 → 可循环场，**禁止**非宇宙关硬切宇宙。P17：第 1 关 Boss 用百战要塞（陆地接近带 + 循环庭院）。P24：第 2 关 Boss 场是铁堡厂轨（陆地B 接入厂房三轨循环，已做图）。宇宙 A 留给第 5 关 |

## 1. 五关大纲

### 第 1 关 · 边境突袭

| 项 | 内容 |
|---|---|
| 一句话 | 反叛军突袭边境机场，电雷紧急升空清场。 |
| Boss | **百战** — 叛军前线机动要塞/指挥机，炮塔+装甲，纯地球军武。 |

| 结束旁白 | 前线已肃清。叛军残部向工业带撤退。 |

| 项 | 内容 |

|---|---|
| 一句话 | 追入近地战场；敌转外星兵器。旗舰将溃时，前四关 Boss 残核被紧急协议拉起拼合，与玩家齐射洞穿旗舰。 |

## 3. 敌机资产规划（复用 / 新增）

原则：每关新种类 ≤2；前 3 关偏地球军武，第 4 后半点缀异常，第 5 才换外星造型。

| 关 | 复用现有 | 建议新增 | 调性备注 |
|---|---|---|---|
| 1 | 小/中战斗机、地面建筑、炮台 | 可选：侦察无人机 ×1 | 正常军武；定调「人打人」 |
| 2 | 同上 + 渠面低飞、双联高射（旧模型的打法变体） | 本关波次表定为 **0 新模型**。武装快艇、工厂防空炮推迟到第 3 关以后 | 工业走廊。水面是陆地B 排水渠，不是河流A |
| 3 | 强化小中型 + 建筑 | **机场停机可击**（静态）；**重装对地机** | 基地总攻 |
| 4 前半 | 舰载小中型 | **舰载轰炸机**；**巡洋舰副炮**（建筑位） | 海战 |
| 4 后半 | 密度可略降 | **残骸漂浮物**（装饰/低血）；可选「异色叛军机」 | 世界观转折 |
| 5 | 尽量少复用地球机 | **碟形侦察**；**棱晶战斗机**；**能量炮台**；旗舰召唤物 | 外星 |

掉落源（玩法，故事可挂皮）：精英标记敌、编队清空奖励、运输机/补给箱；第 4 后半运输机可叙事为「打捞残骸的叛军货机」。细则另表，不在本文件锁数值。

## 4. Boss 与关键演出资产

### 4.1 百战（第 1 关）

| 项 | 说明 |
|---|---|
| 行为 | ≈ 现第一关 Boss 骨架：炮塔阶段 → 核心阶段；机炮/导弹/螺旋·瞄准 |
| 素材 | 优先换皮（命名/涂装「百战」），少改行为 |
| 击败 | 常规爆炸 → 过关 |

### 4.2 铁堡（第 2 关）

铁堡细节见 `docs/电雷_第二关_铁堡Boss设计_v1.md`。P24 已实现主战、厂轨和 `s2_open` / `s2_end`。第 2 关道中波次仍未做。下表只留故事侧摘要。

| 项 | 说明 |
|---|---|
| 行为 | 弹药转运装甲列车。厂内三轨换轨，武器按固定顺序循环。困难才有过载段。没有激光 |
| 场地 | 道中收束在陆地B。Boss 场为 `factoryBoss` / 铁堡厂轨：主题接近后循环三轨，不切宇宙。道中波次、掉落和侧后斜入见 `docs/电雷_第二关波次表_v1.md`（v1 已拍板；代码仍空） |
| 素材 | 车头 + 弹药车厢，黄黑警示条，车顶高射炮。代码像素；参考图只定气氛 |
| 击败 | 多段弹药爆炸，铁轨崩裂，然后过关。旁白 `s2_end` 仍用 §2 文案 |

### 4.3 炉心（第 3 关）

| 项 | 说明 |
|---|---|
| 行为 | 新：浮空堡垒；外围炮塔 → 护盾核心（可复用困难三阶段架子） |
| 武器调性 | 仍偏导弹/火焰；激光留给第 5 关（或困难彩蛋） |
| 素材 | 赛博灯带/装甲块大轮廓 |

### 4.4 黑曜（第 4 关）— 转折钩子

| 项 | 说明 |
|---|---|
| 行为 | 舰载防空机，中上体型；正常阶段战至「血空」 |
| **禁止** | 血空后立刻播常规爆炸通关 |
| 演出序列 | ① 瘫痪冒烟 ② 巨碟入场 ③ 一发射线/能量柱摧毁黑曜 ④ 碟缓离 ⑤ 旁白 `s4_ufo` → 进入第 5 关流程 |
| 必做资产 | 巨碟剪影；击破光束；黑曜残骸帧；短黑场/字幕位；海面残骸装饰层（可循环，几块即可） |

### 4.5 回收者（第 5 关）

| 项 | 说明 |
|---|---|
| 行为 | 多部件巨型战舰（主炮、侧翼、核心）；阶段表可拉满；能量弹色与地球火黄区分 |
| 结局演出（纯演出） | ① 旗舰将溃 ② 百战/铁堡/炉心/黑曜残核剪影飞入拼合 ③ 临时联合舰齐射 + 一束集中激光 + 可选玩家伤害加成窗口 ④ 旗舰解体 ⑤ 旁白 `s5_end` / `s5_coda` |
| 必做资产 | 四 Boss 残核小图；联合舰拼合帧或简化骨骼；穿透激光；旗舰大爆炸帧 |
