## 3. 敌机资产规划（复用 / 新增）

原则：每关新种类 ≤2；前 3 关偏地球军武，第 4 后半点缀异常，第 5 才换外星造型。

| 关 | 复用现有 | 建议新增 | 调性备注 |
|---|---|---|---|
| 1 | 小/中战斗机、地面建筑、炮台 | 可选：侦察无人机 ×1 | 正常军武；定调「人打人」 |
| 2 | 同上 + 渠面低飞、阶梯侧移、一次性俯冲、侧后斜入 | **工厂防空炮** ×1。武装快艇仍推迟（陆地B 没有河，只有排水渠） | 工业走廊。水面是陆地B 排水渠，不是河流A |
| 3 | 强化小中型 + 建筑 + 坦克 + 工厂防空炮 | **机场停机可击** `parked_fighter`（静态）；**重装对地机** `strike`。已按第 3 关波次表实现（2026-10-27） | 基地总攻。道中是河流A，末段岸上加焦土 |
| 4 前半 | 舰载小中型 | **舰载轰炸机** `carrier_bomber`；**巡洋舰副炮** `cruiser_gun`（建筑位）。规格在 `docs/电雷_第四关波次表_v2.md`，未实现 | 海战。新图 `seaB`，不复用河流A |
| 4 后半 | 密度可略降。异色涂装仍是 `small`，不单开型号 | **残骸漂浮物** `wreck_float`（装饰/低血，道具池，不算第三种新敌） | 世界观转折。旁白 `s4_wreck` |
| 5 | 尽量少复用地球机 | **碟形侦察**；**棱晶战斗机**；**能量炮台**；旗舰召唤物 | 外星 |

掉落源（玩法，故事可挂皮）：精英标记敌、编队清空奖励、运输机/补给箱；第 4 后半运输机可叙事为「打捞残骸的叛军货机」。细则另表，不在本文件锁数值。

## 4. Boss 与关键演出资产

### 4.1 百战（第 1 关）

| 项 | 说明 |
|---|---|
| 行为 | ≈ 现第一关 Boss 骨架：炮塔阶段 → 核心阶段；机炮/导弹/螺旋·瞄准 |
| 素材 | 优先换皮（命名/涂装「百战」），少改行为 |
| 击败 | 常规爆炸 → 过关 |

### 4.2 铁堡（第 2 关）

铁堡细节见 `docs/电雷_第二关_铁堡Boss设计_v1.md`。P24 已实现主战、厂轨和 `s2_open` / `s2_end`。道中波次见 `docs/电雷_第二关波次表_v2.md`。下表只留故事侧摘要。

| 项 | 说明 |
|---|---|
| 行为 | 弹药转运装甲列车。厂内三轨换轨，武器按固定顺序循环。困难才有过载段。没有激光 |
| 场地 | 道中收束在陆地B。Boss 场为 `factoryBoss` / 铁堡厂轨：主题接近后循环三轨，不切宇宙。道中波次、掉落和侧后斜入见 `docs/电雷_第二关波次表_v2.md`。道中新增 1 个模型（工厂防空炮），快艇仍不做 |
| 素材 | 车头 + 弹药车厢，黄黑警示条，车顶高射炮。代码像素；参考图只定气氛 |
| 击败 | 多段弹药爆炸，铁轨崩裂，然后过关。旁白 `s2_end` 仍用 §2 文案 |

### 4.3 炉心（第 3 关）

细节见 `docs/电雷_第三关_炉心Boss设计_v1.md`。道中见 `docs/电雷_第三关波次表_v1.md`。道中和炉心已于 2026-10-27 实现（P32 + P33）。下表只留故事侧摘要。

| 项 | 说明 |
|---|---|
| 行为 | 浮空堡垒。四座环绕炮舱可打，然后装甲瓣按节拍开合，合拢时核心不吃子弹。简单和中等主战归零即胜。困难另有过载。没有激光 |
| 场地 | 道中收束在河流A。末段岸上用已有焦土地块点缀，不重画整图。Boss 场为 `furnaceBoss` / 炉心浮台：焦土接近后循环底盘，不切宇宙 |
| 素材 | 赛博灯带、装甲瓣、环绕炮舱。代码像素；参考图只定气氛 |
| 击败 | 常规多段爆炸，然后过关。旁白 `s3_open` / `s3_end` 仍用 §2 文案 |

### 4.4 黑曜（第 4 关）— 转折钩子

时间轴、可控性和海图见 `docs/电雷_第四关_黑曜Boss设计_v1.md`。总表见 `docs/电雷_第四关完整思路表_v1.md`。道中设计表见 `docs/电雷_第四关波次表_v2.md`。仍未实现。下表只留故事侧摘要。§2 的三句旁白不改。

| 项 | 说明 |
|---|---|
| 行为 | 舰载防空机，中上体型；正常阶段战至「血空」。困难另有过载，过载打空才算血空。战斗不用激光 |
| **禁止** | 血空后立刻播常规爆炸通关 |
| 演出序列 | ① 瘫痪冒烟 ② 巨碟入场 ③ 一发射线/能量柱摧毁黑曜 ④ 碟缓离 ⑤ 旁白 `s4_ufo` → 再走通关离场，进入第 5 关流程 |
| 演出中的人 | 无敌，可以移动，不能射击、不能投弹。失败不重播这一段。血空前被击落仍是普通重生 |
| 必做资产 | 巨碟剪影；击破光束（演出，不是武器表里的激光）；黑曜残骸帧；字幕位用现有旁白条。全屏黑场不插进离场中间，第 5 关交接仍用现有 3 秒关卡字卡。海面残骸是 `seaB` 后两块加低血漂浮物 |
| 旁白 | `s4_open` 开场，`s4_wreck` 在残骸入画（规格时钟 96 秒），`s4_ufo` 在能量柱打散黑曜、碟开始离开时 |
