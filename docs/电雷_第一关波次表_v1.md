## 3. 移动与弹幕定义

### 3.1 移动方式

| 编号 | 说明 | 参数 |
|---|---|---|
| `straight` | 直线下冲 | `speed`（像素/秒），可选 `angle`（0 = 正下方） |
| `sine` | 下降，同时左右正弦摆动 | `vy`、`amp`（振幅）、`period`（周期） |
| `v_dive` | V 字编队下压到 `stopY`，然后两翼向外 45° 散开离场 | `speed`、`stopY` |
| `cross` | 从一侧上角斜穿到对侧下方 | `from`（左上/右上）、`speed` |
| `hover` | 以 120 像素/秒下降到 `stopY`，悬停 `hold` 秒（左右轻微漂移 ±12 像素），然后以 100 像素/秒向上撤离 | `stopY`、`hold` |
| `side_arc` | 从屏幕左边或右边 y = `y0` 处切入，沿半径 140 的弧线转向下方，然后以 `speed` 俯冲 | `side`、`y0`、`speed` |
| `orbit` | 飞到锚点，以半径 `r` 绕圈 `hold` 秒，然后以 90 像素/秒向下离场 | `anchor`、`r`、`period`、`hold` |
| `slow_push` | 以 30 像素/秒下降到 `stopY`，停留 `hold` 秒（左右漂移 ±20 像素），然后以 60 像素/秒向下离场 | `stopY`、`hold` |
| `ground` | 贴在地面上随背景向下卷动。`entry` 决定进场：`top`（默认，炮塔和导弹车）从屏幕上方跟着地块进来；`left` / `right` 从左右屏外横穿；`bottomLeft` / `bottomRight` 从底部角落斜着开上来。`vx` 可覆盖横向速度。坦克若下一步会开上河流或浅水（`water` / `waterB` / `shallow`）就停在岸边；已经在水里就朝最近的陆地开 | `vx`（可选）、`entry`（可选，默认 `top`） |

同一波里的多架敌人用 `interval`（出场间隔，秒）依次出场。

### 3.2 弹幕方式

速度是街机基准速度；代码里统一乘 0.8（`ENEMY_BULLET_SPEED_SCALE`）。

| 编号 | 说明 | 子弹 | 实际速度 |
|---|---|---|---|
| `none` | 不开火 | — | — |
| `aimed1` | 1 发瞄准玩家 | 小弹 | 120 |
| `aimed3burst` | 连续 3 发瞄准，间隔 0.12 秒 | 小弹 | 120 |
| `fan3` / `fan5` | 3 向或 5 向扇形，中心对准玩家，总张角 `spread` | 小弹 | 120 |
| `fan7wide` | 7 向宽扇形，朝正下方，张角 90° | 大光球 | 100 |
| `ring8` / `ring16` | 环形一圈，每次旋转 `rotStep` | 大光球 | 100 |
| `fixed2` | 双联平行 2 发（间距 10），沿炮管方向；炮管每秒最多转 60° 追玩家 | 小弹 | 120 |
| `missile` | 追踪导弹，追踪 1.2 秒后直飞 | 导弹 | 88 |
| `aimed_fast3` | 3 向快弹，张角 15° | 小弹 | 152 |
| `laser_sweep` | BOSS 专用横扫激光（见 §5） | 激光 | — |

通用规则：`interval` 是开火间隔，`firstDelay` 是进场后第一次开火的延迟，`maxShots` 是最多开火几次（不写就一直开火直到离场）。敌人只在 y ≥ 8 时开火；离玩家不到 48 像素时不发瞄准弹。

- 击毁后 30% 掉一个 B，不掉 P（`BUILDING_DROP_CHANCE`）。和携带机的必定掉落分开算

## 5. BOSS：轨道战舰

### 5.1 基本数据

| 部件 | 尺寸 | 判定 | 血量 | 分数 |
|---|---|---|---|---|
| 舰体 | 约 220×140 | 矩形，撞到就死。舰首上的子弹记入最近的存活弱点；弱点圆心以上的装甲不扣血 | — | — |
| 左炮塔 | 约 40×40 | 圆，半径 16；相对舰体中心偏移 (−78, +20) | 140 | 5000 |
| 右炮塔 | 约 40×40 | 圆，半径 16；偏移 (+78, +20) | 140 | 5000 |
| 核心 | — | 圆，半径 22；偏移 (0, +10)；只在阶段二打得动 | 560 | 30000 |
| **合计** | | | **840** | **40000** |

- 炸弹扣 BOSS 总血量的 8% = 67 点：阶段一由活着的炮塔平分（两座都在时每座 33–34 点），阶段二全部给核心；入场和阶段切换期间无敌，不扣血
- 玩家子弹打进舰首（存活弱点的圆心，一直到舰体下沿）就命中当前弱点：阶段一打最近的活炮塔，只剩一座时整面舰首都算它；阶段二整面舰首打核心。命中立刻扣血并闪白，不必先飞到圆心。从舰体外掠过的子弹不消失。弱点圆心以上的装甲挡住子弹但不扣血
- 测试版**没有超时**：BOSS 不会自己飞走

### 5.2 时间线（按 Lv3 打法估算）

| 时间（相对） | 绝对时间 | 内容 |
|---|---|---|
| +0.0–3.0 秒 | 2:35–2:38 | 入场：从 y = −70 降到 y = 110，无敌 |
| +3 秒起 | 2:38– | **阶段一**：舰体在 x = 180 ± 40 左右来回（周期 6 秒） |
| 约 +19 秒 | 约 2:54 | 两座炮塔都被打掉 → 1.5 秒切换（无敌；屏幕上的敌弹全部变成每颗 10 分） |
| 约 +20.5 秒 | 约 2:55 | **阶段二**：核心打开发光 |
| 约 +45 秒 | 约 3:20 | 核心被打掉 → 2.5 秒多段大爆炸（6 次大爆炸 + 大屏震），清掉所有敌弹（不加分），+30000 |
| 约 +47.5 秒 | 约 3:23 | STAGE CLEAR，2 秒后进入结算页 |

估算依据：Lv3 打单个目标时，实际命中约每秒 18–22 点。阶段一 280 血约 15–16 秒，阶段二 560 血约 25 秒，加上入场 3 秒和切换 1.5 秒，合计约 45 秒。

### 5.3 阶段一攻击
- 左炮塔：`fan5` 张角 60°，瞄准玩家，间隔 1.6 秒
- 右炮塔：`aimed3burst`，间隔 1.6 秒，比左炮塔晚 0.8 秒，两边交替开火
- 舰体：每 5 秒一次 `fan7wide`（慢速大光球，朝正下方）
- 打掉一座炮塔后：另一座的开火间隔 × 0.8（射速 +25%）；被打掉的炮塔脱落下坠，中等爆炸

### 5.4 阶段二攻击
- `ring16` 大光球环形弹：间隔 2.0 秒，每次旋转 11.25°
- **横扫激光** `laser_sweep`：每 7 秒一次
  - 预警 0.8 秒：从核心向下画一条细的粉紫色闪烁线
  - 发射 1.5 秒：宽 10 像素的激光从 −25° 扫到 +25°（下一次反过来扫）；判定宽 8 像素
  - 发射期间暂停环形弹
  - 放炸弹会立刻打断激光，并重新开始 7 秒冷却
- 激光和环形弹的空档里：`aimed_fast3`，间隔 1.2 秒
- 核心血量 ≤ 280（一半）时：环形弹间隔改为 1.6 秒，激光每 5.5 秒一次，扫动缩短到 1.2 秒

## 6. 难度曲线

| 段落 | 同屏敌人 | 同屏敌弹（估算峰值） | 教学 / 考验重点 |
|---|---|---|---|
| 地面段 0:05–0:50 | ≤ 8 | ≤ 15 | 射击、躲单发瞄准弹、第一次吃 P、地面单位不能撞 |
| 海岸段 0:50–1:35 | ≤ 14 | ≤ 40 | 扇形弹、环形弹、追踪导弹、第一次拿到炸弹 |
| 基地段 1:35–2:30 | ≤ 16 | ≤ 70 | 地空混合、需要走位、密集编队、合理用炸弹 |

- 每段之间留 3 秒空档（0:49、1:34、2:29），让玩家喘口气，也方便换背景
- 全程峰值约 90 颗敌弹，远低于上限 150，给中低端机留余量

  - 死得多或漏掉携带机：2:26 的保底补给机（W27）不开火、停留 3 秒，基本能吃到；最差情况下 BOSS 战开始时是 Lv2

## 8. 数据格式（给程序用）

文件：`src/game/levels/stage1.ts`。时间单位是秒，坐标是逻辑像素。

### 8.1 类型定义

```ts
type EnemyType = 'small' | 'medium' | 'interceptor' | 'bomber' | 'drone'
               | 'tank' | 'turret2' | 'missile_car';

type Move =
  | { kind: 'straight'; speed: number; angle?: number }
  | { kind: 'sine'; vy: number; amp: number; period: number }
  | { kind: 'v_dive'; speed: number; stopY: number }
  | { kind: 'cross'; from: 'topLeft' | 'topRight'; speed: number }
  | { kind: 'hover'; stopY: number; hold: number }
  | { kind: 'side_arc'; side: 'left' | 'right'; y0: number; speed: number }
  | { kind: 'orbit'; anchor: { x: number; y: number }; r: number; period: number; hold: number }
  | { kind: 'slow_push'; stopY: number; hold: number }
  | { kind: 'ground'; vx?: number; entry?: 'top' | 'left' | 'right' | 'bottomLeft' | 'bottomRight' };

type Fire =
  | { kind: 'none' }
  | { kind: 'aimed1' | 'aimed3burst' | 'missile' | 'aimed_fast3'
      | 'fixed2'; interval?: number; firstDelay?: number; maxShots?: number; atY?: number }
  | { kind: 'fan3' | 'fan5' | 'fan7wide'; spread: number; interval: number; firstDelay?: number }
  | { kind: 'ring8' | 'ring16'; interval: number; rotStep: number };

interface SpawnGroup {
  enemy: EnemyType;
  count: number;
  xs: number[];            // 每架的出场 x；只有一个值时全部同一个 x
  y?: number;              // 默认 -20；地面单位按地块行出现
  interval?: number;       // 依次出场间隔
  move: Move;
  fire: Fire;
  fireOnly?: number[];     // 只有这些序号（从 0 开始）开火；不写表示全部开火
  hp?: number;             // 不写就用敌人默认血量
  score?: number;          // 不写就用敌人默认分数
  drops?: { index: number; item: 'P' | 'B' }[];  // 第几架是携带机
}

type BuildingType = 'pillbox' | 'fuel_depot' | 'radar_station' | 'sea_gun';

interface BuildingPlacement {
  id: string;              // 'B01'
  type: BuildingType;
  section: 'ground' | 'coast' | 'base';
  row: number;             // 占地最下面一行（该段地块网格下标）
  col: number;             // 占地最左一列
}

interface Wave {
  id: string;              // 'W04'
  t: number;               // 出场时间（秒）
  section: 'ground' | 'coast' | 'base';
  mvp: boolean | 'partial';
  condition?: 'powerBelowMax';   // 条件波次
  groups: SpawnGroup[];
}

interface BossConfig {
  enterAt: number; enterDuration: number; parkY: number;
  drift: { amp: number; period: number };
  parts: { id: 'turretL' | 'turretR' | 'core'; offset: { x: number; y: number };
           radius: number; hp: number; score: number; phase: 1 | 2 }[];
  phase1: { turretL: Fire; turretR: Fire; hull: Fire; survivorRateMul: number };
  transition: { duration: number; bulletsToScore: number };
  phase2: { ring: Fire; aimed: Fire;
            laser: { every: number; telegraph: number; sweep: number;
                     fromDeg: number; toDeg: number; width: number; hitWidth: number };
            enrageAtHpRatio: number;
            enrage: { ringInterval: number; laserEvery: number; sweep: number } };
  death: { duration: number; explosions: number };
}
```

### 8.3 实现要点
- 时间轴按游戏时间推进（暂停时停止），用固定步长累计
- 炮塔和导弹车仍按「地块行」从屏幕顶端外面跟着卷动进来。坦克用 `entry`，可以从左右或底角进来，并且不能停在河流或浅水上
- P1（MVP）只加载 `mvp` 为 `true` 或 `"partial"` 的波次；`"partial"` 只生成小型和中型战机的组
- 击落率分母 = 实际生成的敌人数
- 建筑放在 `StageData.buildings`，按世界卷轴距离出场，不走波次时间轴。位置每帧由卷轴直接算出（整像素，不插值），所以和地块对齐
- 调试面板显示：当前时间、波次编号、同屏敌人数、同屏敌弹数。H5 上 F2 跳到预警、F3 跳到 Boss。面板和这两个跳关**默认关闭**，在设置里打开「调试模式」后才出现（F1 同样翻转这一项）

## 9. 本版假设（可以改）
1. 全关时长定为约 3 分 25 秒（道中 2 分 25 秒），比 v1 写的 2 分 45 秒长，以符合「3–4 分钟含 BOSS」的目标
2. 新增「中型战机」作为第 8 种敌人，正式版也保留（和 P1 的素材复用方案一致）
3. 重型轰炸机给 2000 分（比中型高一档）

5. BOSS 战背景换成代码生成的星空，不用地块（对应「BOSS 在轨道上」）
6. BOSS 测试版不超时；阶段切换时把屏幕上的敌弹换成分数
7. 撞机时敌机不受伤；死亡时清掉全屏敌弹（给玩家喘口气）
