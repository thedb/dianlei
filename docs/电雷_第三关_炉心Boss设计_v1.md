### 2.2 Boss 场

地图 id `furnaceBoss`，显示名 **炉心浮台**。

**场地外观锁定 C 淹水船坞废港**（`FURNACE_MAP_LOOK` = `'C'`，2026-10-27 Yoan 选定）。它替换原来「A 灯带四瓣底盘」铺满屏的循环段：A 现在只指 Boss 底盘精灵（§9），地图场走废港。目的是和第 2 关铁堡厂轨的单调厂房底板明显拉开。语汇：干船坞坑、半沉驳船、锈起重机骨架、淹水泥滩、焦土岸、锈混凝土垫、断桩、废铁。参考图在仓库外（`furnace-bg-refs/C-dockyard.jpg`，不入库）。

**C 必须是接着河流A 的白天港口（2026-10-27 真机反馈锁定）**：

- **水要接着河**：河流A 的中槽水道（第 9–13 列）从接近带第 0 行一路流进港池，再作为中央运河穿过整段循环，任何一行都不断。循环段两侧屏边各有一条外侧水道，另有船台（水从运河或外侧水道切进码头）。不准再出现整屏泥灰、没有水的循环段。
- **色调跟河流A 对齐**：白天、亮、军港废墟。水用河流A 的同一套水色和白沫边（不另做暗水），混凝土是亮灰，泥滩是橄榄色，钢构和起重机是亮锈橙。不准切成暗色赛博、不准整体压暗。测试锁定：循环段平均亮度不低于河流A 的 0.85 倍，接近带不低于 0.75 倍；两段的水像素占比都超过 30%。
- 从道中进 Boss 场的整个过程不暗场、不淡出、不铺预警白云、不切宇宙（见下表「接图」）。

| 2 | 卷轴把焦土和浮台卷进画面。不走星空云层 |

## 4. 环舱与开合

这是本关唯一的主机制。炮舱负责前段血。装甲瓣负责后段的开合。瓣没有自己的血。

### 4.1 环舱段

四座炮舱绕堡垒中心顺时针转。初始角 **45° / 135° / 225° / 315°**（0° 为正下方，顺时针增加）。角速度草案 36°/秒。摧毁一座不改变其余三座的角度，空位留着。

| 项 | 锁定内容 |
|---|---|
| 数量 | 4。id `pod0` … `pod3` |
| 可打 | **同一时间只有一座可打**（「激活舱」，`furnaceActivePod`），按 `pod0` → `pod1` → `pod2` → `pod3` 的顺序轮到。入场滑行就从 `pod0` 开始。四座都毁才进入 §4.2 |
| 激活舱 | 只有子弹打中**激活舱的命中圆**才扣血，扣的就是这座 |
| 等待舱 | 未轮到的完好炮舱照常开火、照常转，但不吃伤害：子弹打中它的命中圆会被**挡下消失，不扣任何血**（选定「挡下」而非「穿过」，这样玩家看得出它是实体，只是还没轮到） |
| 底盘 / 瓣 / 核心 | 环舱段对玩家子弹**完全不挡**：子弹穿过底盘、装甲瓣、核心继续飞，不消失、不扣任何血、不转记到任何炮舱，所以转到底盘上方的激活舱照样打得到（旧的「记入较近炮舱」和「底盘挡弹」都作废）。只对子弹放行；玩家机体碰到底盘、瓣、炮舱仍即死 |
| 轮换 | 激活舱被击破的那一帧，下一座存活炮舱立刻成为激活舱，高亮描边直接出现，不闪（§9） |
| 核心 | 装甲瓣保持合拢。子弹和追踪导弹打不进核心 |
| 摧毁 | 一座炮舱中爆炸，炮口不再射击。残骸没有命中盒，打在残骸上的子弹按底盘或空处处理。四座都毁的那一帧进入 §4.2 的切换 |
| 轨道 | 半径草案 76。命中半径草案 14 |
| 随机 | 转角由时间决定，不读 `rng` |

没打中激活舱、也没打中等待舱的子弹一律继续飞。追踪导弹只锁激活舱。四座都毁、进入 §4.2 切换之后，底盘、瓣、核心的挡弹规则（§4.3）才恢复。

### 4.2 切换

四座炮舱都毁了之后：

| 项 | 锁定内容 |
|---|---|
| 时长 | 1.2 秒（`FURNACE_PHASE_INVULN`） |
| 受伤 | 这段无敌。炸弹不结算 |
| 开火 | 停火 |
| 瓣 | 保持合拢 |
| 敌弹 | 已经飞出的敌弹继续飞，不转分、不清掉 |
| 衔接 | 结束时进入露核段，状态从 `closed` 开始 |

简单、中等、困难都走这一次切换。它不是困难专属。

### 4.3 露核段

装甲瓣是四片环绕板，绕同一中心转，并做开合。核心固定在堡垒中心。

| 状态 | 主战时长 | 过载时长 | 核心吃子弹和追踪弹 | 新弹幕 |
|---|---|---|---|---|
| `closed` | 1.8 秒 | 1.4 秒 | 否 | 平行高射，外加一次导弹 |
| `opening` | 0.4 秒 | 0.3 秒 | 是 | 火焰扇 |
| `open` | 2.2 秒 | 1.6 秒 | 是 | 火焰扇 |
| `closing` | 0.4 秒 | 0.3 秒 | 否 | 不发射 |

主战一圈 **4.8 秒**。困难过载一圈 **3.6 秒**。可受伤的窗口是 `opening` + `open`：主战 2.6 秒，过载 1.9 秒。

每次进入 `closed`，整圈瓣前进 **45°**。核心仍在中心。变的是瓣的时钟位置，也就是窗口两侧的遮挡。合拢后再张开，开口方向已经换过。

合拢时打在瓣或底盘上的子弹消失，不扣核心。张开时只有打中核心命中半径（`FURNACE_CORE_RADIUS` = **24**，即草案 20 × 1.2）的子弹扣核心；打在瓣上的仍然消失。瓣的命中盒在四个状态都在，用来吃掉打偏的子弹。

底盘在核心下方留一条**喉道**：`opening` / `open` 时，x 落在核心中心 ± 核心命中半径（24）以内的子弹穿过底盘继续飞，不被底盘吃掉，打到核心才扣血。喉道之外仍由底盘挡下。`closed` / `closing` 没有喉道。追踪弹同样只在 `opening` / `open` 锁核心。

开合不是无敌。无敌只有 §4.2、§7.1 的 1.2 秒切换，以及死亡之后。

### 4.4 漂移

开战之后，堡垒 x 在 180 左右做正弦漂移。草案振幅 32、周期 8 秒。漂移不切换武器，不关核心窗口，不无敌。入场滑入的 2 秒不做这次漂移。1.2 秒切换期间漂移照走，只是不扣血。

y 停在 `FURNACE_PARK_Y`。开合不改变停靠高度。

## 7. 阶段、血量、分数

阶段看部位，不看漂移位置。

| 顺序 | 部位 | 基础血量 | 分数 | 何时能打 |

| 困难追加 | 过载段，仍是 `core` | 180 | 30000 留到这一段被打掉 | 仅困难。主战核心清空之后 |

主战血量合计 **560**。分数合计 **40000**。核心在炮舱还活着时不扣血。1.2 秒切换不扣血。

这组血量是草案。锁定的是时长目标：干净的 Lv3、简单难度、主炮实际约每秒 20 点、开合占空比按 §4.3 时，环舱段约 14 秒，露核段约 26 秒，主战合计约 40 秒（不含入场和 1.2 秒切换）。试玩若差一截，改血量或占空比，并回写本节。不要为了凑成铁堡的 840 把窗口拖长。

| 难度 | 主战血量 | 过载 | 血条 |
|---|---|---|---|
| 简单 | 560 | 无。核心归零即死 | 一条红，打到 0 |
| 中等 | 70 × 1.15 × 4 + 280 × 1.15 = 644 | 无。核心归零即死 | 一条红，打到 0 |
| 困难 | 560 × 1.30 = 728 | 180 × 1.30 = 234 | 红槽是炮舱加核心，黄槽是过载 |

中等血量按部件各自 `scaleHp` 后再加总。`scaleHp` 不取整，代码里就是 80.5 × 4 + 322 = 644。

### 7.2 炸弹与受击

`fightMax` 等于本局会打到的部位血量之和（困难含过载）。伤害是 `round(fightMax × BOMB_BOSS_RATIO)`。

| 时机 | 子弹 / 追踪弹 | 炸弹 |
|---|---|---|
| 入场滑行 | 只有激活舱（`pod0`）入画后能被打中。其他炮舱挡下子弹；底盘放行。都不扣血 | 能。只扣激活舱 |
| 环舱段 | 只有打中激活舱扣该舱。打中等待舱挡下消失，不扣血。打在底盘、瓣、核心上的穿过继续飞，不扣血，不转记 | 能。**只扣激活舱**，其他炮舱不受影响 |

炸弹是唯一会清掉已经飞出的敌弹的玩家手段。开合、炮舱摧毁、阶段切换、过载切换和炉心死亡都不清弹。自机被击落仍按现有规则清一次，给下一架留空档。

## 8. 死亡、过关、旁白

简单和中等在主战核心归零时进入死亡。困难在过载归零时进入死亡。死亡是常规解体，然后通关离场。本关没有巨碟。

|---|---|
| 1 | 多段爆炸。6 次大爆炸，2.4 秒，沿底盘散布。屏震用现有 Boss 死亡震。瓣作为代码碎片散开，无判定 |
| 2 | 不清除已经飞出的敌弹 |

残骸留在轨道空位上，跟着轨道转（`furnaceSyncMounts` 照常更新）。击破时间记在 `systems/furnace.ts` 的 `WeakMap` 里（`furnacePodWreckAge` / `furnaceLastWreckAge`，只给美术用，不读 `rng`）。

烘焙可以分底盘、瓣、炮舱三层，便于旋转。不要把开合焊进一张不会动的全图。实现按这三层加核心烘焙（`buildFurnaceChassis` / `buildFurnacePetal` / `buildFurnacePod` / `buildFurnaceCore`），合拢、张开各一张底盘；瓣和炮舱运行时旋转贴图。所有烘焙坐标都是整数像素，`plot` 遇到非整数坐标直接跳过（#52 真机崩溃就是非整数行号越界）。静帧脚本 `npm run art:furnace` 仍未添加。
