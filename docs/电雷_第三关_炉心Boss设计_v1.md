### 2.1 道中（上下文，本文不排波）

## 3. 入场（可玩，不锁操作）

玩家在整段入场里保持移动、射击和炸弹。

| 步 | 锁定内容 |
|---|---|
| 1 | 河流A 道中收束。道中刷怪在预警时停止。`STAGE3_WARNING_AT` = **118** 秒。常量单独命名，不引用 `STAGE2_WARNING_AT` |
| 2 | 卷轴把焦土和浮台卷进画面。不走星空云层 |
| 3 | 循环段就位。堡垒从画面上方滑入 |
| 4 | 停稳在锚点。炮舱位于初始角。装甲瓣合拢 |
| 5 | 开战：WARNING 字标、名称牌「炉心」「赛博浮垒」、血条。环舱段开火 |

滑入 **2 秒**，**可以受伤**，不开火。中心从 `FURNACE_ENTER_Y` = **−72** 落到 `FURNACE_PARK_Y` = **168**，x 固定 **180**（`LOGICAL_W / 2`，与 `BOSS_ANCHOR_X` 相同）。

血条：开战前 2 秒从左向右填满。简单 / 中等是一条红。困难先填红槽再填黄槽，比例见 §7。

WARNING 字标显示 1.5 秒。名称牌留到死亡。挑战 Boss「3」的 `seek` 落在已经接好的接近带上（`FURNACE_ENTER_AT` = **123**），不铺白云，卷轴继续。123 与 118 的 5 秒差等于 `WARNING_DURATION`。按现有 `tileHandoffDistance(5)`，本地卷轴比河流A 末行超前约 120 像素。

预警 118 秒时，`118 × 40 + 640 = 5360 < 5760`。若改长道中时钟，要同时改河流A 的像素高度或重算这对数字，并改写本节。

## 4. 环舱与开合

这是本关唯一的主机制。炮舱负责前段血。装甲瓣负责后段的开合。瓣没有自己的血。

### 4.1 环舱段

四座炮舱绕堡垒中心顺时针转。初始角 **45° / 135° / 225° / 315°**（0° 为正下方，顺时针增加）。角速度草案 36°/秒。摧毁一座不改变其余三座的角度，空位留着。

| 项 | 锁定内容 |
|---|---|
| 数量 | 4。id `pod0` … `pod3` |
| 可打 | 环舱段开始就能打。四座可同时打 |
| 核心 | 装甲瓣保持合拢。子弹和追踪导弹打不进核心 |
| 摧毁 | 一座炮舱中爆炸，炮口不再射击。四座都毁的那一帧进入 §4.2 的切换 |
| 轨道 | 半径草案 76。命中半径草案 14 |
| 随机 | 转角由时间决定，不读 `rng` |

打在底盘上、没有打中炮舱的子弹，记入当前较近的一座存活炮舱，和铁堡把车体伤害记入较近弱点的规则同一条。打空的子弹不消失。

### 4.2 切换

四座炮舱都毁了之后：

| 项 | 锁定内容 |
|---|---|
| 时长 | 1.2 秒（`FURNACE_PHASE_INVULN`） |
| 受伤 | 这段无敌。炸弹不结算 |
| 开火 | 停火 |
| 瓣 | 保持合拢 |
| 敌弹 | 已经飞出的敌弹继续飞，不转分、不清掉 |
| 衔接 | 结束时进入露核段，状态从 `closed` 开始 |

简单、中等、困难都走这一次切换。它不是困难专属。

### 4.3 露核段

装甲瓣是四片环绕板，绕同一中心转，并做开合。核心固定在堡垒中心。

| 状态 | 主战时长 | 过载时长 | 核心吃子弹和追踪弹 | 新弹幕 |
|---|---|---|---|---|
| `closed` | 1.8 秒 | 1.4 秒 | 否 | 平行高射，外加一次导弹 |
| `opening` | 0.4 秒 | 0.3 秒 | 是 | 火焰扇 |
| `open` | 2.2 秒 | 1.6 秒 | 是 | 火焰扇 |
| `closing` | 0.4 秒 | 0.3 秒 | 否 | 不发射 |

主战一圈 **4.8 秒**。困难过载一圈 **3.6 秒**。可受伤的窗口是 `opening` + `open`：主战 2.6 秒，过载 1.9 秒。

每次进入 `closed`，整圈瓣前进 **45°**。核心仍在中心。变的是瓣的时钟位置，也就是窗口两侧的遮挡。合拢后再张开，开口方向已经换过。

合拢时打在瓣或底盘上的子弹消失，不扣核心。张开时只有打中核心半径的子弹扣核心；打在瓣上的仍然消失。瓣的命中盒在四个状态都在，用来吃掉打偏的子弹。

开合不是无敌。无敌只有 §4.2、§7.1 的 1.2 秒切换，以及死亡之后。

### 4.4 漂移

开战之后，堡垒 x 在 180 左右做正弦漂移。草案振幅 32、周期 8 秒。漂移不切换武器，不关核心窗口，不无敌。入场滑入的 2 秒不做这次漂移。1.2 秒切换期间漂移照走，只是不扣血。

y 停在 `FURNACE_PARK_Y`。开合不改变停靠高度。

## 5. 武器

三套，都是地球军火。实现可以用现有小弹、大弹和导弹精灵，或 `{ kind: 'pattern' }`。不新增激光种类。

| 武器 | 用在哪 | 锁定行为 |
|---|---|---|
| 环舱扇 | 环舱段，每座活着的炮舱 | 沿该舱朝外的方向打小弹扇形。炮舱毁了就停 |
| 平行高射 | 环舱段的底盘；露核段和过载的 `closed` | 自底盘中线向下的平行小弹。过载比主战多一路 |
| 导弹 | 环舱段每座活着的炮舱；露核段和过载的 `closed` | 短追踪，然后直线。没有激光引导 |
| 火焰扇 | 露核段和过载的 `opening` 与 `open` | 大弹扇形，暖色，朝玩家张开。不是光带，击中判定仍是大弹 |

环舱段不跑开合表。露核段不复活炮舱。

同屏敌弹维持在 `ENEMY_BULLET_CAP`（150）以下。瞄准弹离玩家近于 `AIMED_MIN_DIST`（48）时这一发不发射。

困难过载不掉弹药箱。弹药箱留在铁堡。

## 7. 阶段、血量、分数

阶段看部位，不看漂移位置。

| 顺序 | 部位 | 基础血量 | 分数 | 何时能打 |
|---|---|---|---|---|
| 先 | `pod0` … `pod3` | 各 70 | 各 2500，打掉即给 | 环舱段 |
| 后 | `core` | 280 | 30000 | 四座炮舱都毁，且瓣处于 `opening` 或 `open` |
| 困难追加 | 过载段，仍是 `core` | 180 | 30000 留到这一段被打掉 | 仅困难。主战核心清空之后 |

主战血量合计 **560**。分数合计 **40000**。核心在炮舱还活着时不扣血。1.2 秒切换不扣血。

这组血量是草案。锁定的是时长目标：干净的 Lv3、简单难度、主炮实际约每秒 20 点、开合占空比按 §4.3 时，环舱段约 14 秒，露核段约 26 秒，主战合计约 40 秒（不含入场和 1.2 秒切换）。试玩若差一截，改血量或占空比，并回写本节。不要为了凑成铁堡的 840 把窗口拖长。

| 难度 | 主战血量 | 过载 | 血条 |
|---|---|---|---|
| 简单 | 560 | 无。核心归零即死 | 一条红，打到 0 |
| 中等 | 560 × 1.15 = 644 | 无。核心归零即死 | 一条红，打到 0 |
| 困难 | 560 × 1.30 = 728 | 180 × 1.30 = 234 | 红槽是炮舱加核心，黄槽是过载 |

中等血量按部件各自 `scaleHp` 后再加总，实现若四舍五入，以代码的取整为准，并回写这张表。

### 7.1 困难过载（第二条血）

简单和中等不进入。结构与铁堡过载、百战困难第三阶段相同：主战清空之后另给一段血。弹幕仍是 §5 的三套地球武器，只加快开合、加密弹幕。

| 项 | 内容 |
|---|---|
| 切换 | 1.2 秒，无敌，停火。已经飞出的敌弹留下。炸弹不结算 |
| 外观 | 不新做底盘。核心发光改为警示黄。瓣的块数仍是 4 |
| 开合 | §4.3 的过载时长。从 `closed` 开始 |
| 武器 | 过载列的平行高射、导弹、火焰扇。没有激光，没有弹药箱 |
| 血条 | 双槽。主战扣血时黄槽保持满。过载开始后红槽空，只掉黄槽。`bar: 'extra'`，`gate: 'hard'` |
| 结束 | 过载归零 → 给 30000 → 死亡 |

### 7.2 炸弹与受击

`fightMax` 等于本局会打到的部位血量之和（困难含过载）。伤害是 `round(fightMax × BOMB_BOSS_RATIO)`。

| 时机 | 子弹 / 追踪弹 | 炸弹 |
|---|---|---|
| 入场滑行 | 能打中已经入画的炮舱 | 能。伤害平分到还活着的炮舱 |
| 环舱段 | 打中炮舱就扣该舱。打中底盘记入较近的活炮舱 | 能。平分到还活着的炮舱 |
| 瓣合拢 | 打在瓣或底盘上的消失，不扣核心 | 能。露核段扣核心。合拢不挡炸弹 |
| `opening` / `open` | 打中核心才扣核心 | 能，扣核心 |
| 1.2 秒切换 | 不能 | 不能 |
| 过载切换的 1.2 秒 | 不能 | 不能 |
| 死亡动画 | 战斗已结束 | 战斗已结束 |

炸弹是唯一会清掉已经飞出的敌弹的玩家手段。开合、炮舱摧毁、阶段切换、过载切换和炉心死亡都不清弹。自机被击落仍按现有规则清一次，给下一架留空档。

底盘碰到玩家判定点即死。瓣和炮舱碰到判定点同样即死。合拢不挡碰撞。

## 8. 死亡、过关、旁白

简单和中等在主战核心归零时进入死亡。困难在过载归零时进入死亡。死亡是常规解体，然后通关离场。本关没有巨碟。

| 步 | 内容 |
|---|---|
| 1 | 多段爆炸。6 次大爆炸，2.4 秒，沿底盘散布。屏震用现有 Boss 死亡震。瓣作为代码碎片散开，无判定 |
| 2 | 不清除已经飞出的敌弹 |
| 3 | 然后只走 `stepVictoryExit`：先回到平飞，再冻结 2 秒，2 秒缓回出生点，尾焰 0.85 秒，再向上飞出。击破时的侧倾不带进返航。结算仍等飞出画面 |
| 4 | 旁白 `s3_end`，Boss 进入清空时挂上。文案与故事表相同：航母坐标已锁定。准备舰载出击。 |

`s3_open` 属于第 3 关开场，不在死亡流程里。文案：突入叛军主基地。电雷，撕开防线。

正式通关且注册表里已有第 4 关时，结算层走现有字卡 `STAGE_CARD_TIME`（3 秒）：「第四关」「航母出击」，然后从第 4 关 t = 0 进入。分数、生命、炸弹、主副武器、僚机和死亡次数沿用现有携带。通关奖金折进携带分。挑战 Boss 和第 4 关尚未注册时，仍进结算屏。重试只重开刚打完的那一关，不带携带。

P32 把第 3 关放进注册表之后，正式通关第 2 关会字卡进入第 3 关。这是现有 `nextStageId`，不是新流程。挑战 Boss「2」仍进结算。
