## 2. 场地

### 2.1 道中（上下文，本文不排波）

第 2 关 Boss 之前的最后一张道中图是 **陆地B**（`landB`）。更早的道中图、波次、新敌种不在本文。

陆地B 的上下边契约保持不变：第 9–13 列是路面中轴，边缘行没有水。厂房接近带的第 0 行接这条边。陆地B 末段是林地，接近带的读法是林间道路进入厂房。

### 2.2 Boss 场

地图 id `factoryBoss`，显示名 **铁堡厂轨**。

| 项 | 锁定内容 |
|---|---|
| 结构 | 一条主题接近带，然后上下边对齐的循环段（`loopFrom`） |
| 接图 | 陆地B 末行直接接到接近带。不淡出、不铺预警白云、不切宇宙、不切星空 |
| 卷轴加速 | 沿用 `TILE_HANDOFF_RAMP` / `TILE_HANDOFF_PEAK` / `TILE_HANDOFF_FAST_END`（0.5 秒升到 280 像素/秒，4.5 秒回到 `BG_SCROLL_SPEED` 40） |
| 战中卷动 | 循环段继续以 40 像素/秒上卷 |
| 接近带 | 下段是林地道路，然后厂门。过了厂门，厂房内墙、高窗和三轨占满上半。长度 1 个区块（40 行） |

## 3. 入场（可玩，不锁操作）

玩家在整段入场里保持移动、射击和炸弹。

| 步 | 锁定内容 |
|---|---|
| 1 | 陆地B 道中收束。道中刷怪在接近开始时停止。`warningAt` 占位 118 秒 |
| 2 | 卷轴把厂房卷进画面。不走第一关那套 5 秒星空云层 |
| 3 | 厂内循环段就位，三轨对齐到 §2.3 |
| 4 | 铁堡在**中轨**滑入并停稳。停稳时看见的是车尾，不是整列 |
| 5 | 开战：WARNING 字标、名称牌「铁堡」「弹药转运」、血条、换轨计时、武器从第 1 式「高射扇」开始 |

滑入约 2 秒，**可以受伤**，不开火。尾梁从画面上方（`TIEBAO_ENTER_TAIL_Y` = −12）落到遭遇尾梁（y = 160）。9 节车列的中心从 `enterY` = **−432** 落到 `parkY` = **−260**。`parkY` 是开战歇脚中心，不是终态中心。

遭遇窗口：尾梁 y = 160，再向上 2.5 节（200 像素）。半节（40 像素）还在 y = 0 上面，画面里大约两节车厢。机车鼻大约在 y = −680。

终态（机车 + 2 节，高 280）的鼻停在屏幕 y = **48**，中心 `TIEBAO_END_PARK_Y` = **188**，尾梁 y = 328。那是剥到 ≤30% 之后的位置，不是开战位置。

血条：开战前 2 秒从左向右填满。简单 / 中等是一条红。困难先填红槽再填黄槽，比例见 §7。

WARNING 字标显示 1.5 秒。名称牌留到死亡。挑战 Boss「2」的 `seek` 落在已经接好的厂内接近带上（`TIEBAO_ENTER_AT` = 123），不铺白云，卷轴继续。标题演示仍只跑第一关。

## 4. 剥厢

主血条按剩余比例剥车厢。困难的第二血条不剥。

| 项 | 锁定内容 |
|---|---|
| 车列 | 机车 + 9 节。每节间距 80（车身 72 + 钩缝 8）。机车段 116（尖头加驾驶室）。尾梁余量 4 |
| 命中盒宽 | 80。高度 = 116 + 节数 × 80 + 4。9 节是 **840**，终态 2 节是 **280** |
| 阈值 | 主血剩余 **90 / 80 / 70 / 60 / 50 / 40 / 30%** 各剥正好 1 节后车。同一帧跨过几档，就一次剥几节 |
| 表现 | 被剥的那节在它的歇脚位置爆一次（中爆炸）再加两团碎片（小爆炸）。画在那节上的顶座随裁切消失 |
| 推进 | 每剥 1 节，尾梁下移 24，车列跟着进入画面。≤30% 时鼻在 y = 48，画面上是完整的机车 + 2 节 |
| 终态 | ≤30% 之后不再剥。简单 / 中等把这一条血打到 0，然后死亡、通关 |
| 困难 | 第一条血走同一条剥厢曲线。这条血打空之后，第二条血是过载（§7.1），仍是机车 + 2 节，不再剥 |
| 入场 | 滑入时按当前血量直接取节数，不补爆。爆炸留到开战之后的第一次结算 |
| 死亡 | 若还没剥到终态，死亡帧把剩下的节一次剥完，再把车心放到终态中心，然后走 §8 的爆炸 |

| 90% | 1 | 机车+8 | 760 | 184 | −196 |
| 80% | 2 | 机车+7 | 680 | 208 | −132 |

## 5. 换轨

主战全程换轨，直到主血条被打空。困难过载继续换轨，周期相同。换到哪一条轨不推动阶段，也不改剥厢。

| 项 | 锁定内容 |
|---|---|
| 节奏 | 从上一次停稳到下一次停稳 **6 秒**。主战和困难过载相同 |
| 窗口 | 输出 4.8 秒，然后背景并轨 1.2 秒。没有预告段 |
| 预告 | 不点亮目标轨，不画轨道高亮，不给轨端光点。目标轨在并轨开始的那一帧才选定 |
| 车体 X | 始终是三条固定轨之一：72 / 180 / 288。并轨的 1.2 秒里车体留在**正在离开的那条轨**。动画结束的那一帧，X 跳到新轨，同时武器序号 +1 |
| 并轨画面 | 只画背景辙叉。`TIEBAO_SWITCH_SPAN` = 176。岔尖从旧轨收到新轨。辙叉前方（更小的 y）已经是新轨，后方仍是旧轨。地图贴图仍是三条直轨。这一秒里车体的屏幕 X 保持旧轨 |
| 必换 | 等概率去另外两条，不留在当前轨。用关卡 `SceneContext.rng` |
| 受伤 | 并轨可以受伤。换轨不给无敌 |
| 开火 | 并轨期间暂停开火 |
| 死亡 | 并轨中被打死：取消换轨，进入死亡 |
| 冲轨 | 下冲或返回还没结束时，不开始并轨。其它武器不推迟换轨。一个输出窗只冲一次 |

从中轨出发，左与右各 50%。从左轨出发，中与右各 50%。从右轨出发，中与左各 50%。允许左直接到右。

## 6. 武器循环

每次**换轨成功**（X 落到新轨的那一帧），攻击式样 +1。顺序固定。开战还没有换过轨，式样是第 1 式。第 8 式之后回到第 1 式。

炮塔被打掉、核心打开、剥厢、当前在哪条轨，都不改变序号，也不重置 6 秒时钟。被剥车厢上的顶座不再绘制。两门真枪的锚点留在机车和第二节。

| 序号 | 名称 | 锁定行为 |
|---|---|---|
| 1 | 高射扇 | 车顶 `fan5`，瞄准玩家。间隔不乘射速 |
| 2 | 导弹齐射 | 4–6 发短追踪、然后直线的导弹 |
| 3 | 落弹雨 | 地面先出预警圈，再爆炸 |
| 4 | 侧舷扫射 | 左右机枪扫射，把玩家赶出车底正下方 |
| 5 | 封轨弹墙 | 短时间的固定弹墙，打向相邻轨 |
| 6 | 冲轨撞击 | 沿当前轨快冲到屏幕底沿 y = 640，再慢退。一个输出窗一次。机车+4 之前不下冲 |
| 7 | 三轨火箭 | 左、中、右各一发慢速火箭，直线向下 |
| 8 | 弹链抛射 | 抛出弹药箱；没被打掉就在地面小爆 |

禁止激光、扫射光带、能量柱。困难过载也不补激光。

式样在抵达新轨后才切换。因此「封轨弹墙」打完才会换轨，下冲发生在下一条轨上。

枪口：高射扇交替两门顶炮。炮位的屏幕 y > 8 时从炮位打出；还在画面外时改从当前看得见的车厢中线打出，避免子弹在画面外被清掉。导弹、落弹、侧舷、弹药箱用先导车厢的中线，只要那一点的屏幕 y > 8；否则用当前最末节。封轨弹墙从机车顶炮那一行发出；机车还在画面外时，这一行收到 y = 4。

除高射扇以外，攻击间隔 × `TIEBAO_RATE_SCALE`（2/3），频率 ×1.5。高射扇的 1.4 秒和首发 0.4 秒不乘。冲轨的下冲和返回不走这个倍率。弹速、半径、发数、追踪时长、弹药箱飞行 1.15 秒不乘。

干净的 Lv3、简单难度、主炮实际约每秒 20 点时，主战大约 42 秒。6 秒一式，大约打完第 1–7 式并进入第 8 式。中等约 48 秒。困难主战约 55 秒，会进入第二圈的第 2 式。过载改走三式循环，时钟同样是 6 秒，不从八式的下一号接下去。

同屏敌弹维持在 `ENEMY_BULLET_CAP`（150）以下。

## 8. 阶段、血量、分数

阶段看血，不看轨道。剥厢看主血剩余比例，不单开阶段。

| 顺序 | 部位 | 基础血量 | 分数 | 何时能打 |
|---|---|---|---|---|
| 先 | `roofCar` 后车厢顶炮 | 140 | 5000，打掉即给 | 主战开始就能打。两门可同时打 |
| 先 | `roofLoco` 车头顶炮 | 140 | 5000，打掉即给 | 同上 |
| 后 | `core` 车头核心 | 560 | 30000 | 两门车顶炮都毁了之后 |
| 困难追加 | 过载段，仍是 `core` | 240 | 30000 留到这一段被打掉 | 仅困难。主战核心清空之后。车列已是机车+2 |

主战血量合计 **840**。分数合计 **40000**。核心在车顶炮还活着时不扣血。车顶炮毁到核心打开没有无敌。

打在车体上的子弹和追踪导弹记入当前存活弱点里较近的一个。车体外掠过的子弹不消失。

锚点是从机车鼻向下的行，不是从会移动的车心量。运行时 `offsetY = 行 − 当前高度 / 2`。
