### 2.1 道中（上下文，本文不排波）

第 2 关 Boss 之前的最后一张道中图是 **陆地B**（`landB`）。更早的道中图、波次、新敌种不在本文。

### 2.2 Boss 场

### 2.3 三轨位置

逻辑分辨率 360×640，y 向下增大。

| 轨 | 建议 X | 说明 |
|---|---|---|
| 左 | 72 | 距左缘 72 |
| 中 | 180 | 与 `LOGICAL_W / 2`、第一关 `BOSS_ANCHOR_X` 相同 |
| 右 | 288 | 距右缘 72 |

轨距 108。三条 X 可调整，但必须是屏幕上的三条固定车道，中轨留在画面正中附近。Boss 车宽草案 ≤ 80，使车身只覆盖所在轨，不骑到邻轨中心。

## 3. 入场（可玩，不锁操作）

玩家在整段入场里保持移动、射击和炸弹。没有失去操作的过场。

| 步 | 锁定内容 |
|---|---|
| 1 | 陆地B 道中收束，卷轴向厂房接近。道中刷怪在接近开始时停止；具体 `warningAt` 由以后的第二关波次表填写 |
| 2 | 卷轴把巨型厂房卷进画面。字标流程不走第一关那套 5 秒星空云层 |
| 3 | 厂内循环段就位，左 / 中 / 右三轨对齐到 §2.3 的固定 X |
| 4 | 铁堡在**中轨**、上半屏停稳。这一刻视为玩家已经追上 |
| 5 | 开战：WARNING 字标、名称牌「铁堡」「弹药转运」、血条、换轨计时、武器从第 1 式「高射扇」开始 |

开战前的滑入（草案）：车体沿中轨从画面上沿落到停靠点，时长约 2 秒，**可以受伤**，不开火。不另做地图上的第二辆装饰列车；若接近带需要远处车影，用同一精灵，不要第二套实体规则。

停靠锚点是车体中心，草案 `parkY = 128`。车头朝屏幕下方，车厢向屏幕上方延伸。草案外形约 80×160 时，下沿约在 y = 208，留在上半屏。

血条：开战前 2 秒从左向右填满；来不及填就在开战帧直接满。简单 / 中等是一条红。困难先填红槽再填黄槽，比例见 §7。

WARNING 字标草案显示 1.5 秒。名称牌留到死亡。挑战 Boss 跳到本关时，`seek` 落在已经接好的厂内接近带上，不铺白云，卷轴继续，与第一关挑战 Boss 的接法相同。P24 起调试面板的挑战列表有「2」。标题演示仍只跑第一关。

## 4. 换轨

主战全程换轨，直到主血条被打空。困难过载段继续换轨，时钟改短（§7）。换到哪一条轨**不**推动阶段。

| 项 | 锁定内容 |
|---|---|
| 节奏 | 主战：从上一次停稳到下一次停稳 **10 秒** |
| 窗口结构 | 10 秒内部：输出 → 预告 → 横移。草案 8.1 秒 + 1.1 秒 + 0.8 秒 |
| 预告 | 目标轨亮起（警示色虚线或轨道高亮），约 1.0–1.2 秒。草案 1.1 秒。预告开始时就选定目标轨 |
| 受伤 | 预告和横移**都可以受伤**。换轨不给无敌 |
| 选轨 | 等概率去另外两条。必换轨，不留在当前轨。用关卡 `SceneContext.rng`，禁止 `Math.random` |
| 横移 | 沿水平方向从当前 X 到目标 X，y 保持停靠（冲轨武器除外）。草案 0.8 秒，smoothstep。判定跟着车体 |
| 开火 | 预告期间当前武器继续。横移期间暂停开火。抵达的那一帧算换轨成功，武器序号 +1，然后开新的 10 秒 |
| 死亡 | 预告或横移中被打死：取消换轨，进入死亡 |

从中轨出发，左与右各 50%。从左轨出发，中与右各 50%。从右轨出发，中与左各 50%。允许跨过中轨（左直接到右）。

与「冲轨撞击」互斥：撞击的预告、下冲或返回还没结束时，换轨预告推迟到车体回到停靠点。其它武器不推迟换轨。草案的下冲在输出窗前段就结束，赶在下一轮预告之前。这条推迟留给出以后把下冲加长、和预告叠在一起的情况。

## 5. 武器循环

每次**换轨成功**，攻击式样 +1，到第 8 式之后回到第 1 式。顺序固定，不随机。开战时还没有换过轨，式样是第 1 式。

炮塔被打掉、核心打开、当前在哪条轨，都不改变序号，也不重置 10 秒时钟。

| 序号 | 名称 | 锁定行为 |
|---|---|---|
| 1 | 高射扇 | 车顶 `fan5`，瞄准玩家 |
| 2 | 导弹齐射 | 车厢发射管打出 4–6 发短追踪、然后直线的导弹 |
| 3 | 落弹雨 | 敞篷车厢抛弹，地面先出预警圈，再爆炸 |
| 4 | 侧舷扫射 | 左右机枪扫射，把玩家赶出车底正下方 |
| 5 | 封轨弹墙 | 短时间的固定弹墙，打向相邻轨 |
| 6 | 冲轨撞击 | 沿当前轨短距离下冲，先预告，再回到上半屏 |
| 7 | 三轨火箭 | 左、中、右各一发慢速火箭，直线向下 |
| 8 | 弹链抛射 | 抛出弹药箱；没被打掉就在地面小爆 |

禁止激光、扫射光带、能量柱。困难过载也不补激光。

式样在「抵达新轨」后才切换。因此「封轨弹墙」打完才会换轨，下冲发生在**下一条**轨上，两式不在同一条轨上叠成连招。

干净的 Lv3、简单难度、主炮实际约每秒 20 点时，主战大约 42 秒：打完第 1–4 式，并进入第 5 式约 2 秒。中等约 48 秒，第 5 式能打完大半。困难主战约 55 秒，会进入第 6 式。第 7、第 8 式要主战打得更久（掉火力，或采用 §10 的加血 TBD）才排到。过载段改走三式快循环，不从八式的下一号接下去。若试玩要求简单难度也走完八式，只加主战血量，不改 10 秒，不打乱顺序。

同屏敌弹维持在 `ENEMY_BULLET_CAP`（150）以下。按下面的草案，峰值大约在侧舷扫射，约 50 发量级。

## 6. 各式草案参数

下列数字全部可调。子弹速度写的是乘过 `ENEMY_BULLET_SPEED_SCALE`（0.8）之后的实际速度，除非另注。瞄准弹离玩家近于 `AIMED_MIN_DIST`（48）时沿用现规则，这一发不发射。

### 6.1 高射扇

| 项 | 草案 |
|---|---|
| 预设 | 现有 `fan5`，张角 60°（与百战左炮塔相同） |
| 瞄准 | 玩家 |
| 间隔 | 1.4 秒 |
| 首发 | 开战 0.4 秒（`TIEBAO_FAN_FIRST`）。本文原先只写间隔，P24 选定这个延迟 |
| 弹 | 小弹，实际 120 像素/秒 |
| 枪口 | 两座车顶炮交替。炮塔摧毁后仍从破口射击，武器不因此停掉 |

### 6.2 导弹齐射

| 项 | 草案 |
|---|---|
| 发数 | 5（锁定范围 4–6） |
| 追踪 | 0.55 秒，然后沿当时速度直线。短于现成导弹的 `MISSILE_HOMING_TIME`（1.2 秒） |
| 速度 | 与现成敌方导弹相同，实际 88 像素/秒 |

| 波次 | 一个输出窗两波，落在窗内 0.3 秒和 4.0 秒 |

### 6.3 落弹雨

| 项 | 草案 |
|---|---|
| 每波 | 4 个地面圈 |
| 落点 | 1 个圈的 x 取玩家当时的 x；另外 3 个在下半屏，用关卡 rng，圆心彼此至少隔 48 |
| 预告 | 0.8 秒，代码画的警示圈。预告不致命 |
| 爆炸 | 预告结束的那一帧，半径 26，碰到即死 |
| 波次 | 一个输出窗两波，约 0.4 秒和 4.0 秒开始预告 |
| 外观 | 敞篷车厢落下的炮弹，调色板爆炸色。不是激光 |

### 6.4 侧舷扫射

| 项 | 草案 |
|---|---|
| 枪 | 左舷、右舷各一挺 |
| 扫法 | 左枪从左下 40° 扫到正下偏右 15°；右枪镜像。扫过车底正下方那一列 |
| 弹 | 小弹，实际 120 像素/秒，每 0.08 秒一发，单次扫射约 1.0 秒 |

### 6.5 封轨弹墙

弹墙打在**相邻轨**的 X 上，方向固定向下，不瞄准。

| Boss 所在 | 弹墙位置 |
|---|---|
| 中轨 | 左轨和右轨各一堵 |
| 左轨 | 只封中轨，右轨空着 |
| 右轨 | 只封中轨，左轨空着 |

| 项 | 草案 |
|---|---|
| 一堵墙 | 8 发小弹，纵向间距 18，从车厢高度生成 |
| 速度 | 实际 70 像素/秒，直线向下 |
| 次数 | 一个输出窗两堵（或左右同时的那一组算一次），间隔 1.6 秒 |

远处那条非相邻轨是让出的空位。

### 6.6 冲轨撞击

| 项 | 草案 |
|---|---|
| 预告 | 0.5 秒，当前轨高亮，车头警示条闪。预告不位移 |
| 下冲 | 沿当前轨，车体下沿下探到 y = 300，时长约 0.45 秒 |
| 返回 | 回到 `parkY`，时长约 0.55 秒 |
| 伤害 | 车体判定在预告、下冲、返回全程都在。不另发射弹 |
| 次数 | 一个输出窗 1 次，进入该式约 1.0 秒后开始预告 |
| 换轨 | 这一式没回到停靠点之前，不开始下一次换轨预告 |

下探停在画面中部，不到玩家出生高度（`PLAYER_SPAWN_Y` = 560）。

### 6.7 三轨火箭

| 生成 | y = −16 |

## 7. 阶段、血量、分数

阶段看血，不看轨道。

主战是一段连续战斗：换轨和八式循环从开战跑到主血条结束。部位只决定「子弹扣在谁身上」和外观，不切换武器表。

| 顺序 | 部位 id 建议 | 基础血量 | 分数 | 何时能打 |
|---|---|---|---|---|
| 先 | `roofCar` 后车厢顶炮 | 140 | 5000，打掉即给 | 主战开始就能打。两门可同时打 |
| 先 | `roofLoco` 车头顶炮 | 140 | 5000，打掉即给 | 同上。打掉一门不提高另一门射速 |
| 后 | `core` 车头核心 | 560 | 30000 | 两门车顶炮都毁了之后 |
| 困难追加 | 过载段，仍是 `core` | 240 | 上面的 30000 留到这一段被打掉 | 仅困难，主战核心清空之后 |

主战血量合计 **840**。分数合计 **40000**（两门炮各 5000，核心 30000），与百战同一量级。核心在车顶炮还活着时不扣血。车顶炮毁到核心打开没有无敌，子弹马上改扣核心。外观上座圈破开、冒烟即可。

打在车体上的玩家子弹和追踪导弹记入当前存活弱点（还活着的车顶炮里较近的一门；两门都毁后是核心）。不要求先打到圆心。车体外掠过的子弹不消失。

部位沿车长方向前后放，避免为了左右各一门把车身加宽。草案偏移相对车体中心，y 向下为正：`roofCar` (10, -46) 半径 14，`roofLoco` (-10, 22) 半径 14，`core` (0, 50) 半径 18。

| 难度 | 主战血量 | 过载 | 主战时长（约每秒 20 点，不含入场） |
|---|---|---|---|
| 简单 | 840 | 无 | 约 42 秒 |
| 中等 | 840 × 1.15 = 966 | 无 | 约 48 秒 |
| 困难 | 840 × 1.30 = 1092 | 240 × 1.30 = 312 | 主战约 55 秒，过载约 16 秒 |

简单和中等：主战核心归零 → 死亡 → 过关。困难：主战核心归零不给 30000，也不死，进入过载。

### 7.1 困难过载

与百战的困难第三阶段同一条结构：主条打空之后的额外血段，简单和中等不进入。

| 项 | 内容 |
|---|---|
| 切换 | 草案 1.2 秒，全战斗只有这一段无敌。屏幕上的敌弹改成每颗 10 分。切换期间炸弹不结算。6 秒换轨钟从无敌结束、落弹雨开始时起算 |
| 血条 | 与百战相同的双槽：左边红槽按 840 / 1080，右边黄槽按 240 / 1080，中间白分隔。主战扣血时黄槽保持满。过载开始后红槽空，只掉黄槽。`bar: 'extra'` |
| 换轨 | 继续换，停稳间隔改为 **6 秒**。草案内部：输出 4.6 秒，预告 0.8 秒，横移 0.6 秒。仍可在预告和横移中受伤 |

| 结束 | 过载血量归零 → 给 30000 → 死亡 |

### 7.2 炸弹与受击

炸弹沿用现成结算，不另写比例。`prepareBossConfig` 先按难度乘血，`createBoss` 的 `fightMax` 等于部件血加上本局会打的过载段，伤害是 `round(fightMax × BOMB_BOSS_RATIO)`。简单没有过载段，8% × 840 = 67，与百战主战相同。中等和困难跟着乘过的 `fightMax` 走。车顶炮阶段由还活着的炮塔平分；只剩核心时全部扣在核心上。

| 时机 | 能否扣血 |
|---|---|
| 入场滑行 | 能 |
| 换轨预告、换轨横移 | 能 |
| 车顶炮毁、核心接上的那一帧 | 能 |
| 冲轨全程 | 能 |
| 困难过载的 1.2 秒切换 | 不能 |
| 死亡动画 | 战斗已结束 |

车体碰到玩家判定点即死，规则与百战船体相同（空中大型 Boss）。
