## 3. 入场（可玩，不锁操作）

玩家在整段入场里保持移动、射击和炸弹。

| 步 | 锁定内容 |
|---|---|
| 1 | 陆地B 道中收束。道中刷怪在接近开始时停止。`warningAt` 占位 118 秒 |
| 2 | 卷轴把厂房卷进画面。不走第一关那套 5 秒星空云层 |
| 3 | 厂内循环段就位，三轨对齐到 §2.3 |
| 4 | 铁堡在**中轨**滑入并停稳。停稳时看见的是车尾，不是整列 |
| 5 | 开战：WARNING 字标、名称牌「铁堡」「弹药转运」、血条、换轨计时、武器从中轨 A 式「炮塔追扫」开始 |

滑入约 2 秒，**可以受伤**，不开火。尾梁从画面上方（`TIEBAO_ENTER_TAIL_Y` = −12）落到遭遇尾梁（y = 160）。9 节车列的中心从 `enterY` = **−432** 落到 `parkY` = **−260**。`parkY` 是开战歇脚中心，不是终态中心。

遭遇窗口：尾梁 y = 160，再向上 2.5 节（200 像素）。半节（40 像素）还在 y = 0 上面，画面里大约两节车厢。机车鼻大约在 y = −680。

终态（机车 + 2 节，高 280）的鼻停在屏幕 y = **48**，中心 `TIEBAO_END_PARK_Y` = **188**，尾梁 y = 328。那是剥到 ≤30% 之后的位置，不是开战位置。

血条：开战前 2 秒从左向右填满。简单 / 中等是一条红。困难先填红槽再填黄槽，比例见 §7。

WARNING 字标显示 1.5 秒。名称牌留到死亡。挑战 Boss「2」的 `seek` 落在已经接好的厂内接近带上（`TIEBAO_ENTER_AT` = 123），不铺白云，卷轴继续。标题演示仍只跑第一关。

## 4. 剥厢

主血条按剩余比例剥车厢。困难的第二血条不剥。

| 项 | 锁定内容 |
|---|---|
| 车列 | 机车 + 9 节。每节间距 80（车身 72 + 钩缝 8）。机车段 116（尖头加驾驶室）。尾梁余量 4 |
| 命中盒宽 | 80。高度 = 116 + 节数 × 80 + 4。9 节是 **840**，终态 2 节是 **280** |
| 阈值 | 主血剩余 **90 / 80 / 70 / 60 / 50 / 40 / 30%** 各剥正好 1 节后车。同一帧跨过几档，就一次剥几节 |
| 表现 | 被剥的那节在它的歇脚位置爆一次（中爆炸）再加两团碎片（小爆炸）。同一帧跨过几档，爆炸一次放完。画在那节上的顶座随裁切消失 |
| 演出 | 爆炸当帧就把这几节从车尾裁掉，车头留在原处，前面的车厢不往上补进空档。剥厢爆炸用 `TIEBAO_SHED_BLAST_FRAME` = 0.08 秒/帧（中爆炸 6 帧共 0.48 秒，碎片 4 帧共 0.32 秒；别的爆炸仍是 0.06 秒/帧）。然后停 `TIEBAO_SHED_DELAY` = 1.2 秒，玩家尾焰加到 `TIEBAO_CHASE_FLAME`（0.35，大约长 60%）。中爆炸在 0.48 秒结束，剩下约 0.72 秒车列落稳，尾焰才收回。剩余车列用 `TIEBAO_SHED_SLIDE` = 0.4 秒/节向下挪到这一列的歇脚位。一节大约下降 104（车节 80 + 尾梁推进 24）。落稳才是正常交战姿态。死亡、入场滑入、困难第二血不播这段，直接落到终态 |
| 推进 | 每剥 1 节，落稳后尾梁比上一列低 24，车列跟着进入画面。≤30% 时鼻在 y = 48，画面上是完整的机车 + 2 节。歇脚坐标不改，变的是到达的时机 |
| 终态 | ≤30% 之后不再剥。简单 / 中等把这一条血打到 0，然后死亡、通关 |
| 困难 | 第一条血走同一条剥厢曲线。这条血打空之后，第二条血是过载（§7.1），仍是机车 + 2 节，不再剥 |
| 入场 | 滑入时按当前血量直接取节数，不补爆。爆炸留到开战之后的第一次结算 |
| 死亡 | 若还没剥到终态，死亡帧把剩下的节一次剥完，再把车心放到终态中心，然后走 §8 的爆炸 |

几何（未乘难度；难度只乘血，不改这些 y）：

| 剩余主血 | 已剥 | 还挂着 | 命中盒高 | 尾梁 y | 车心 y |
|---|---|---|---|---|---|
| 100% | 0 | 机车+9 | 840 | 160 | −260 |
| 90% | 1 | 机车+8 | 760 | 184 | −196 |
| 80% | 2 | 机车+7 | 680 | 208 | −132 |
| 70% | 3 | 机车+6 | 600 | 232 | −68 |
| 60% | 4 | 机车+5 | 520 | 256 | −4 |
| 50% | 5 | 机车+4 | 440 | 280 | 60 |
| 40% | 6 | 机车+3 | 360 | 304 | 124 |
| ≤30% | 7 | 机车+2 | 280 | 328 | 188 |

命中盒是剩下的整列（含画面外的部分），不是只包屏幕里那 2.5 节。纯几何在 `systems/tiebaoShed.ts`。

两门真枪留在机车和紧挨机车的第二节车厢上（终态的后节）。每一节车厢另有至少一座可见炮座，画在该节上，剥厢时随裁切消失。

## 5. 换轨

主战全程换轨，直到主血条被打空。困难过载继续换轨，周期相同。换到哪一条轨不推动阶段，也不改剥厢。

**作废：**「并轨的 1.2 秒里车体留在旧轨，动画结束的那一帧 X 跳到新轨」。整列瞬移、单帧把 `boss.x` 从一条轨跳到另一条，都不再允许。

**同时作废：**把整列长贴图按横条错位剪切（车体被拧成一条 S 形橡皮筋）。道岔曲线留下，画法换成刚性分节。下面这一条替换这两条旧读法。

| 项 | 锁定内容 |
|---|---|
| 节奏 | 输出窗口仍是 4.8 秒。邻轨一轮 **6.7 秒**，左↔右一轮 **8.6 秒**。主战和困难过载同一套。原来的 6 秒是 `TIEBAO_SWITCH_PERIOD`（输出 4.8 + 基础走岔 1.2），走岔加长之后不再当作实际停稳间隔 |
| 窗口 | 输出 4.8 秒，然后沿道岔走。邻轨 `TIEBAO_MOVE + TIEBAO_MOVE_EXTRA` = 1.2 + 0.7 = **1.9 秒**。左↔右是邻轨时长的 **2 倍 = 3.8 秒**，不是再加 0.7。预铺不加时：提前量仍是距离 `TIEBAO_SWITCH_LEAD` = 64。跨度和预铺不改，u 仍从 0 走到 1，车还贴在同一条岔股上，只是更慢 |
| 预告 | 不点亮目标轨，不画轨道高亮，不给轨端光点，不闪预警。目标轨在并轨开始的那一帧才选定 |
| 股道 | 三条直轨是造好的股道，并轨时也不许扭弯、抽断、或用曲轨盖住改形。直股笔直穿过道岔。岔股是另铺的钢轨 |
| 背景 | 道岔是叠上去的固定几何：尖轨从股道分出，曲轨／导曲线走到辙叉，辙叉汇入目标股道。曲轨用 `tiebaoClosureX`，和车同一条曲线。贴在股道上的像素不画，画完再把三条股道的钢轨按直线盖回去。没有高亮、没有预警闪 |
| 留存 | 并轨一开始就铺下这段道岔。进行中它跟车共用的带子走，所以轮子在画出来的钢轨上。换完或取消的那一帧钉在当时的世界坐标，之后只加厂景卷轴，不再跟着车。整段顶边出了屏幕底再回收。可以同时留着好几段。不淡出、不瞬删 |
| 同一条路径 | 车和岔股共用 `tiebaoSwitchX` / `tiebaoSwitchBand`（也就是 `tiebaoClosureX`）。禁止轨一条曲线、车另一条 |
| 刚性分节 | 车头、每一节装甲厢各自是刚性矩形，从现有长贴图上裁对应的行。废除横条剪切。每节取轨上的前端点和后端点，车身放在两点中点，按切线轻微旋转。弯里看得见折线铰接，像素不变形 |
| 转角 | 封顶 `TIEBAO_CAR_MAX_BANK` = 25°。弯再急也只转到这个角，不拧皮、不剪切 |
| 直轨 | 全列同一个 X，角度 0。直轨时仍是一整张裁切，不逐节转 |
| 剥厢 | 剩几节画几节，和 N=9 的剥厢一致 |
| 完成 | 整列都在新轨上才算换完，然后目标轨的停稳次数 +1，按 §6 换式。邻轨 1.9 秒、左↔右 3.8 秒结束时尾梁走到新轨，不另加等待 |
| 跨度 | 邻轨 `TIEBAO_SWITCH_SPAN` = 240（从 176 略加长，弯更缓、转角更小）。左↔右复式 `TIEBAO_SWITCH_CROSS_SPAN` = 480，路径经过中轨 180，不许从空中飞过去 |
| 扫过 | u = 0 时辙叉跟在车头前方 64 像素，整列还在旧轨。u = 1 时整列已在新轨。长车列车头在画面外，不能把 1.9 / 3.8 秒的大部分耗在屏外：前 `TIEBAO_SWITCH_RUSH`（0.22）只把辙叉送到屏幕上沿，剩下的时间才让可见尾段和这段道岔走完。车头已经在画面里的短列仍按线性扫过。这不是跳变，也不是为了无敌把变轨取消 |
| 判定 | 停稳时每节刚性盒拼成当前轨上的一整列。并轨时每节一只轴对齐盒，包住该节转过的矩形，不用连续斜切条冒充车体。灯、车顶炮、核心光和枪口贴在所属那一节上，跟该节同一个平移和转角，不再按部件自己未旋转的 y 去曲线上取 X。`boss.x` 是车列中心 y 的曲线 X，并轨时不再拿它当唯一命中盒 |
| 必换 | 等概率去另外两条，不留在当前轨。用关卡 `SceneContext.rng` |
| 受伤 | 并轨全程无敌：不扣血、不剥厢。落稳（回到输出）后再扣血、再剥。子弹打在车体上仍会消失 |
| 开火 | 并轨期间暂停开火 |
| 死亡 | 并轨中打不掉血，所以不会在走岔途中被打死。落稳之后再死，按已经停稳的式样进入死亡。若死亡或困难过载的无敌切换正好发生在并轨中，仍取消这次换轨：尾梁收到当时更近的那条轨上，车列在这一帧收直，不增加该轨的停稳次数。已经铺下的道岔留在地上，随卷轴离开 |
| 冲轨 | 下冲或返回还没结束时，不开始并轨。剥厢的停顿或下移还没结束时，也不开始并轨，避免演出和道岔叠在一起。其它武器不推迟换轨。一个输出窗只冲一次 |

从中轨出发，左与右各 50%。从左轨出发，中与右各 50%。从右轨出发，中与左各 50%。允许左直接到右。左到右走复式道岔，先收到中轨再收到另一侧，不走一条飞过中轨的斜线。

## 6. 武器循环

废除全局 1→8。主战六式绑在三条轨上。每次**换轨成功**（整列都进入新轨的那一帧），只给**目标轨**的停稳次数 +1，然后打该轨的下一式。奇数次是 A，偶数次是 B。换轨失败、死亡或过载切换取消，都不加这次次数。

开战停在中轨、还没换过，中轨已经算第 1 次停稳，式样是 A：**炮塔追扫**。第一次成功回到中轨是第 2 次，改打双联散射 + 追踪导弹。左轨和右轨从 0 起算，第一次成功停上才是第 1 次。

炮塔被打掉、核心打开、剥厢，都不改这条轨的次数，也不重置输出窗口。被剥车厢上的顶座不再绘制。两门真枪的锚点留在机车和第二节。

| 轨 | 第 1、3、5… 次停稳（A） | 第 2、4、6… 次停稳（B） |
|---|---|---|
| 左 72 | 侧舷扇扫（`sweep`） | 舷炮排射（`volley`） |
| 中 180 | 炮塔追扫（`turret`） | 双联散射 + 追踪导弹（`twin`） |
| 右 288 | 尾抛轨雷（`mines`） | 冲轨撞击（`ram`） |

括号里是 `TIEBAO_MODE_IDS` 的代码名，中文名是 `TIEBAO_MODE_NAMES`。每条轨一个主题：左轨侧舷火力（扇面把人赶出车底 / 斜线把人逼回车底），中轨车顶炮（追着人扫 / 钉住再用导弹逼走），右轨车尾与轨面（轨道变危险 / 整条道变危险）。

| 式样 | 锁定行为 |
|---|---|
| 侧舷扇扫 | 可见节两侧枪口各扫出一片扇面，三扫，把玩家赶出车底正下方 |
| 舷炮排射 | 可见各节两侧从前往后依次朝外下方斜射，连成斜线；每排后尾梁补一发瞄准弹。不瞄准的斜线三排 |
| 炮塔追扫 | 车顶炮一股弹流，首发瞄准，之后带转速上限追玩家；每扫后从玩家一侧舷口补一把三发小扇。炮塔被毁仍射击 |
| 双联散射 + 追踪导弹 | 每拍三组「三向 × 两发并排」，两舷交替；拍与拍之间各放一对短追踪导弹 |
| 尾抛轨雷 | 尾梁抛出看得见的弧线，雷落在轨面上变成敌弹，沿轨下滑，引信到点向左右横爆。第 1、3 抛封另外两条轨，第 2 抛落在本轨 |
| 冲轨撞击 | 0.9 秒车体预警（§7.6），然后沿当前轨快冲到屏幕底沿 y = 640，再慢退。一个输出窗一次。开战（9 节）起就真冲 |

**三轨火箭**和**弹链抛射**退出战斗。主战和过载都进不去这两式。过载仍会按 §8.1 额外掉弹药箱，那不是弹链抛射这一式。旧六式里的高射扇、导弹齐射、落弹雨、侧舷扫射、封轨弹墙已由上表取代，代码里不再保留。

禁止激光、扫射光带、能量柱。困难过载也不补激光。新六式全是实弹。

式样在抵达新轨后才切换。并轨途中仍显示离开那条轨的式样，但是停火。冲轨是右轨的 B 式，所以下冲发生在右轨上。

**共用节拍（锁定）。** 输出窗口 4.8 秒，六式按同一张拍子排，时刻是到站后的最终秒数，不再乘倍率：

| 段 | 时刻 | 内容 |
|---|---|---|
| 起手 | 0 – `TIEBAO_TELL`（0.4）秒 | 车身上的像素动作，说明这一站打什么。不出弹，不用字幕。冲轨没有起手，它的 0.9 秒预警就是起手 |
| 三拍 | `TIEBAO_BEATS` = 0.5 / 2.0 / 3.5 秒 | 每拍出弹不超过约 0.9 秒 |
| 收枪 | 最后出弹 ≤ `TIEBAO_LAST_SHOT`（4.2）秒 | 之后至少 0.6 秒空白，再并轨 |

起手只在到站之后出现，不预告下一条轨，和 §5「目标轨不预告」不冲突。已经飞出的敌弹在并轨期间照常飞。轨雷的横爆最晚约 4.65 秒，仍在输出窗口内。

| 式样 | 起手（0–0.4 秒） |
|---|---|
| 侧舷扇扫 | 可见节两侧枪口 2×2 口焰闪两下 |
| 舷炮排射 | 可见各节侧面炮门从前往后依次亮一格（和开火顺序一样） |

| 尾抛轨雷 | 尾梁抛射口亮，一颗雷在尾梁上露头 |

**枪口（锁定，扩大到全部六式）：** 每一发都贴在所属车节上，跟该节同一套平移和转角（`tiebaoRowMount`）。不从车外空白或屏幕上沿凭空出现。炮位在画面外（屏幕 y ≤ 8）时改用当前看得见的那一节（`visibleMuzzleRow`），避免子弹在画面外被清掉。

| 发射点 | 用在 |
|---|---|
| 可见节左右边 ±18（`TIEBAO_SIDE_MUZZLE_X`，36 像素厢体的半宽） | 侧舷扇扫、双联散射、炮塔追扫的收尾扇（取玩家那一侧） |
| 排射各节的左右边 ±18 | 舷炮排射：车心屏幕 y 在 0–`TIEBAO_VOLLEY_CAR_MAX_Y`（400）之间的可见节，最多取最靠车尾的 `TIEBAO_VOLLEY_CARS`（3）节 |
| 车顶炮座中线 | 炮塔追扫：两门顶炮按拍交替（第 1、3 拍后车厢行 240，第 2 拍机车行 64）；该门在画面外时用可见节中线 |
| 导弹管 ±28（`TIEBAO_MISSILE_X`） | 追踪导弹，左右交替，在可见节上 |
| 尾梁中线 | 舷炮排射的尾梁点射、尾抛轨雷的抛射口 |

同屏敌弹维持在 `ENEMY_BULLET_CAP`（150）以下。
