## 0. 这一关在做什么

玩家从航母甲板弹射出去，打穿护航舰群，飞过一段安静的开阔海，然后撞上不像地球武器打出来的残骸。Boss 黑曜是这支舰载航空队的末代王牌，仍然是人。玩家把他的血打空之后，不允许按前三关那样爆炸通关：一架巨碟压下来，一发能量柱打散黑曜，碟自己离开。玩家看着，然后去追。

### 1.2 为什么是航母

第 3 关结束旁白已经把目标说死。本关开场不再从陆地机场起飞。关卡选择和第 3 关通关进入时，自机先停在飞行甲板上，播完弹射起飞（§1.7）才交给玩家。挑战 Boss「4」不播这段，直接出现在敌舰甲板。`s4_open` 的「航母甲板就绪。电雷，出击。」接的是上一句「准备舰载出击」，中间用现有 3 秒字卡「第四关」「航母出击」接上，不另写一句过场字幕。

海上的敌人是叛军最后一支地球军武：开场甲板是出击的跑道，中段是护航舰群，Boss 场是黑曜所在的舰空。循环段再看到甲板，读的是王牌头顶的飞行甲板，不是把开场那一艘倒带重放，也不是船坞室内，更不是星空。

### 1.3 为什么中途出现残骸

第 2 关的打捞物、第 3 关缴获的航母坐标，在第 4 关后半落到画面上。第 7 块海图在 **96 秒**从屏幕上方进入，海水仍是同一套白天的水，金属和焦痕换成冷色。旁白 `s4_wreck` 只负责说「弹痕不像地球武器」。残骸不是新的战斗机种类：地块打不到，漂浮物是道具池。

最后兵器是叛军在这片海打捞的外星残骸；黑曜是护送它的末代王牌；碟是来收回残骸的原主，所以只击毁挡在现场的黑曜。这是设定，不是旁白。旁白原文一字不改。

### 1.4 为什么巨碟只毁黑曜、不杀玩家

故事表里的外星人「原主」在这一关末尾现身，来回收残骸。黑曜是地球这边最后的舰载王牌，挡在回收现场上。碟的目标是他：旁白写的是「击毁目标」，不是「击毁你」。

所以：

- 击毁必定发生。碟不因玩家的位置改落点，也不给玩家一个「躲开就打不中」的判定。
- 玩家在这 6.80 秒里无敌，可以移动，不能射击，不能投弹。移动是为了看着碟，不是第二战斗阶段。
- 碟没有名称牌，没有血条，不是第二个 Boss。
- 血空之前玩家被击落，走普通重生或游戏结束，不进入巨碟，也不快进到巨碟。演出里不可能死，因此没有「重播这一段」的入口。

前三关的 Boss 都是玩家打爆的。本关把击杀从玩家手里拿走，转折才成立。血空那一帧若走常规爆炸通关，碟就变成事后字幕，钩子没有了。

### 1.7 弹射起飞（2026-10-28 试玩锁定）

只在第 4 关从 t = 0 进入时播放：关卡选择，以及第 3 关通关后的进关。挑战 Boss「4」从 123 秒切入敌舰甲板，不播。地图预览刮动海面B 不播。重生走原来的屏外飞入，不重播。

顺序锁定：

1. 自机停在飞行甲板上，整机在画面内，不从屏幕下方飞入。x 是画面中线（落在两条划线中间），y 是 `CARRIER_PARK_Y`。
2. 背景卷轴速度是 0。关卡时钟停在 0，预警和 Boss 入场仍按 `40 * t` 对齐。
3. 画面左侧是舰载起步灯，五盏自上而下点亮，像素块，只用 48 色调色板。
4. 灯灭之后：尾焰从冷机渐强，自机沿弹射道向前冲到 `CARRIER_RELEASE_Y`，卷轴按 40 像素/秒开始。前冲是三次加速（起步极慢，到释放点最快），不是匀速。尾焰强度跟速度走，不跟时间走。
5. 冲刺结束才可以移动、射击、投弹。点灯和冲刺期间忽略摇杆、A、B。

| 常数 | 当前值 | 说明 |
|---|---|---|
| `CARRIER_LIGHTS_TIME` | 3.0 秒 | 灯不加时。间距 `CARRIER_LIGHT_STEP` 0.48 秒，点完保持到灯时结束 |
| `CARRIER_LIGHT_COUNT` | 5 | 锁定盏数 |
| `CARRIER_RUSH_TIME` | 3.2 秒 | 上一轮 1.2 秒。整段多出的 2 秒都加在这里 |
| `CARRIER_PARK_Y` | 608 | 精灵中心。32 像素机身仍整架在 640 画面内 |
| `CARRIER_RELEASE_Y` | 224 | 行程 384 像素，是上一轮 192 像素的两倍。32 像素机身占 208–240，仍在屏内，高于顶栏。平时出生点仍是 `PLAYER_SPAWN_Y` 560，重生不改 |

整段 **6.2 秒**（灯 3.0 + 前冲 3.2）。尾焰走现有 `drawEngineFlame` 的推力。点灯时不画尾焰。前冲位置用三次缓入 `u³`：一半时间只走完约 12.5% 的路程，到释放点速度最高。推力用速度 `u²`（三次曲线的导数），从 0 收到 1，`velocityY` 同步为负，火焰跟着变长。冲刺结束回到巡航推力。灯亮期间时钟和卷轴继续冻结。挑战 Boss「4」、地图预览、死亡重生仍不播。

## 3. 地图背景思路

海面B 和黑曜舰空已画在 `seaB.ts` / `obsidianBoss.ts`。黑曜主战和巨碟演出已进代码。本节仍未做的是道中波次、副炮实弹和漂浮物实体。地块像素只用 48 色调色板索引。云影规则与现有海陆图相同：贴左右边，不放屏幕中央从上进入的云，不旋转 90°。

### 3.1 为什么是这个颜色

炉心试玩的教训是 Boss 场比道中突然暗一档，玩家以为切了关。本关把同一件事提前写成测试，不放到画完再改。

开阔水用 `ocean` / `oceanB`（102–103）：海军蓝底上的深浅色块，不成整行细横线，也不铺一行白沫。`water` / `waterB` 的像素不改，河流A 和前三关的水道保持原样——那是一条窄河，不是整屏海。烘焙的地块本身不动。`seaSwell.ts` 在卷轴上另画断续浪：浪峰是浅水蓝、约 2 像素高，带白沫帽；浪谷是深水、约 3 像素高；白沫是 2×2 点。颜色和粗细停在试玩认可的对比度，不再整体加亮。浪不是一把等距尺子：主浪峰基准 56 像素，另一条浪峰 88，浪谷单独 74，白沫点基准 72。每一条再按族号和波序号做 ±10 像素相位抖动，大约五条里空一条。一条浪峰是 1–3 段短横（每段 3–7 列），中间留空，不横贯整屏。白沫出不出、出在哪一列，也由这套哈希决定，相邻两条的密度不一样。哈希不吃屏幕坐标，所以浪形跟着相位走，不会逐帧闪；同一卷轴和时刻重画相同。主浪峰屏幕位移仍是卷轴的 0.18 倍，再加每秒 36 像素。只落在开阔水上，不涂甲板、舰体、残骸、炮位和敌舰甲板。本关的「亮色日间海战」仍是这套蓝，不另铺黑夜。

甲板可以比海水更亮。混凝土和白划线在日光下，读成飞行甲板。暗下去的是金属碎片的灰，不是把海水换成黑色。淡青 9 只做点缀，玩家青 10–13 不做碎片主体。黑曜机体本身是深色金属，叠在亮甲板上才有剪影。不要为了迁就机体把海图涂黑，也不要把机体改成浅灰。

残骸和巨碟用同一套冷金属，让 96 秒的碎片和血空后的碟对得上。地球火黄（调色板 40–43）留给爆炸和地球弹。能量柱以白 7 为主体，淡青 9 只做外缘。

### 3.2 亮度（锁定，画不到就改用色，不放宽比例）

算法与 `src/game/maps/furnaceBoss.test.ts` 相同：把地块光栅的调色板索引按 Rec.709 权重求平均。基准 `Lwater` 是现有 `water` 地块光栅的平均亮度。

| 区域 | 下限 |
|---|---|
| 第 0 块甲板 | ≥ `Lwater` × 0.90。开场不得比这张白天的海更暗 |
| 第 1 块（甲板收到海） | ≥ `Lwater` × 0.85 |
| 第 2 块、第 6 块开阔水 | ≥ `Lwater` × 0.90 |
| 第 7、8 块残骸 | ≥ 第 6 块 × 0.75 |
| 黑曜舰空接近带 | ≥ 海面B 最后 40 行 × 0.85 |
| 黑曜舰空循环甲板 | ≥ 第 0 块 × 0.85 |
| 任何一块 | ≥ `Lwater` × 0.70。低于这一档视为骤黑 |

另两条结构限制，用来保证上面的比例画得出来：

- 新地块不用调色板 0（纯黑）或 1（暗海军蓝）当填色。投影仍走现有 `SHADE`。
- `wreckAlloy` + `wreckBurn` 只铺在第 7、8 块的内部。第 7 块内部非边缘格合计不超过 **18%**，第 8 块不超过 **28%**（草案比例；亮度测试没过时先减面积或换更亮的灰，不改 0.75）。

### 4.2 折线（可读性在这里写死）

黑曜是一架飞机，一个命中盒。开战停在中歇点 x = 180、y = `OBSIDIAN_PARK_Y`（草案 140）。武器圈主战 4.8 秒、过载 3.6 秒，三式各占三分之一，从导弹齐射算起：导弹齐射 → 折线扇 → 掠袭。**只在第二式「折线扇」开始时飞一次**，等概率去另外两个歇点，不留在当前点。主战飞 0.45 秒，过载飞 0.32 秒。折线期间 y 保持 `OBSIDIAN_PARK_Y`，不开火，可以受伤。这条 y 只约束折线。掠袭可以改 y。

开战先在中歇点打完第一轮导弹（1.6 秒）才第一次折线。之后每次落地，要再等一整圈减去这段飞行（主战约 4.35 秒，过载约 3.28 秒）才再飞。这段停留是玩家读位置的时间，不得改成连续折线。

炉心的教训是露弱点的窗口要够打。黑曜没有门，可打的时间是全程，安全输出的时间是停火：

| 项 | 档 | 值 |
|---|---|---|
| 主战折线停火 | 锁定下限 | **不得短于 0.45 秒**。可以加长，不能缩短 |
| 过载折线停火 | 锁定下限 | **不得短于 0.32 秒**。可以加长，不能缩短 |
| 落稳后再停 | 锁定下限 0.12 秒；现行草案 0.15 秒 | 然后才打第一扇 |
| 一式几扇 | 草案 | 第一扇：主战 5 发 44°，过载 7 发 64°。第二拍：主战隔 0.35 秒窄扇 3 发 22°，过载隔 0.28 秒 5 发 40°。折线时长仍不低于 0.45 / 0.32 |

歇点提示，避免画成第二套铁轨，也避免玩家看不出它要飞：

| | 内容 |
|---|---|
| **可有** | 飞行期间机体按现有侧倾转向目标歇点。尾焰用现有引擎火焰，飞行时可以稍长。受击白闪覆盖整机，含飞行中 |
| **禁止** | 在 96 / 180 / 264 画线、画点、点亮落点。地面影子先跳到目标点。整机闪烁。黄圈标成「只有圈内扣血」。给歇点做 UI 准星 |

飞行中的侧倾是主提示。不另做轨道预告。

第三式是掠袭，不再是平行曳光。同一歇点 x 不变，不追玩家，这一式内不再折线。主战 1.6 秒：0–0.30 预兆（尾焰拉长）停火，0.30–0.75 缓入缓出下探 140 → 280 停火，0.75–1.05 到底一梭，1.05–1.60 拉起回 140 停火。过载 1.2 秒按 0.20 / 0.30 / 0.25 / 0.45。到底一梭是中路加外撇，速度 140；过载窗内排不进的轮不发。下探 y 上限 ≤ 320。只在到底段开火。全程可受伤，碰撞照常。和铁堡冲轨分开：掠袭每圈一次，只到上半屏，有预兆，时间短，然后飞回。逐秒和弹参以专文 §5.3 为准。

### 4.3 血量与过载

全身一个部位 `frame`。简单、中等一条红。困难先红后黄，`gate: 'hard'`，`bar: 'extra'`。

| 难度 | 主战 | 过载 | 分数 |
|---|---|---|---|
| 简单 | 1200 | 无 | 40000，主战归零入账 |
| 中等 | 1380 | 无 | 同上 |
| 困难 | 1560 | 468 | 40000 留到过载归零 |

约 40 秒是锁定目标。血量数字仍是草案，不再把「每秒 20 点」当成锁。进代码后按专文 §6，用武器测试场实测 DPS 再反推血量回写。`frame` 半径草案 32，见 §4.5。过载切换 1.2 秒，无敌，停火，敌弹留下，炸弹不结算。入场 1.6 秒可受伤。折线和掠袭可被炸弹打中。血空之后炸弹键无效。

### 4.4 巨碟时间轴与 UI

时钟从血空那一帧起。暂停冻住，恢复后续播，不从头播。底下甲板继续卷。

| t（秒） | 段 |
|---|---|
| 0.00–1.60 | 瘫痪。从血空时的屏幕坐标缓出滑落到 (180, 300)，侧倾加烟，不解体。不再原地冒烟。折线若在半途，从当前坐标滑落，不留在半途 |
| 1.60–3.60 | 碟从 y = −120 降到 (180, 100)。移动 1.6 秒，再停 0.4 秒。直径 208，占 y −4…204。不再停在 148 |
| 3.60–3.85 | 碟心蓄能。还没有柱 |
| 3.85–4.40 | 能量柱，宽 18，从碟心打到黑曜中心。可见空隙约 48，柱长约 200。不伤玩家，不清弹，不进 `FIRE_PRESETS` |
| 4.40 | 黑曜才解体：6 次大爆炸铺 1.2 秒。同时挂 `s4_ufo`。名称牌撤下。碟开始离开 |
| 4.40–6.80 | 碟从 y = 100 匀速升到 y = −140。合计仍是 6.80 秒 |
| 6.80 | 演出结束，才调用 `stepVictoryExit` |

UI 就用已经存在的元素，不新写一句旁白：

| | 内容 |
|---|---|
| **锁定** | 血条留在画面上，槽是空的，不隐藏，不换成碟的血条。名称牌留到 4.40 秒。碟无名称、无血条、无锁定框。射击不生成子弹、不画枪口焰。炸弹键无效。僚机停火，仍无判定，跟着平移。不盖全屏黑。能量柱命中的闪白不超过 2 帧 |
| **可有** | 瘫痪帧的烟、侧倾和熄火的喷口。3.60 秒碟心蓄能点变亮，作为柱的前兆 |
| **禁止** | 把碟做成第二个 Boss。血空之后还在机体上闪黄圈，暗示还能打。演出中途插黑场 |

0 到 4.40 秒没有新旁白。玩家靠「打不出弹、血条已空、名字还在、碟没有血条」读出战斗结束。4.40 秒的 `s4_ufo` 负责说明谁击毁了谁。
