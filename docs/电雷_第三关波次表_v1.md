## 0. 锁定

1. 道中地图只有 **河流A**（`riverA`）。Boss 场 **炉心浮台**（`furnaceBoss`）。
2. `STAGE3_WARNING_AT` = 118，`FURNACE_ENTER_AT` = 123。不引用第 1 关或第 2 关的预警常量。
3. 新敌种只有 `parked_fighter`、`strike`。工厂防空炮是复用。
4. 不改 `hpScale`、`fireRateScale`、`bulletSpeedScale`。
5. 清波奖励和定点补给机不做。保底携带机仍是 `powerBelowMax` 的一架中型，不是补给机。
6. 风险箱时刻写在第 3 关自己的常量里，不指向 `RISK_CRATE_EASY_T` 这一组第一关时钟。
7. 段落标签 `valley` / `dock` / `crossing` / `scorch` 不选地图。
8. 末段焦土只装饰 `lakeRight` 与 `forestHead` 的内部岸，不改边缘契约。见炉心设计 §2.1。

## 3. 两种新模型

### 3.1 停机 `parked_fighter`

| 项 | 锁定 | 草案（实现时微调） |
|---|---|---|
| 体型 | `small` / `ground` | 精灵 32×32，命中半径 14 |
| 血 / 分 | 计入击落率。不开火，不掉落 | 血 8，分 400 |
| 移动 | 新移动 `planted`：锚在地图格，只跟卷轴，自身速度 0 | |
| 地形 | 锚点及机体必须在 `land` 上。不压 feature，不压水，不压区块边缘行 | |
| 生成 | 与建筑相同：地图把锚点卷进画面时生成。预警后不再生成。已经在场上的继续留到被打掉或卷出 | |
| 炸弹 | 小型。屏幕内直接毁，屏幕外不受影响 | |

出场意图：码头段一组 3 架并排，焦土段一组 3 架。困难可以在桥后岸上再加 2 架。简单每组可以少 1 架。具体行号 P33 对着河流A 的陆地格填，并写进测试。

它不是陆地B 上那种没有碰撞的 `PLANE` 地块。地块飞机仍不可打。

### 3.2 重装对地机 `strike`

| 项 | 锁定 | 草案（实现时微调） |
|---|---|---|
| 体型 | `medium` / `air` | 精灵 40×36。不放大小型机，也不直接套轰炸机 |
| 血 / 分 | 计入击落率 | 血 36，分 900 |
| 移动 | 新移动 `strafe` | 见下 |
| 弹幕 | 只在平飞段打一次扇形，之后不再连射 | 5 发大弹，张角约 40°，实际速度约 90。`firstDelay` 约 0.2 秒 |

`strafe`：从屏幕顶外以进入角飞到 `levelY`，沿水平飞 `run` 像素，然后以离开角向下飞出。不悬停，不拉起。机头按当前段的航向转，尾焰留在机尾。y < 8 时不开火，且不计时。`run` 为正往右。

签名读法是「压低、平飞投弹、走」。三次出场都用这个动作，参数可以不同。不和 V 字波同一秒。

| 出场 | 时段 | 意图 |
|---|---|---|
| 第一次 | `crossing` 前段，约 1:08 | 简单 1 架，中等和困难 2 架，左右错开约 1.2 秒。先出的那架可以不掉落 |
| 第二次 | `scorch` 初段，约 1:32 | 三档都有。困难 3 架 |
| 第三次 | 预警前，约 1:46 | 简单可以没有。中等 1 架，困难 2 架 |

架数实现时微调。模型不能换成轰炸机冒充。

## 4. 时段

每一段写签名，不写每一架的 x。P33 把签名拆成波次 id。

| 时段 | 标签 | 谁出现 | 签名 |
|---|---|---|---|
| 0:00–0:20 | `valley` | 小机双列正弦，一波 V 字。一架中型悬停 | 开场压进河谷。中型若主炮未满，这架掉 P |
| 0:20–0:46 | `dock` | 岸上坦克，1–2 门工厂防空炮，海上炮台随地图进入。第一组停机 | 停机可击。炮位不挡河心 |
| 0:46–1:06 | `crossing` | 拦截机侧弧，小机斜穿，少量无人机 | 复用空中。桥面上不放停机 |
| 1:06–1:28 | `crossing` | 第一次对地，一架轰炸机慢推，导弹车一辆 | `strafe` 第一次出场 |
| 1:28–1:54 | `scorch` | 第二、三次对地，小机略密，第二组停机。1:50 附近一架 B 携带。1:54 保底中型 | 焦土前的对地。保底机只在主炮低于满级时生成 |

另有一架 P 携带放在约 0:36 的码头段，一架 B 携带放在约 1:16。T 不从飞机掉，T 走建筑锁。M 走建筑锁和风险箱。时刻实现时微调，种类预算不改：P 两架、B 两架，外加 1:54 的保底。

困难在 0:20 之后的小机上把部分点射从无火改成 `aimed1` 或 `aimed3burst`。中等少改一点。不新做弹种。
