## 0. 锁定

从 v1 原样保留：

1. 道中地图是新图 **海面B**（`seaB`），9 × 40 行。不用河流A 当大海。
2. Boss 场是 **黑曜舰空**（`obsidianBoss`）。
3. `STAGE4_WARNING_AT` = 118，`OBSIDIAN_ENTER_AT` = 123，`STAGE4_WRECK_AT` = 96。
4. 新种类只有 `carrier_bomber` 和建筑 `cruiser_gun`。`wreck_float` 是道具，不是第三种敌机。
5. 不改 `hpScale`、`fireRateScale`、`bulletSpeedScale`。
6. 清波奖励和定点补给机不做。
7. 段落标签 `deck` / `fleet` / `swell` / `wreck` 不选地图。
8. 本关不出坦克、导弹车、工厂防空炮、`parked_fighter`、`strike`、`turret2`。

v2 加锁：

9. 舰载轰炸机只在甲板、舰群、残骸各出场一次。架数 1/1/1、1/1/2、0/1/1。
10. 副炮 6 个放置位都在第 3–5 块。简单和中等生成 5 座，困难生成 6 座。
11. 主炮满级的飞机数以 §9.1 的合计为准：113 / 146 / 178。目标带 110 / 145 / 175，允许 ±15。试玩改动必须回写本表并留在带内。
12. 风险箱只读 §5 的 `STAGE4_RISK_*`。不读其它关的时钟。
13. 每波 `mvp: true`。不把签名轰炸机写成 `mvp: false`。

## 3. 两种新种类

### 3.1 舰载轰炸机 `carrier_bomber`

| 项 | 锁定 | 草案 |
|---|---|---|
| 体型 | `medium` / `air`。计入击落率。`countsInKillRate` 保持默认 true | 精灵 56×48。命中半径 22。不放大小型机，不套 `bomber` 的 60 血贴图 |
| 血 / 分 | | 血 48，分 1000。`scaleHp` 仍适用 |
| 移动 | 复用 `slow_push`。不新做移动。不改 `SLOW_PUSH_ENTER_SPEED`（30）和 `SLOW_PUSH_EXIT_SPEED`（60） | `stopY` = 180，`hold` = 2.0。从屏外到 180 约 7 秒，停 2 秒，再以 60 像素/秒离开 |
| 弹幕 | 只打一轮，然后不再连射。5 发大弹，向下扇形，不瞄准玩家 | 张角 36°，速度 80，`maxShots` 1，`firstDelay` 0.6 |
| 出场 | 三次的时段见 §9.2。先出的那一架（W07）掉 B。后两次不掉 | |

v1 写过「速度约 70」。那个数达不到：`slow_push` 的速度是全局常量，改了会让第 1–3 关的轰炸机一起变快。本表作废「约 70」，停留只调 `stopY` 和 `hold`。

弹幕用一次性 `pattern`，不新增 `FIRE_PRESETS` 行：

```text
shape: fan
count: 5
spreadDeg: 36
aim: down
bullet: large
speed: 80
maxShots: 1
firstDelay: 0.6
```

`aim: 'down'` 是锁定。不要换成 `fan5`，那一式瞄准玩家而且是小弹。

死亡爆用和 `bomber` 同类的两次追加小爆即可，偏移草案 `(-16, -6, 0.06)`、`(14, 8, 0.12)`。

### 3.2 巡洋舰副炮 `cruiser_gun`

| 项 | 锁定 | 草案 |
|---|---|---|
| 种类 | 建筑，`small` / `building`。不计入击落率。炸弹按小型直接毁掉屏幕内的炮 | 精灵 32×32，占 2×2 |
| 地形 | 四格都在 `cruiserGunDeck` 上。该地块掩码是 water，画成炮位，不画炮管 | |
| 血 / 分 | 不改全局 `BUILDING_HP`（现为 3，改了会改前三关房子）。本类单独常量 `CRUISER_GUN_HP` | 血 16，分用现有 `SCORE_BUILDING`（500）。`scaleHp` 仍适用 |
| 炮管 | `BUILDING_BARRELS` 新一行，双管，固定朝下。不走海上炮台的转向 | 每 1.8 秒一组。平行两发小弹，`aim: 'down'`，间距 14，速度 110 |
| 数量 | 放置 6 座，都在第 3–5 块。简单和中等生成前 5 座，困难再生成第 6 座 | |
| 难度字段 | `BuildingPlacement` 增加可选 `difficulties`，语义与 `Wave.difficulties` 相同：省略表示三档都生成。B06 写 `['hard']`。过滤发生在放进调度器之前 | |

不要用 `fixed2`。那一式跟着炮管转向，会读成瞄准激光。本炮不瞄准。

困难不另加岸炮。本关不放 `sea_gun`。

## 5. 掉落与风险箱

副炮按放置顺序 B01 → B06：

| id | 掉落 | 谁生成 |
|---|---|---|
| B01 | T | 三档 |
| B02 | M | 三档 |
| B03 | T | 三档 |
| B04 | 组 `s4-fleet-mate`，物品 M | 三档 |
| B05 | 组 `s4-fleet-mate`，物品 M | 三档 |
| B06 | 省略，走 `BUILDING_DROP_RULES` | 仅困难 |

组的成员顺序就是放置顺序：B04 然后 B05。进关 `floor(rng × 2)` 恰好一座掉 M。没抽中的那座走默认表（主炮未满时 P/B，满级只 B），不是什么都不掉。锁仍然压过默认表。

风险箱：

| 常量 | 值 |
|---|---|
| `STAGE4_RISK_EARLY_T` | 42 |
| `STAGE4_RISK_MID_T` | 68 |
| `STAGE4_RISK_LATE_T` | 92 |
| `STAGE4_RISK_CENTER_X` | 180 |
| `STAGE4_RISK_LEFT_X` | 48 |
| `STAGE4_RISK_MID_X` | 220 |
| `STAGE4_RISK_RIGHT_X` | 312 |

| 档 | 生成 |
|---|---|
| 简单 | 42 秒，x = 180 |
| 中等 | 42 秒，x = 48；92 秒，x = 312 |
| 困难 | 中等两只，再加 68 秒，x = 220 |

92 秒比旁白 96 秒早 4 秒。试玩若要挪箱子，只许改 x 或把 92 再提前，不许把箱子放到 96 秒，也不许改旁白时钟。

和波次错开：W10 在 44 秒，x 为 120 和 280，不占 42 秒的 180 和 48。W17 在 68 秒，x = 120，困难箱在 x = 220。B05 的炮位中心约 x = 252，比箱子晚 1.6 秒进画。若试玩叠在一起，只许挪箱子的 x，B05 的行列不动。W23 在 94 秒，x 为 80 和 160，不占 92 秒的 312。
