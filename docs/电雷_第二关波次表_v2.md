## 3. 移动与弹幕

### 3.1 已有移动

`straight`、`sine`、`v_dive`、`cross`、`hover`、`side_arc`、`orbit`、`slow_push`、`ground`、`rear_diag` 照旧。`straight` 的 `angle` 仍是 0 = 正下方，正数向右。

### 3.2 已有弹幕

不新增弹种。难度不乘弹速，也不改 `fireRateScale`。

本关用到：`none`、`aimed1`、`aimed3burst`、`fan3`、`fan5`、`ring8`、`missile`、`aimed_fast3`，以及工厂防空炮的 `pattern`（平行两发、沿炮管、连发三轮）。W03 的第一次中型也用 `pattern` 打一次 4 发扇形。本关不再使用 `fixed2`。`aimed_fast3` 仍只给困难的低侧弧。

通用规则：y < 8 时不开火，这段时间不推进开火计时。离玩家不到 48 像素时，带 `minDist` 的瞄准弹不发。工厂防空炮的平行弹没有 `minDist`，玩家贴得很近时第二轮仍打。连发的后续轮（`AIMED_BURST_GAP` = 0.12 秒）同样遵守屏外停表；沿炮管的那一轮把 `aimAngle` 传进去，不改去瞄准玩家。

### 3.4 阶梯侧移（`step_slide`）

从出生点起算，不逐步积分。`steps` 次「向下 `drop` 像素，再向侧面 `|run|` 像素」，剩下的距离继续正下方。`run` 为正往右（航向 90°），为负往左（航向 270°），向下时航向 0。`steps` 只允许 1 或 2。1 读作下 → 侧 → 下。

机头朝下的精灵跟着当前这一段的航向转，尾焰留在机尾。x 在 24–336 以外、或 y < 8、或 y > 640 时不开火，而且不计时。

| 参数 | 说明 |
|---|---|
| `speed` | 沿当前这一段走，像素/秒 |
| `drop` | 每一段向下的长度 |
| `run` | 每一段侧移的长度，符号是方向 |
| `steps` | 1 或 2 |

三次出场。不和任何 `v_dive` 同一秒。
