# 《电雷》P12 地图资产说明

P12 把地图从关卡里拆出来，做成注册表里的资产，并重做了第一张图 **陆地A**。本文说明注册表、区块地图的结构、性能做法，以及怎样写一张新地图。

## 1. 地图注册表

代码在 `src/game/maps/`。

| 文件 | 作用 |
|---|---|
| `types.ts` | `TileMapDef`（地块图：`id`、`label`、`rows`、`build()`、`cloudShadows`）和 `StarfieldMapDef`（星空：`previewSeconds`） |
| `registry.ts` | 唯一知道全部地图的地方。`listMaps` / `getMap` / `getTileMap` / `getMapGrid`（网格只生成一次并缓存） |
| `terrain.ts` | 地形掩码：每个地块编号是 `land` / `water` / `feature`。`terrainAt`、`footprintOn` |
| `chunks.ts` | 区块地图：区块定义、种子排序 `planChunks`、`composeChunks`、画区块用的 `ChunkPainter` |
| `landA.ts` | 陆地A 的区块库和槽位表 |
| `track.ts` | 背景轨道：关卡或预览要卷哪些图、从哪个卷动量开始、几秒交接；坐标换算和坦克地形判断 |
| `preview.ts` | 地图预览的列表和轨道 |

现有 4 张图（第一关原来的三段加星空）：

| id | 名称 | 类型 | 来源 | 长度 |
|---|---|---|---|---|
| `landA` | 陆地A | 地块（区块） | P12 重做，原地面段 | 440 行 = 7040 像素 = 176 秒 |
| `landB` | 陆地B | 地块（整张） | 原基地段：围墙、跑道、机库、停机坪，原样 | 192 行 = 3072 像素 |
| `seaA` | 海面A | 地块（整张） | 原海岸段：弯河、石堡、码头，原样 | 160 行 = 2560 像素 |
| `spaceA` | 宇宙A | 星空 | 预警后的 3 层视差星空 | 预览 24 秒 |

### 关卡怎么引用地图

`StageData.maps`：

```ts
maps: {
  run: [{ map: 'landA', at: 0 }],   // 预警前依次使用的地块图，at = 交接时间（秒）
  boss: 'spaceA',                    // 预警后的星空
}
```

`run` 有多张图时，第 i 张（i > 0）提前 `MAP_BLEND_LEAD`（1 秒）开始卷动，在 `at − 1` 到 `at + 2` 秒之间交叉淡入。建筑的 `map` 必须是 `run` 里的一张，否则 `placeBuildings` 直接报错。

## 2. 陆地A

### 区块序列

一个区块是 40 行 × 23 列（一屏高）。区块库有 9 种，每种 2 个变体，种子决定变体、镜像、装饰散布。`LAND_A_SEED = 7`，`planChunks` 排出的序列是：

| # | 地图行 | 卷动时间 | 区块 | 内容 |
|---|---|---|---|---|
| 0 | 0–39 | 0–16 秒 | meadow v0（固定） | 开场草地、树丛、岩石 |
| 1 | 40–79 | 16–32 秒 | farmland v0 | 农田（麦田 / 菜地 / 翻耕地）、田间小路 |
| 2 | 80–119 | 32–48 秒 | hills v1（镜像） | 深色草丘、岩石群、树林 |
| 3 | 120–159 | 48–64 秒 | village v0（镜像） | 十字街、红 / 棕屋顶房屋、广场 |
| 4 | 160–199 | 64–80 秒 | streamStart（固定） | 池塘，小河从这里向上流出（左侧） |
| 5 | 200–239 | 80–96 秒 | streamLake（固定） | 左侧小河加右侧湖泊 |
| 6 | 240–279 | 96–112 秒 | streamEnd（固定） | 小河拐弯、桥、右侧湖泊，河在这里结束 |
| 7 | 280–319 | 112–128 秒 | forest v0 | 大片森林和林间空地 |
| 8 | 320–359 | 128–144 秒 | meadow v1（镜像） | 草地 |
| 9 | 360–399 | 144–160 秒 | crossroads v0（镜像） | 土路十字路口 |
| 10 | 400–439 | 160–176 秒 | village v0 | 村庄（预警加速时已经在屏幕上） |

「卷动时间」是这块底边到达屏幕底部的时间段，它会提前 16 秒从屏幕顶部进入。第一关 150 秒预警时卷动量是 6000 像素，预警加速再走 192 像素，屏幕顶到 6832 像素，没有超出 7040，所以不循环。

### 区块边缘接口

- 主路在每个区块的第 0 行和第 39 行都正好在第 11 列（`ROAD_COL`）。区块中间可以左右摆动。
- 小河在边缘只能出现在左侧 2–4 列、右侧 18–20 列，或者不出现（`StreamSide`）。区块声明自己的 `bottom` / `top`，镜像时左右对调。
- 其他东西都不能把路或水画到区块的上下边缘行上。
- `planChunks` 只把边缘接口一致的区块排在一起，并且会看下一个固定槽位，保证固定区块接得上。排不出来直接报错。
- 测试会检查每种区块、每个变体、镜像与否、多个种子都满足这个接口，并检查陆地A 每条接缝两侧的路列和水列一致。

### 画法

- 全部是代码按 48 色调色板逐像素画的，没有图片文件。
- 地块（`art/tiles.ts`）：新增 26 个陆地地块（编号 33–58），旧的 33 个地块原样保留，所以海面A、陆地B 像素不变。
- 栅格化（`art/mapRaster.ts`）：按邻居做自动拼接（道路、街道、湖泊、桥、森林、农田边缘），水边自动画一圈沙。光从左上来：树冠、屋顶、岩石这些「立起来」的像素向右下 3 像素投影，投影颜色走调色板的暗一档（`SHADE`）。区块上方多算一行，影子和邻接能跨过区块接缝。
- 云影：陆地A 设了 `cloudShadows`，画 3 片半透明椭圆，比地面卷得稍快。

## 3. 性能

- 地图从不整张烘焙。每个区块第一次要用时烘焙成一张 368×640 的离屏画布（约 0.9 MB），放进 `MAP_CHUNK_CACHE` = 4 张的 LRU（`art/mapDraw.ts` 的 `ChunkCache`）。
- 每帧每张可见地图只 `drawImage` 屏幕上的 1–2 个区块；第一关预警前只有陆地A 一张，所以是 2 次。云影再加 3 个椭圆填充。
- 下一个区块分帧预烘：每帧 4 行地块（`MAP_PREFETCH_ROWS_PER_FRAME`），约 11 帧烘完一块，而一块要 16 秒才卷完，所以正常卷动不会在某一帧里一次烘整块。只有完全不透明的图才预烘，交叉淡入时不会同时烘两张图。
- 进入战斗的第一帧会同步烘焙屏幕上的区块。

## 4. 地图预览

调试面板（首页右上角 48×48 热区，2 秒内点 6 下）→「地图预览」→ 选一行。

- 列表：陆地A、陆地B、海面A、宇宙A、第一关全程、返回。新注册的地图和新关卡会自动出现在列表里。
- `playMode: 'mapPreview'`，规则在 `battle/playMode.ts` 的 `PLAY_MODE_RULES`：`scroll: true`、`spawns: false`、`track: 'preview'`、`leaveAtTrackEnd: true`。场景里没有针对这个模式的字符串分支。
- 只有自机，可以移动、射击、暂停。没有波次、敌人、建筑、预警和 BOSS。不写战报和最高分。
- 结束时间：地块图到最后一行顶到屏幕上沿（陆地A 160 秒）；宇宙A 24 秒；第一关全程到 `warningAt`（150 秒）。结束后自动回首页。暂停菜单「返回标题」直接回首页。

## 5. 怎样写一张新地图

1. **地块**：需要新地块就在 `art/tiles.ts` 的 `TileId` 末尾追加编号、更新 `TILE_COUNT`，在 `paintLandTiles` 里用调色板画出来。会立起来投影的像素记进 tall 掩码。
2. **地形**：在 `maps/terrain.ts` 把新地块归到 `LAND` 或 `WATER`；不写就是 `feature`（建筑不能压，坦克能开）。
3. **区块库**：照 `maps/landA.ts` 写 `ChunkDef[]`。每个区块用 `ChunkPainter` 画（`meadow`、`mainRoad`、`stream`、`blob`、`house`、`scatter`……），声明 `bottom` / `top` 的小河接口，遵守第 2 节的边缘规则。
4. **槽位表**：写 `ChunkMapSpec`：`slots` 里固定槽 `{ fixed }` 或候选槽 `{ pick: [...] }`，`seed`、`maxRepeats`。长度 = 槽位数 × 40 行。
5. **注册**：在 `maps/registry.ts` 写一个 `TileMapDef`（`build: () => composeChunks(SPEC)`），加进 `MAPS`。只想要整张手写的图也可以，`build` 返回任意 `TileGrid`，行数要等于 `rows`。
6. **关卡**：在关卡的 `maps.run` 里引用它；建筑的 `map` 写这张图的 id，行列放在地形对的位置。
7. **测试**：`maps/maps.test.ts` 会检查注册表、序列确定性、接缝；建筑测试检查每座都在对的地形上。新图需要的话补一条自己的测试。
8. **预览**：打开「地图预览」看一遍。

## 6. 陆地B / 海面A / 宇宙A 还没做的

- **陆地B、海面A**：还是 P4 的整张生成（`buildBaseMap` / `buildCoastMap`），没有拆成区块，也没有投影、云影、自动拼接；第一关不再使用，只在地图预览里能看到。重做时按第 5 节写区块库，补海面专用的区块接口（海岸线、码头、桥），再决定哪一关用它们。
- **宇宙A**：仍是代码生成的 3 层视差星点，没有星云、行星、陨石等远景，也还是由预警时间驱动淡入。
- 4 张图都还没在真机上测过性能。
