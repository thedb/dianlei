## 1. 总评

这一关的骨架立得住，而且是五关弧里最有戏的一关。前三关的 Boss 都是大机器（要塞、列车、浮垒），第 4 关第一次是一个「人」开的飞机。把玩家亲手打空的血条交给巨碟收割，「人打到末代王牌，巨碟夺食」的转折靠机制成立，不靠字幕。安静的开阔海接冷色残骸，再接王牌，这段节奏也对。弱点集中在三处。第一，黑曜的武器组几乎逐项照抄炉心（导弹 5 发、5 发大弹扇、2 路平行向下，过载圈同为 3.6 秒），三歇点又像铁堡三轨，「王牌」只剩名字。第二，巨碟锁定构图（碟停 y = 148、直径 208，黑曜在 y = 140）会让碟把黑曜整个盖住，最关键的一帧看不见。第三，开场我方甲板和 Boss 场敌方甲板是同一套图，玩家分不清「出击的船」和「王牌的船」，「末代」也没有画面上的证据。这三处改掉，叙事和雷电味都会更硬。其余多是数值口味，可以进代码再调。

## 2. 保留清单

| 项 | 为什么留 |
|---|---|
| 血空后禁止常规爆炸，巨碟五段 6.80 秒，玩家无敌、可移动、不能射击 | 转折靠「把击杀从玩家手里拿走」成立。可移动不可射，玩家就只能看着，正好是要的情绪 |
| 血条留空槽、名称牌留到 4.40 秒、碟无名无血条 | 「打不出弹 + 血条已空 + 名字还在」就能让人读懂战斗已结束，不用新旁白。这是全案最聪明的 UI 决定 |
| 40000 分在血空那一帧入账 | 分数是玩家挣的，碟抢走的是击杀，不是战果。不要改 |
| 碟往上离开，玩家通关也往上飞出 | 和「追踪」同向，下一关的钩子是动作给的 |
| 血空前被击落走普通重生；巨碟不是存档点；同一帧血空优先 | 规则闭合，没有「重播演出」的入口 |
| 全身一个 `frame`，没有门，不画轨，不点亮歇点 | 和炉心的「开合门」、铁堡的「轨」从机制上分开。整机白闪就是唯一的受击语言 |
| 折线停火下限 0.45 / 0.32、落稳后再停 ≥ 0.12 | 把炉心「窗口要够打」的教训换成了飞机的说法：安全输出窗口是停火，不是门 |
| 困难黄槽、座舱改警示黄 | 黄色过载是百战、铁堡、炉心一路用下来的通用语言，不算抄炉心。保持一致更好读 |
| 战斗无激光，能量柱不进 `FIRE_PRESETS` | 守住第 5 关的独占 |
| 亮度锁成测试（开放水面以 `water` 为基准，0.70 骤黑底线，不放宽比例） | 直接吸收炉心试玩教训，比画完再改便宜 |
| 新图 `seaB`，不拿河流A 当海 | 第 3 关已是河，第 4 关必须一眼是海 |
| 甲板 → 舰群 → 开阔海 → 残骸四段，开阔海不放轰炸机、不放新炮 | 「安静之后出事」是本关最好的一笔节奏。残骸段比舰群疏，也对 |
| 旁白时钟：`s4_wreck` = 96 秒对第 7 块入画，`s4_ufo` 在柱结束那一帧，没有 `s4_end` | 时机都落在画面事件上，不靠倒计时 |
| 已收口缺口（全局 `slow_push` 不改、B 两架、副炮 5/5/6 + `BuildingPlacement.difficulties`、`CRUISER_GUN_HP` 16、地块从 87 起、冷色小机不开型号、清波 / 补给不做） | 都有代码依据，没有推翻的理由 |
| 敌弹全程不清（只有炸弹和血空前被击落） | 与炉心一致，规则少一条例外 |
| 深色黑曜压在亮甲板上 | 剪影可读，不必为了机体压暗地图 |

## 3. 建议改动清单

### P0-1　巨碟构图：碟会盖住黑曜

| | |
|---|---|
| 现状 | 黑曜专文 §8、思路表 §4.4：碟中心降到 (180, 148)，直径 208（占 y −4…252、x 76…284）。黑曜停在 y = 140，x 可能是 96 / 180 / 264 或折线半途。柱「从碟底打到黑曜中心」 |
| 问题 | 不管黑曜停在哪个歇点，他都落在碟的圆盘里面（96 也在 76…284 之内）。碟画在上层，黑曜在最关键的 3.85–4.40 秒被盖住；碟画在下层，又读成碟比飞机低。俯视里「碟底」就是碟心，碟心到黑曜只有 8 像素，柱根本没有长度。x 固定 180 时，黑曜在 96 / 264 也接不上一根竖柱 |

| 文档 | **P34 前必须改**：黑曜专文 §8 表 ①②④ 行、§11 碟入场行；思路表 §4.4 |

### P0-2　黑曜和炉心同构、和铁堡同位：第三式换成「掠袭」

逐项对照（数字取自黑曜专文 §5 和炉心专文 §6）：

| | 炉心 | 黑曜（现稿） |
|---|---|---|
| 导弹 | 5 发（过载 6），间隔 0.08，追踪 0.5 秒，88 px/s | 5 发（过载 6），间隔 0.08，追踪 0.45 秒，96 px/s |
| 大弹扇 | 5 发 56°，瞄准后夹角，96 px/s；过载 7 发 68° | 5 发 48°，瞄准后夹角，100 px/s；过载 7 发 64° |
| 平行向下 | 2 路间距 36，3 轮，120 px/s；过载 3 路 | 2 路间距 22，4 轮，130 px/s；过载 3 路 |
| 过载一圈 | 3.6 秒 | 3.6 秒 |
| 横向占位 | 铁堡三轨 72 / 180 / 288 | 三歇点 96 / 180 / 264 |

| | |
|---|---|
| 问题 | 玩家体感是「去掉炮舱的炉心，停在铁堡的三条轨上」。黑曜是全作第一个「人」Boss，可现稿里没有任何只有战斗机才做得出的动作：y 永远是 140，折线只是横移 |
| 替代 | 武器圈保持 4.8 / 3.6 秒和三式结构，第一式导弹、第二式折线扇都不动。**第三式「平行曳光」换成「掠袭」**：同一歇点 x 不变，直线俯冲到 y 280 再拉起。主战 1.6 秒窗口：0–0.30 预兆（尾焰拉长，已在「可有」里），停火；0.30–0.75 缓入缓出下探 140 → 280，停火；0.75–1.05 到底一梭，沿用现在的平行曳光参数（2 路，3 轮）；1.05–1.60 拉起回 140，停火。过载 1.2 秒：0.20 / 0.30 / 0.25（3 路）/ 0.45 |
| 锁什么 | 下探 y 上限 ≤ 320（机体下沿 ≤ 368，出生点 560）。x 不追玩家。只在到底那一段开火。全程可受伤，机体碰撞照常即死。这一式之内不再折线 |
| 和铁堡撞击的区分 | 铁堡撞击：整列一次，冲到 y = 640，只在 loco+4 出现。掠袭：每圈一次，只到上半屏，有预兆，短，飞回原位 |
| 取舍 | 代码都在 `systems/obsidian.ts` 的脚本里，和折线是同一种补间，只是方向改成 y，不需要新系统。玩家敢贴脸就更容易对准、追踪弹更快到，代价是近距离那一梭和碰撞，这才是王牌对决的味道 |
| 退一步 | 若 P34 想压风险，B 案：第三式改「机炮点射」（`aimed3burst` 连 3 次，间隔 0.3），导弹改 4 发、追踪 0.8 秒，至少在数字上和炉心拉开。可选再加：左右歇点 y 160、中歇点 y 125，让落点读成航线，不像三条轨 |
| 文档 | **P34 前必须改**：黑曜专文 §4（y 不变的锁只管折线）、§5.3、§11 武器圈行；思路表 §4.1 武器行、§4.2 |

### P1-5　命中圆太小，血量按理想 DPS 估的　（草案数字，建议 P34 首版就改）

| | |
|---|---|
| 现状 | 精灵 80×96，`frame` 半径 26。主战 800 点按「约每秒 20 点、约 40 秒」估算 |
| 问题 | 主炮 Lv3 的侧弹偏 15°（`LV3_SPREAD_DEG`），在距离 d 处横向偏出 0.268d。半径 26 时，距离超过约 120 像素就只剩中路一发命中，Lv3 不带僚机实际只有 10 点/秒。M2 对正时两架僚机（±25.6）各加 10；T Lv2 约加 7.5。实际 DPS 在 10 到 30 之间，800 点的战斗可能拖到 80 秒。另外机翼看上去中弹，子弹却穿过去不闪白，这和炉心「不该挡的挡了」是同一类读错，只是方向相反 |
| 替代 | 仍是一个圆，草案半径改 **32**（盖住机身和翼根）。锁定的是「约 40 秒」这个时长，不是 20 DPS 这个假设：用武器测试场，在 y 140 放 r = 32 的靶，玩家站 y 480，测「Lv3 + M1、无 T」的实际 DPS，再反推主战血量 |
| 文档 | 不改锁。半径和血量本来就是草案，可进代码调，回写专文 §6 / §11 |

### P1-9　漂浮物单开道具池等于再写一套系统　（P35 前）

## 5. 拍板用的推荐最终方向

1. **巨碟时间轴不动，构图改。** 瘫痪段黑曜失控滑到 (180, 300)，碟停 (180, 100)，柱从碟心打到黑曜，可见约 200 像素。P34 前改专文 §8 和思路表 §4.4。
2. **黑曜要有战斗机才有的动作。** 武器圈仍是「导弹 → 折线扇 → X」，X 从平行曳光换成「掠袭」：同一 x 俯冲到 y ≤ 320，只在到底时打一梭，有预兆，全程可受伤。折线规则、停火下限、单一 `frame`、无激光、黄过载全部保留。
3. **Boss 场必须是敌舰，而且是空的。** 左舷舰岛、钢灰甲板、红甲板线、6–8 个空停机位，新增地块 99–101。「末代」靠空甲板讲，不靠字幕。
4. **能量柱和残骸不用玩家青。** 白 7 为主，淡青 9 为辅；10–13 留给玩家，40–43 留给地球火。
5. **舰载轰炸机换成航弹帘。** 正下方两排大弹，血 72、分 2000，在画面中部投下；不改全局 `slow_push`，不加 `FIRE_PRESETS` 行。
6. **难度曲线不下凹。** 中等、困难不低于第 3 关同类波，舰群是全关峰值；开阔海和残骸段保持安静，「安静 → 王牌 → 碟」是本关的节奏签名。
7. **漂浮物用敌人管线实现**（地面、`planted`、不计击落率、不携带），故事上仍不算新敌种；黑曜命中圆改 r = 32，血量按武器测试场实测 DPS 反推到约 40 秒。
