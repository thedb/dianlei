## 3. 移动与弹幕

### 3.1 已有移动

和第一关 §3.1 相同的种类照旧用：`straight`、`sine`、`v_dive`、`cross`、`hover`、`side_arc`、`orbit`、`slow_push`、`ground`。`straight` 的 `angle` 仍是 0 = 正下方，180 = 正上方。

同一波里的多架用 `interval` 依次出场。组上的 `delay` 是整组再晚一点。

### 3.2 已有弹幕

速度仍是街机基准，代码乘 `ENEMY_BULLET_SPEED_SCALE`（0.8）。难度**不**再乘弹速，也**不**改 `DIFFICULTY_PROFILES` 里的 `fireRateScale`（三档都是 1）。改那一列会波及第一关。

本关用到的种类：`none`、`aimed1`、`aimed3burst`、`fan3`、`fan5`、`ring8`、`fixed2`、`missile`、`aimed_fast3`。没有新弹种。`aimed_fast3` 只给困难的低侧弧拦截机，每架 1 轮。

通用规则不变：敌人 y ≥ 8 才开火；离玩家不到 48 像素不发瞄准弹。侧后斜入还要多一条，见下节。

### 3.3 侧后方斜入（`rear_diag`）

小型机从画面左右两侧、玩家的斜后方进入，再朝斜上方飞出画面顶端。这是本关的新入场。

玩家停靠在 y = 560，机头朝画面上方。侧后方指的是机尾两侧、画面下缘外面，不是画面上半部的侧方。

和现有入场的差别：

| 入场 | 出生 | 飞向 | 本关谁用 |
|---|---|---|---|
| 顶入 `straight` | 画面上方外，默认 y = −20 | 向下，可带小角度 | 纵队、护航 |
| 顶角 `cross` | 左上或右上 | 斜向下，穿到对侧底 | 跑道段的交叉队 |
| 侧弧 `side_arc` | 左缘或右缘，y0 多在 60–240 | 先向内画四分之一圆，然后**向下**俯冲 | 拦截机。弧的终点在出生点下方 |
| 坦克底角 | 画面底角 | 贴地开上来 | 只有坦克 |
| **`rear_diag`** | 左缘外 x = −16 或右缘外 x = 376，y0 在 580–640 | 恒定直线，朝画面内侧、**向上** | 只有小型机 |

`side_arc` 的弧结束之后速度加在 y 上（越飞越靠下），做不成「从后面追上来」。`cross` 的终点在画面底部。`straight` 可以手写 152° / 208° 凑出同一条直线，但每一波都要自己管正负号，也和侧弧容易看混。实现时加一个命名种类，内部仍是匀速直线。

拍板起点（内偏角约 28° 已定；速度和间隔试玩可调）：

| 参数 | 建议 | 说明 |
|---|---|---|
| `side` | `left` / `right` | 左出生 x = −16，右出生 x = 376 |
| `y0` | 620，林地合围用 640，困难加塞的一波用 580 | 560 是玩家停靠高度。620–640 在机尾下面。580 仍在机身侧面偏后。不要用 80–220，那是侧弧的高度 |
| `bearing` | **28°** | 相对正上方、朝画面内侧。25° 偏直；到了约 40° 会从对侧穿出，到不了顶边 |
| `speed` | 160–185 像素/秒 | 简单慢，困难快 |
| `interval` | 简单 0.30，中等 0.26，困难 0.22 | 同一侧的出场间隔 |
| 左右 | 同一波左右同时出 | 不要左队飞完再出右队，否则一波会拖过 10 秒 |

28°、速度 170、从 (−16, 620) 向右上飞时：大约 0.4 秒后还在左缘 x ≈ 16、y ≈ 560，也就是贴着机尾外侧出现；大约 2.5 秒后穿过中线 x = 180、y ≈ 250；大约 4.3 秒后从顶端偏右离开。玩家先在侧后方看见它，再看它爬到机头前面。右缘是镜像。

出生点必须落在现有剔除框里面（x 在 −120 和 480 之间，y 在 −120 和 700 之间）。x = −200 会在出生那一帧被扔掉。

开火：现有规则是 y ≥ 8 就能打。侧后斜入出生时 y 已经远大于 8，若 `firstDelay` 是 0，会在画面外的下缘开枪。这个种类在 x 进入 24–336 之前不开火。表里写了点射的，再加 `firstDelay` 0.55、`maxShots` 1（`aimed3burst` 算一轮）。没写点射的就是 `none`。

### 8.2 需要新写的，只限于进关数据表达

侧后斜入需要一个新的移动种类。现有种类表达不了「下缘外侧、向斜上方」：

```ts
| { kind: 'rear_diag'; side: 'left' | 'right'; y0: number; bearing: number; speed: number }
```

`bearing` 是相对正上方的内偏角，单位度。左侧速度方向是 `angle = 180 - bearing`，右侧是 `180 + bearing`（和 `straight` 的角度约定相同）。出生后匀速，直到飞出剔除框。x 进入 24–336 之前不开火。

波次要能按难度取舍。建议：

```ts
interface Wave {
  // 现有字段 …
  section: 'ground' | 'coast' | 'base' | 'outskirts' | 'runway' | 'woods';
  /** 不写 = 三个难度都出。 */
  difficulties?: readonly ('easy' | 'medium' | 'hard')[];
}

interface SpawnGroup {
  // 现有字段 …
  /** 不写 = 跟着整波走。W14 的第二门炮、W20 的护航、W04 的第三辆坦克用这个。 */
  difficulties?: readonly ('easy' | 'medium' | 'hard')[];
  /** 某一档换弹。不写的档用 `fire`。 */
  fireByDifficulty?: { medium?: Fire; hard?: Fire };
  /** 某一档改架数。多出来的架沿用同一组 xs 和 interval。 */
  countByDifficulty?: { medium?: number; hard?: number };
}
```

W13 整波标 `['medium', 'hard']`，W22 整波标 `['hard']`。简单档的底表不写 `difficulties`。击落率只数真正 `spawn` 出去的飞机，和现在「跳过的保底机不进分母」一样。

不要为了三档复制三份完整时间轴，也不要在运行时改 `FIRE_PRESETS` 或 `WEAPONS`。

`StageSection` 加上 `outskirts` / `runway` / `woods` 之后，第一关仍用原来的三个标签。段落不参与选地图。
