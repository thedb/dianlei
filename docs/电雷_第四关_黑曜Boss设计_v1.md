## 2. 场地

### 2.1 为何新图

河流A 是河谷，不是大海。第 4 关道中禁止把 `riverA` 当成海战图。新地图 id `seaB`，显示名 **海面B**。本 PR 只写规格，P34 再画。

| 项 | 锁定内容 |
|---|---|
| 长度 | 9 × 40 行 = 360 行 = 5760 像素。与陆地B、河流A 同级 |
| 预览 | `(5760 − 640) / 40 = 128` 秒。注册后地图预览自动多一行「海面B」 |
| 卷动 | `BG_SCROLL_SPEED` 40。不循环道中图 |
| 云影 | 设 `cloudShadows`。贴边云规则与现有海陆图相同 |
| 种子 | 草案 `SEA_B_SEED` = 37。九个槽全部固定，不镜像。舰岛保持在右侧 |
| 坦克 | 本关不生成坦克和导弹车。海上没有给他们的路 |

边缘只有两种契约。`sealEdges` 在画完内部之后盖上，测试检查每个区块的第 0 行和第 39 行。

|---|---|
| `deck` | 第 2–20 列是 `carrierDeck`。第 0–1 列和第 21–22 列是 `water`。船体不贴死 23 列的外边 |
| `sea` | 23 列全是 `water` 或 `waterB` |

| 2 | `deckWake` | deck → sea | 甲板 → 舰群 | 甲板结束，尾流收回满幅海水 |

### 2.2 巡洋舰副炮的占地

副炮是建筑，地形掩码走 `water`。舰体 `cruiserHull` 是 `feature`，建筑不能压在 feature 上。每门副炮下面留一块 **2×2** 的 `cruiserGunDeck`：画面上画成金属炮位，地形表里归 **water**。2×2 必须整块落在这四格上，不能骑进舰体。测试用 `validateBuildingFootprint`。

### 2.3 残骸层

两层，都不是第三种新敌：

| 层 | 锁定 |
|---|---|
| 地块 | 第 7、8 块内部的 `wreckAlloy`、`wreckBurn`。不压边缘行。不可射击 |
| 漂浮物 `wreck_float` | 代码像素小件，锚在地图上，随卷轴走。血草案 4，分草案 200。不开火，不掉落，不进击落率。炸弹按小型打掉屏幕内的。实现用单独的道具池，**不**新增 `EnemyType` |

漂浮物从第 7 块进入画面开始出现，预警之后不再新生成。已经在场上的随卷轴离开或被打掉。

接近带按「本地卷轴约 120」来画：画面上半已经是甲板船首，开阔海留在下沿。

循环段的接缝用 `enemyDeck`，不用 `carrierDeck`。舰岛精灵可以复用，必须放在左舷。停机位是空的，6–8 个。不要让玩家以为绕回了出发的船。

### 2.6 亮度连贯（2026-10-28 补锁）

炉心试玩的教训是 Boss 场比道中突然暗一档。本关提前写成测试，比例锁定，画不到就改地块用色，不放宽比例。算法与 `furnaceBoss.test.ts` 的光栅亮度相同。基准 `Lwater` 是现有 `water` 地块的平均亮度。开放水面仍复用 `water` / `waterB`，不改这两张地块的像素。

| 区域 | 下限 |
|---|---|
| 海面B 第 0 块甲板 | ≥ `Lwater` × 0.90。开场不得比这张白天的海更暗 |
| 第 1 块、第 2 块、第 6 块 | 第 1 块（舰尾过渡）≥ `Lwater` × 0.85。第 2 块和第 6 块开阔水 ≥ `Lwater` × 0.90 |
| 第 7、8 块残骸 | ≥ 第 6 块 × 0.75。冷金属渐变，海水仍是同一张水。不低于开阔海约 0.75 |
| 接近带 | ≥ 海面B 最后 40 行 × 0.85 |
| 循环甲板 | ≥ 海面B 第 0 块 × 0.85。钢灰敌甲板，不另做夜航 |
| 任何一块 | ≥ `Lwater` × 0.70。低于这一档视为骤黑 |

我方甲板最后一行是地图行 63，约 **25.6 秒**离开屏幕底。新地块不用调色板 0 或 1 当填色。残骸和巨碟用灰 3–5、淡灰 6、白 7，淡青 9 只做点缀，不用玩家青 10–13 做主体。能量柱以白 7 为主体，淡青 9 只做外缘，不用爆炸黄 40–43。黑曜机体保持深色金属，靠亮甲板衬出剪影；不要为了机体把海图涂黑。面积细则见思路表 §3.2。

玩家在入场里保持移动、射击和炸弹。

| 步 | 锁定内容 |
|---|---|

## 4. 刃翼十字

黑曜是一架舰载战斗机。开战之后机体沿 ∞ 巡航（利萨如：`x = sin θ`，`y = sin 2θ`），中心是 (180, `OBSIDIAN_PARK_Y`)。收叠和半展周期 8 秒。全开和困难过载角速度 ×2。四片刃翼绕肩上的铰链转，不整张换图。三个歇点不再飞。阶段 3 和过载的俯冲前刺打断这条 ∞：预兆里收到 (180, 140)，再按 y 140→280→140 下探，窗口结束用 0.16 秒 Ease 回 ∞，不取消这次俯冲。入场和展开过渡仍收到路径中心。

零件层，相对机体中心。角度是画布弧度，0 朝机头（屏幕下方），正角把刃尖摆向左侧，右侧刃用相反数。y 正方向朝机头。v3 后掠角从机尾量起（π），下表是中间那一层，命中圆跟这一层。每一铰在收叠和半展各画三层，角差约 0.16；全开三层收成同一角。刃根留在自己这一侧，打到的翼就是被削的那一侧。

| 零件 | 枢轴 (x, y) | 收叠 | 半展 | 全开 |
|---|---|---|---|---|
| 左内刃 `innerL` / 铰锁 `hinge0` | (−16, +10) | π−0.66 | π−0.77 | +0.95 |
| 左外刃 `outerL` / 铰锁 `hinge1` | (−14, −12) | π−0.72 | π−0.82 | π−0.95 |
| 右内刃 `innerR` / 铰锁 `hinge2` | (+16, +10) | −(π−0.66) | −(π−0.77) | −0.95 |
| 右外刃 `outerR` / 铰锁 `hinge3` | (+14, −12) | −(π−0.72) | −(π−0.82) | −(π−0.95) |

收叠是堆叠后掠翼：左右都有明显翼展，刃尖朝机尾，不是贴身细线。半展把外层掀到更横（约 1.12 弧度离机尾），内层仍后掠，层叠还在。全开是十字：外刃留在后上方，内刃甩到前下方（±0.95）。过渡用 smoothstep 插值每一层的角，1.1 秒，无敌，不开火。层收拢之后换成细长的十字刃。禁止阶段之间整张贴图硬切。

铰锁画在枢轴上，是橙色圆环。收叠阶段活着的锁另有一圈黄、橙双色刻度，外圈落到命中半径上，表示现在打这里，不闪。过载只把座舱改警示黄。后掠刃是实心青梯度（调色板 12→11→10→9，尖可到白 7），下面垫一块深色金属翼面，根部有橙色喷口。十字刃更长更窄，不垫翼面。左右是同一张刃旋转，不另镜像一张晶体。机体本身不用玩家青。命中圆仍在中间层枢轴外 38 像素、半径 14，不跟着精灵外偏移。后掠刃尖朝机尾，刃缘扇取这一层的左右方位，再翻到朝机头的半平面，所以弹仍飞向玩家；命中圆不翻，留在看见的翼上。

## 5. 武器

速度是最终像素/秒，不吃 `bulletSpeedScale`。时钟不吃 `fireRateScale`。没有激光。阶段切换、剥刃、血空都不清已经飞出的敌弹。只有玩家的 B 炸弹清。

### 5.1 阶段 1 · 收叠

四枚铰锁是主目标，可以同时打。刃翼和机体圆是装甲：子弹停住，不扣机体，也不扣刃段。火力是机头窄扇，密度中等，没有掠袭。

一圈 2.0 秒：

| 时刻 | 内容 |
|---|---|
| 0.25 / 0.70 / 1.15 | 机头 3 发大弹，张角 14°，速度 100 |
| 1.50 | 左右翼根各一枚导弹，速度 96，追踪 0.55 秒 |

四锁全毁才播收叠→半展。没有第二条「打机体也能过关」的路。炸弹打的是这四枚锁。

### 5.2 阶段 2 · 半展

刃缘当武器轨。每圈 1.6 秒。外刃扇和晶片只从还活着的外刃上打。打掉一侧，那一侧的扇和晶片停，另一侧继续。机头双联散射和翼根导弹照打。

| 时刻 | 简单 / 中等 | 困难 |
|---|---|---|
| 0.12 / 0.48 / 0.84 / 1.20 | 每片活外刃 5 发大弹，沿刃的左右方位、朝机头，张角 26° | 同左，再加 1.44 一秒，每片 7 发 |
| 0.30 / 0.96 | 每片 4 发小晶片，速度 168 | 每片 6 发 |
| 0.72 | 机头 3 发窄扇 | 同左 |
| 1.04 | 机头双联散射：左右各 3 发短扇，张角 18°，两口相距 22 | 同左 |
| 1.28 / 1.36 | 左右翼根各一枚导弹，速度 96，追踪 0.55 | 同左 |
