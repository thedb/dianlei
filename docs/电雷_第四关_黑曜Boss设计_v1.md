读表时分两档：

| 档 | 含义 |
|---|---|
| **锁定** | 实现必须遵守。改锁定要先改本文。 |
| **草案（可调）** | 初值，写在 §5 和 §6。实现放进 `config.ts`，试玩可以改，改完回写本文。 |

难度倍率沿用 `scaleHp`：简单 ×1，中等 ×1.15，困难 ×1.30。Boss 时钟不吃 `fireRateScale`，弹速不吃 `bulletSpeedScale`。炸弹比例沿用 `BOMB_BOSS_RATIO`（8%）。血空之后的离场仍最终调用 `stepVictoryExit`，但必须先走完 §8，不能在血空那一帧就爆炸通关。

和炉心的差别：

| | 炉心 | 黑曜 |
|---|---|---|
| 输出 | 炮舱之后，核心按节拍开合，合拢不吃子弹 | 单机全身可打，直到最后一条血空。没有护盾门 |

## 2. 场地

### 2.1 为何新图

河流A 是河谷，不是大海。第 4 关道中禁止把 `riverA` 当成海战图。新地图 id `seaB`，显示名 **海面B**。本 PR 只写规格，P34 再画。

| 项 | 锁定内容 |
|---|---|
| 长度 | 9 × 40 行 = 360 行 = 5760 像素。与陆地B、河流A 同级 |
| 预览 | `(5760 − 640) / 40 = 128` 秒。注册后地图预览自动多一行「海面B」 |
| 卷动 | `BG_SCROLL_SPEED` 40。不循环道中图 |
| 云影 | 设 `cloudShadows`。贴边云规则与现有海陆图相同 |
| 种子 | 草案 `SEA_B_SEED` = 37。九个槽全部固定，不镜像。舰岛保持在右侧 |
| 坦克 | 本关不生成坦克和导弹车。海上没有给他们的路 |

边缘只有两种契约。`sealEdges` 在画完内部之后盖上，测试检查每个区块的第 0 行和第 39 行。

| 契约 | 第 0 行和第 39 行 |
|---|---|
| `deck` | 第 2–20 列是 `carrierDeck`。第 0–1 列和第 21–22 列是 `water`。船体不贴死 23 列的外边 |
| `sea` | 23 列全是 `water` 或 `waterB` |

| # | 区块 | 下边 → 上边 | 段落 | 内容 |
|---|---|---|---|---|
| 0 | `deckCatapult` | deck → deck | 甲板 | 开场就在甲板上。弹射器划线朝屏幕上方。舰岛在右侧列，不压边缘海 |
| 1 | `deckPark` | deck → deck | 甲板 | 甲板延续。2×2 舰载机是地块装饰，没有血、没有碰撞。不是第 3 关的 `parked_fighter` |
| 2 | `deckWake` | deck → sea | 甲板 → 舰群 | 甲板结束，尾流收回满幅海水 |
| 3 | `escortLeft` | sea → sea | 舰群 | 左舷护航舰。舰体是 `cruiserHull`（feature） |
| 4 | `cruiserLine` | sea → sea | 舰群 | 主巡洋舰。副炮占位见 §2.2 |
| 5 | `escortRight` | sea → sea | 舰群 | 右舷护航，队列散开 |
| 6 | `openSwell` | sea → sea | 开阔海 | 涌浪。几乎没有船。密度留给波次表下降 |
| 7 | `wreckNear` | sea → sea | 残骸 | 第一批漂浮残骸。旁白 `s4_wreck` 在这块进入画面时触发 |
| 8 | `wreckFar` | sea → sea | 残骸 | 更密的异形金属。焦痕用新地块，不用陆地的 `scorch` 冒充。上边仍是满幅海水，供 Boss 场对接 |

段落标签 `deck` / `fleet` / `swell` / `wreck` 只作标注，不选地图。区块时间和陆地B 的 9 块表相同：第 n 块的卷动窗口约 `n×16` 到 `(n+1)×16` 秒，并提前 16 秒从屏幕顶进入。第 7 块因此在 **96 秒**进入画面。`STAGE4_WRECK_AT` = **96**。

### 2.2 巡洋舰副炮的占地

副炮是建筑，地形掩码走 `water`。舰体 `cruiserHull` 是 `feature`，建筑不能压在 feature 上。每门副炮下面留一块 **2×2** 的 `cruiserGunDeck`：画面上画成金属炮位，地形表里归 **water**。2×2 必须整块落在这四格上，不能骑进舰体。测试用 `validateBuildingFootprint`。

### 2.3 残骸层

两层，都不是第三种新敌：

| 层 | 锁定 |
|---|---|
| 地块 | 第 7、8 块内部的 `wreckAlloy`、`wreckBurn`。不压边缘行。不可射击 |
| 漂浮物 `wreck_float` | 代码像素小件，锚在地图上，随卷轴走。血草案 4，分草案 200。不开火，不掉落，不进击落率。炸弹按小型打掉屏幕内的。实现用单独的道具池，**不**新增 `EnemyType` |

漂浮物从第 7 块进入画面开始出现，预警之后不再新生成。已经在场上的随卷轴离开或被打掉。

### 2.5 Boss 场

地图 id `obsidianBoss`，显示名 **黑曜舰空**。

| 项 | 锁定内容 |
|---|---|
| 结构 | 一条海面接近带，然后循环的甲板上空（`loopFrom` = 40） |
| 接图 | 海面B 末行直接接到接近带第 0 行。末行是 `sea` 契约。不淡出、不铺预警白云、不切宇宙、不切星空 |
| 卷轴加速 | 沿用 `TILE_HANDOFF_*` |
| 战中卷动 | 循环段 40 像素/秒。巨碟演出期间也不停卷 |
| 接近带 | 下段是开阔海和少量残骸，往上见到敌舰船首和左舷舰岛。1 个区块 |
| 循环段 | 空的敌舰甲板。`enemyDeck` 列 2–20，`enemyMark` 两条红线，8 个空 `deckSpot`。舰岛复用 89，贴在左舷（列 3–6）。左右仍是海。不是我方出发船，不是船坞，也不是星空 |
| 云影 | 设 `cloudShadows`。预警云带仍然关闭 |
| 预览 | 自动多一行「黑曜舰空」：接近带加循环一圈，约 32 秒 |

接近带第 0 行逐格等于 `getMapGrid('seaB')` 的最后一行。不手抄。

`STAGE4_WARNING_AT` = **118**，`OBSIDIAN_ENTER_AT` = **123**。海面B 与河流A 同为 5760 像素，交接积分相同，入场时本地卷轴约 120 像素。常量单独命名，不引用第 2 关或第 3 关的预警常量。`118 × 40 + 640 = 5360 < 5760`。

接近带按「本地卷轴约 120」来画：画面上半已经是甲板船首，开阔海留在下沿。

种子草案 `OBSIDIAN_BOSS_SEED` = 43。不镜像。

循环段的接缝用 `enemyDeck`，不用 `carrierDeck`。舰岛精灵可以复用，必须放在左舷。停机位是空的，6–8 个。不要让玩家以为绕回了出发的船。

### 2.6 亮度连贯（2026-10-28 补锁）

炉心试玩的教训是 Boss 场比道中突然暗一档。本关提前写成测试，比例锁定，画不到就改地块用色，不放宽比例。算法与 `furnaceBoss.test.ts` 的光栅亮度相同。基准 `Lwater` 是现有 `water` 地块的平均亮度。开放水面仍复用 `water` / `waterB`，不改这两张地块的像素。

| 区域 | 下限 |
|---|---|
| 海面B 第 0 块甲板 | ≥ `Lwater` × 0.90。开场不得比这张白天的海更暗 |
| 第 1 块、第 2 块、第 6 块 | 第 1 块（舰尾过渡）≥ `Lwater` × 0.85。第 2 块和第 6 块开阔水 ≥ `Lwater` × 0.90 |
| 第 7、8 块残骸 | ≥ 第 6 块 × 0.75。冷金属渐变，海水仍是同一张水。不低于开阔海约 0.75 |
| 接近带 | ≥ 海面B 最后 40 行 × 0.85 |
| 循环甲板 | ≥ 海面B 第 0 块 × 0.85。钢灰敌甲板，不另做夜航 |
| 任何一块 | ≥ `Lwater` × 0.70。低于这一档视为骤黑 |

我方甲板最后一行是地图行 63，约 **25.6 秒**离开屏幕底。新地块不用调色板 0 或 1 当填色。残骸和巨碟用灰 3–5、淡灰 6、白 7，淡青 9 只做点缀，不用玩家青 10–13 做主体。能量柱以白 7 为主体，淡青 9 只做外缘，不用爆炸黄 40–43。黑曜机体保持深色金属，靠亮甲板衬出剪影；不要为了机体把海图涂黑。面积细则见思路表 §3.2。

## 3. 入场（可玩，不锁操作）

玩家在入场里保持移动、射击和炸弹。

| 步 | 锁定内容 |
|---|---|
| 1 | 海面B 收束。预警 118 秒停止刷怪，不铺白云 |
| 2 | 甲板船首卷进画面 |
| 3 | 黑曜从画面上方滑入，停到开战高度 |
| 4 | 开战：WARNING 字标、名称牌「黑曜」「舰载王牌」、血条。武器从导弹齐射开始 |

血条：开战前 2 秒填满。简单 / 中等一条红。困难先红后黄。WARNING 字标 1.5 秒。名称牌留到巨碟把机体打散为止；散开之后名称牌撤下。

挑战 Boss「4」的 `seek` 落在 `OBSIDIAN_ENTER_AT`。开场旁白和 `s4_wreck` 的时钟都已经过去，不补播。巨碟旁白由演出时钟触发，挑战模式仍会播。

## 4. 折线占位

黑曜是一架飞机，一个命中盒。没有炮塔门，没有开合瓣，没有铁轨。

三个歇点是屏幕 x，不是地图轨，背景不画铁轨，也不点亮落点：

| 歇点 | x |
|---|---|
| 左 | 96 |
| 中 | 180 |
| 右 | 264 |

| 项 | 锁定内容 |
|---|---|
| 开战 | 停在中歇点，还没折线 |
| 何时飞 | 只在武器循环的第二式「折线扇」开始时飞一次 |
| 去哪 | 等概率去另外两个歇点，不留在当前点。用 `SceneContext.rng` |
| 时长 | 主战 0.45 秒，过载 0.32 秒。缓入缓出 |
| 受伤 | 折线全程可受伤。不套铁堡的并轨无敌 |
| 开火 | 折线的 0.45 / 0.32 秒内不发射。飞完立刻按这一式继续 |
| y | **只约束折线。** 折线期间 y 保持 `OBSIDIAN_PARK_Y`。折线不冲到屏幕底。掠袭可以改 y，见 §5.3 |

武器循环按时间走，不按歇点绑式。停在左边也可以打导弹。这是和铁堡分轨六式的分界。

主战一圈 **4.8 秒**，三式各 1.6 秒：导弹齐射 → 折线扇 → 掠袭 → 回到导弹。开战从导弹齐射算起。困难过载一圈 **3.6 秒**，三式各 1.2 秒，顺序相同。三式结构锁定。各式内部的发数、张角和波次是草案，试玩后已加密度，见 §5。第三式是掠袭，不再是平行曳光。

开战先在中歇点打完第一轮导弹（1.6 秒）才第一次折线。每次落地之后，要再等一整圈减去这段飞行（主战约 4.35 秒，过载约 3.28 秒）才再飞。这段停留不得改成连续折线。

### 4.1 折线可读性（2026-10-28 补锁）

黑曜没有开合门。可打的时间是全程，安全输出的时间是停火。炉心试玩要求露弱点的窗口够打，这里把停火写成下限：

| 项 | 档 | 值 |
|---|---|---|
| 主战折线停火 | 锁定下限。§4 写 0.45，§11 标草案 | 不得短于 **0.45** 秒。可以加长，不能缩短 |
| 过载折线停火 | 锁定下限。§4 写 0.32，§11 标草案 | 不得短于 **0.32** 秒。可以加长，不能缩短 |
| 落稳后再停 | 锁定下限 **0.12** 秒；§5.2 的现行草案是 0.15 秒 | 然后才打第一扇。0.15 可以加长，不能低于 0.12 |

歇点不画轨，也不点亮落点。在这个前提下，提示只允许下面两档：

| | 内容 |
|---|---|
| **可有** | 飞行期间机体按现有侧倾转向目标歇点。尾焰用现有引擎火焰，飞行时可以稍长。受击白闪覆盖整机，含飞行中 |
| **禁止** | 在 96 / 180 / 264 画线、画点、点亮落点。地面影子先跳到目标点。整机闪烁。黄圈标成「只有圈内扣血」。给歇点做 UI 准星 |

飞行中的侧倾是主提示。不另做轨道预告。巨碟阶段的 UI 见 §8.4。

## 5. 武器草案

都用现有小弹、大弹和导弹。不新增激光。速度是乘过 0.8 之后的实际速度。离玩家近于 48 像素的瞄准弹不发。

### 5.1 导弹齐射

| 项 | 草案 |
|---|---|
| 第一波 | 主战翼根 4 发，进入该式 0.25 秒，间隔 0.08 秒，追踪 0.55 秒。过载翼根 6 发，0.18 秒起，间隔 0.06 秒，追踪同样 0.55 秒 |
| 第二波 | 主战在最后一发翼根弹之后 0.35 秒，中线再发 2 发，间隔 0.08 秒，短追 0.22 秒。过载隔 0.28 秒，中线 2 发，间隔 0.06 秒，短追同样 0.22 秒 |
| 弹出 | 第一波翼根左右交错。第二波中线 |
| 速度 | 实际 96 像素/秒 |
| 近距 | 离玩家近于 48 像素的瞄准弹不发 |

### 5.2 折线扇

| 项 | 草案 |
|---|---|
| 折线 | 见 §4。飞的时候不发射 |
| 第一扇 | 落稳后 0.15 秒。主战 5 发、张角 44°。过载 7 发、张角 64° |
| 第二拍 | 第一扇之后。主战隔 0.35 秒，窄扇 3 发、张角 22°。过载隔 0.28 秒，5 发、张角 40° |
| 方向 | 朝玩家夹在张角里，整体偏向下方 |
| 速度 | 实际 100 像素/秒 |
| 折线 | 主战不低于 0.45 秒，过载不低于 0.32 秒。飞的时候仍不开火 |

### 5.3 掠袭

第三式。进入这一式时的歇点 x 保持不变，不追玩家。这一式之内不再折线。全程可受伤。碰到玩家判定点即死，和主战相同。

主战窗口 1.6 秒：

| 段 | 时间 | 动作 |
|---|---|---|
| 预兆 | 0–0.30 | 尾焰拉长。停火 |
| 下探 | 0.30–0.75 | 缓入缓出，y 从 140 到 280。停火 |
| 到底一梭 | 0.75–1.05 | 只在这一段开火 |
| 拉起 | 1.05–1.60 | 回到 y = 140。停火 |

全身一个部位 `frame`。主战一直可打，包括折线和掠袭。`frame` 半径草案 **32**（原草案 26）。方法锁定，数字仍是草案：进代码后用武器测试场实测 DPS，再反推血量回写本节和 §11。

| 困难追加 | 过载，仍是 `frame` | 360 | 40000 留到过载归零 | 主战归零后的 1.2 秒切换结束才开始扣 |

锁定目标是战斗「约 40 秒」，不是这些整数。主战 1200、过载 360 仍是试玩后的草案（从 800 / 240 加上去）。实测方法：武器测试场把靶放在 y = 140、半径 32，玩家站在 y = 480，测「主炮 Lv3 + M1、无 T」的实际 DPS，用约 40 秒反推主战血量，改完回写本文。

## 8. 巨碟演出（硬锁）

血空之后**禁止**立刻走常规 Boss 死亡爆炸，禁止立刻 `stepVictoryExit`，禁止立刻打开结算或关卡字卡。

时钟从血空那一帧起，用关卡 `gameTime`。暂停冻住 `gameTime`，演出停在原帧，恢复后接着走，不从头播。没有演出存档。返回标题再进来是新的一局。

巨碟、能量柱和黑曜残骸用屏幕坐标。底下的甲板循环继续以 40 像素/秒卷动。

| t（秒） | 段 | 锁定 |
|---|---|---|
| 0.00 | 血空 | 战斗结束。停火。折线若在半途，不留在当前坐标，从当前屏幕坐标滑落（见下一段）。分数按 §6 在这一帧入账。不爆炸通关。名称牌先留着 |
| 0.00–1.60 | ① 瘫痪 | 换成冒烟破损帧。引擎熄火。从血空时的屏幕坐标缓出滑落到 **(180, 300)**，侧倾，代码烟，无判定。不解体。不再原地冒烟 |
| 1.60–3.60 | ② 巨碟入场 | 俯视圆碟从中心 y = −120 降到 **(180, 100)**。移动 1.6 秒，再停 0.4 秒。直径 208，占 y **−4…204**。不再停在 148。不可被打，无血条，不挡玩家（玩家已无敌） |
| 3.60–3.85 | ③ 蓄能 | 碟心变亮。还没有柱 |
| 3.85–4.40 | ③ 能量柱 | 一根竖柱，宽 18，从碟心打到黑曜中心 (180, 300)。碟下沿约 204 到机体顶约 252，可见空隙约 **48**；柱长约 **200**。柱是代码亮条，不读武器表，不伤玩家，不清弹 |

`s4_ufo` 文案固定为：未知飞行物击毁目标后撤离。追踪。显示 `CAPTION_HOLD`（4 秒）。它覆盖离场和通关离场等待的开头。

| 时段 | 玩家 |
|---|---|
| 0.00–6.80 | **无敌**。可以移动，速度和夹紧与战斗相同。不能射击，不能投弹。僚机停火，仍无判定，跟着平移 |
