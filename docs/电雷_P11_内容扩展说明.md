# 电雷 P11：内容可扩展化重构说明

P11 只改结构，不改玩法：第一关在三种难度、标题演示、挑战 Boss、武器测试、调试浮层、胜利飞离、困难第三阶段黄色血条下的表现与重构前一致。规则仍以《设计文档 v1.1》和《第一关波次表 v1》为准；本文只说明代码放在哪里、怎么加新内容。

架构图（5 张 mermaid，重构前后对照）见 [电雷_架构图_P11.md](./电雷_架构图_P11.md)。

## 模块分布

| 内容                                           | 位置                                                          |
| ---------------------------------------------- | ------------------------------------------------------------- |
| 关卡注册表（唯一引用 `stage1` 的地方）         | `src/game/levels/registry.ts`                                 |
| 关卡统计（敌机总数、MVP 波次）                 | `src/game/levels/stageStats.ts`                               |
| Boss 定义（部件 + 阶段表）                     | `src/game/levels/bosses/orbitalBattleship.ts`                 |
| Boss 通用运行器、分段血条                      | `src/game/systems/boss.ts`                                    |
| Boss 美术注册表 `BOSS_ART`                     | `src/game/art/bossSprite.ts`                                  |
| 敌机定义表 `ENEMY_DEFS`                        | `src/game/entities/enemyDefs.ts`                              |
| 弹幕库（预设、参数化图案、枪械时钟、扫射激光） | `src/game/systems/danmaku.ts`                                 |
| 难度档案 `DIFFICULTY_PROFILES`                 | `src/game/difficulty.ts`                                      |
| 掉落规则 `BUILDING_DROP_RULES`                 | `src/game/systems/dropRules.ts`                               |
| 建筑炮管外观 `BUILDING_BARRELS`、炮管绘制      | `src/game/art/buildingSprite.ts`、`src/game/art/gunBarrel.ts` |
| 可注入随机数 `createRng`                       | `src/engine/rng.ts`（`SceneContext.rng`）                     |
| 对象池（最小堆空闲表，O(log n) 取用）          | `src/engine/pool.ts`                                          |
| 空间网格（已接入子弹 / 导弹对敌机的粗筛）      | `src/game/systems/collision.ts`                               |

战斗场景 `src/game/scenes/battle.ts` 只负责帧顺序，规则拆到 `src/game/battle/`：

- `context.ts` 共享状态；`playMode.ts` 模式规则表；`player.ts` 自机；`combat.ts` 击杀 / 炸弹 / 碰撞；`world.ts` 卷轴 / 波次 / 建筑 / 敌机 / 子弹；`bossFight.ts` Boss 事件与胜利飞离；`fx.ts` 爆炸 / 火花 / 震屏；`range.ts` 武器测试；`pause.ts` 暂停；`render.ts` 场景绘制；`hud.ts` HUD 与覆盖层。

## 模式规则表

`PLAY_MODE_RULES`（`battle/playMode.ts`）每行一个模式。战斗代码只读这些开关，不比较 `playMode` 字符串。

| 开关                           | 正式（play） | 标题演示（attract）      | 武器测试（weaponTest） |
| ------------------------------ | ------------ | ------------------------ | ---------------------- |
| 静音                           | 否           | 是                       | 否                     |
| 可暂停                         | 是           | 否                       | 是（返回标题不确认）   |
| 写战报                         | 是           | 否                       | 否                     |
| 死亡后                         | 复活 / 结束  | 保持残骸（标题淡出重开） | 回标题                 |
| 世界（卷轴、波次、建筑、Boss） | 有           | 有                       | 无                     |
| HUD                            | 关卡 HUD     | 无                       | 测试面板               |
| 难度                           | 本局选择     | 固定简单                 | 固定简单               |

## 加新内容

- **新敌机**：`EnemyType` 加 id，`ENEMY_DEFS` 加一行，`art/enemySprite.ts` 的 `BUILDERS` 加精灵。
- **新弹幕**：`FIRE_PRESETS` 加一行（并在 `Fire` 加 kind），或在波次里直接写 `{ kind: 'pattern', pattern: {...} }`。
- **新 Boss**：在 `levels/bosses/` 写 `BossDef`，在 `BOSS_ART` 注册美术，关卡的 `boss` 指向它。
- **新关卡**：写 `levels/stageN.ts` 导出 `StageData`（新 `id`），加进注册表 `STAGES`；挑战 Boss 列表自动出现。地图瓦片美术目前仍只有第一关。
- **新难度旋钮**：`DifficultyProfile` 已预留 `bulletSpeedScale`、`fireRateScale`、`buildingDrops`，现有三档都保持原值。

## 测试

- `scenes/battle.replay.test.ts`：种子固定的整关 / 挑战 Boss / 演示 / 武器测试回放，比对分数、击杀、阶段时间线和逐帧摘要。
- `scenes/battle.render.test.ts`：同样的回放，每隔若干帧向录制画布绘制，比对绘制调用摘要。
- 两份期望值都在重构前采集。重构不得改动；只有刻意的玩法或画面变更才能用 `REPLAY_CAPTURE=1` 重新采集，并在 PR 中写明。
- 测试改动只涉及取值方式（如 `getStage('1')` 代替直接导入 `stage1`、Boss 运行器的新字段名），没有改行为断言。
