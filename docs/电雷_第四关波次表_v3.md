# 《电雷》第四关波次表 v3

> 日期：2026-10-29｜状态：**海战签名已落地**。施工图是本表。  
> v2（2026-10-28）是 P35 的「第一关换皮」表：正弦、V 字、斜穿当主节奏，舰载轰炸机 `slow_push` + 向下扇，副炮双管固定向下。Yoan 否掉那套道中。v2 留在 `docs/电雷_第四关波次表_v2.md`，不再当施工图。  
> 海图、黑曜和巨碟仍以 `docs/电雷_第四关_黑曜Boss设计_v1.md` 为准。炮位格子和漂浮物锚点仍以 `docs/电雷_第四关完整思路表_v1.md` §3.5 的六座 `cruiserGunDeck` 和八个水锚为准，行列不改。  
> 旁白原文不改。`s4_open` / `s4_wreck` / `s4_ufo` 见故事表 §2。`s4_wreck` 在 `STAGE4_WRECK_AT`（96 秒）亮起。

坐标沿用逻辑分辨率 360×640。时间是关卡时钟。灯阶段时钟冻在 0。前冲 3.2 秒时钟在走。控制在前冲结束时交还，此时时钟约为 3.2 秒。

## 0. 锁定

1. 道中地图是 **海面B**（`seaB`）。Boss 场是 **黑曜舰空**（`obsidianBoss`）。
2. `STAGE4_WARNING_AT` = **118**，`OBSIDIAN_ENTER_AT` = **123**，`STAGE4_WRECK_AT` = **96**。本轮不加这两拍，黑曜主战数字不动。
3. 起飞锁不动：灯 3 秒 + 前冲 3.2 秒，`CARRIER_PARK_Y` 608 → `CARRIER_RELEASE_Y` 224。
4. 最早刷敌 `STAGE4_FIRST_SPAWN` = **11.2**（= `CARRIER_RUSH_TIME` 3.2 + 8）。本表第一波是 **12 秒**。
5. 新种类只有两个：雷击机 `torpedo`、高射炮建筑 `aa_gun`。`wreck_float` 是道具，不是第三种敌机。
6. 三种新移动必须出现：`wake_climb`、`cross_skim`、`radar_paint`。`radar_paint` 的锁定亮灯 **≥ 0.8 秒**（常量 `RADAR_PAINT_MIN`）。
7. 本关主节奏不用 `sine` / `v_dive` / `cross`。不用 `rear_diag`、`step_slide`、`dive_once`、`strafe`、`planted`。不用 `slow_push`。不用 `bomber` 冒充舰载机。不用 `sea_gun` 冒充高射炮。
8. 不改 `hpScale`、`fireRateScale`、`bulletSpeedScale`。清波奖励和定点补给机不做。
9. 段落标签 `deck` / `fleet` / `swell` / `wreck` 不选地图。
10. 本关不出坦克、导弹车、工厂防空炮、`parked_fighter`、`strike`、`turret2`。
11. 满级飞机数以 §9 合计为准：**简单 132，中等 168，困难 200**。目标带 130 / 170 / 210，允许 ±15。2026-10-30 只削困难：八个最密波各 −1，高射炮改为 **5 / 5 / 4**。简单和中等不动。
12. 风险箱只读 §5 的 `STAGE4_RISK_*`。不读其它关的时钟。
13. 每波 `mvp: true`。
14. 漂浮物仍是八个锚点，三档相同。撞机不致死。

v2 作废的行为：

- 舰载轰炸机 `slow_push` + 向下 5 发大弹。
- 巡洋副炮双管固定向下点射。
- 正弦、V 字、斜穿作为本关主菜。

## 3. 两种新种类

### 3.1 雷击机 `torpedo`

替掉 v2 的舰载轰炸机。不是 `bomber`，不是向下 `fan5`。

| 项 | 锁定 |
|---|---|
| 体型 | `medium` / `air`。计入击落率。精灵 **48×40**，命中半径 18。不放大小型机，不套 `bomber` 的 56×48 |
| 血 / 分 | 血 `TORPEDO_HP` 56，分 `SCORE_TORPEDO` 1400。`scaleHp` 仍适用 |
| 移动 | `wake_climb`。从屏下爬到投放高度再离场。不用 `slow_push` |
| 武器 | 一次投放。先画竖的预警光柱 `TORPEDO_WARN` **1.5 秒**（不致死），再变成直线水面危险带：宽 `TORPEDO_WIDTH` 26，长 `TORPEDO_LENGTH` 460，存活 `TORPEDO_LIFE` **3.8 秒**。危险带随海面卷动。玩家圆心碰上去就死。炸弹不擦掉已经投下的轨 |
| 出场 | 甲板、舰群、残骸各一次。架数 **1 / 1 / 1**、**1 / 1 / 2**、**1 / 1 / 2**，合计 **3 / 3 / 5**。甲板那一架掉 B |

### 3.2 高射炮 `aa_gun`

替掉 v2 的巡洋副炮点射。不是 `sea_gun`，不是双管固定向下。

| 项 | 锁定 |
|---|---|
| 种类 | 建筑，`small` / `building`。不计入击落率。炸弹按小型直接毁掉屏幕内的炮 |
| 地形 | 2×2，四格都在已有的 `cruiserGunDeck` 上。不新挖炮位 |
| 血 / 分 | 独立常量 `AA_GUN_HP` **22**。不改全局 `BUILDING_HP`。分用 `SCORE_BUILDING`（500）。`scaleHp` 仍适用 |
| 开火 | 红圈标在玩家当时的位置。延迟后在圈心爆一圈破片。延迟和破片数分档，都落在 **0.6–0.9 秒** |
| 数量 | 海图仍画六座炮位。生成是 **5 / 5 / 4**：简单和中等生成 B01–B05，困难只生成 B01–B04。B05 不进困难，B06 三档都不生成。空爆仍用该档自己的延迟、破片和间隔 |

| 档 | 延迟 | 破片 | 间隔 |
|---|---|---|---|
| 简单 | 0.90 秒 | 10 | 2.20 秒 |
| 中等 | 0.75 秒 | 12 | 1.85 秒 |
| 困难 | 0.62 秒 | 16 | 1.45 秒 |

常量：`AA_BURST_DELAY`、`AA_BURST_COUNT`、`AA_FIRE_INTERVAL`、`AA_BURST_SPEED` 155、预警圈半径 `AA_MARK_RADIUS` 36。

## 4. 三种新移动

| 移动 | 行为 | 开火 |
|---|---|---|
| `wake_climb` | 出生在屏下（约 y = 672）。以 `speed` 向上爬到 `stopY`，停 `hold`，再以 `WAKE_CLIMB_EXIT_SPEED` 200 向上离开。左右有 `WAKE_CLIMB_DRIFT` 12 的小摆 | 机体中心还在底边外（y > 632）时开火钟停住。入屏之后才走表 |
| `cross_skim` | 从左或右屏外贴着一条水平线穿到另一侧。`speed` 是水平速度。不上下摆 | 人还在屏外时不开火。入屏后打短段 `splash`：向下扇，不瞄准玩家 |
| `radar_paint` | 从上方落到 `stopY`。然后亮锁定 **`paint` 秒**。亮的时候瞄准跟着玩家，结束那一帧把轴冻住，再沿冻结轴齐射。然后向上离开 | `paint` 结束前开火钟停住。齐射用 `aim: 'barrel'` 的扇，不继续追玩家 |

`splash` 是 `FIRE_PRESETS` 的一行：向下扇 5 发，张角 64°，小弹，速度 175。波次可以用 `spread` 把张角改宽。它不是 `aimed1`。
