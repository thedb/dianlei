「载入示例」打开仓库自带的 8×8 样例（透明角、黑边、青底、白心），用来练手，不是游戏正式资产。

宽高和取样决定每个格子取参考图的哪一块。同一张图、同一组参数，导出的格子永远一样。

装配预览

路径 B。这里只画当前阶段的整架。点画布上的零件可以选中，选中的描金边。画布整体放大只为了看得清，不写进文件。

「载入装配示例」打开 sample.entity.json：一块机身加一对翼，阶段是 folded（收起）、half（一边张开）、open（两边张开）。用来冒烟，不是现役黑曜。

「网格文件」读取一份已经导出的 *.grid.json（一张调色板像素图，像一张精灵锁定稿），把它加进零件列表。

「装配文件」读取一份 *.entity.json：多张网格，加上各阶段的位置、轴心、角度、整数缩放、水平翻转、层和可选受击框。选中后整份换上，用来核对导出再载入。

「受击框」用青色描在零件上。现役战斗仍用圆，这里只预览。

「阶段」是同一架机体的一个姿势。示例里 folded 是收起，half 是一边张开，open 是两边张开。切换时右边画布上的翼会动，左边的零件预览不动。

「导出 .entity.json」下载装配文件。这是过门的锁定稿。现役 Boss 还没有改去读它。

零件按层从后往前排。点列表或点画布上的零件，金边标出当前件。

「缩放」是整数。1 是一格一像素，2 是每个格子变成 2×2，绕轴心放大，写进装配文件。旋转之后边可能盖住半个屏幕像素，仍用最近邻，不模糊。

「上移」盖住后面的零件，「下移」被别的零件盖住。点过之后图层会重排成 0、1、2…

尚未装配。在左边做好零件后点「移入装配」，或点「载入装配示例」。

使用说明

屏幕分成左右两块。左边「零件预览」只画一张网格。右边「装配预览」只画当前阶段的整架。两块画布不会互相替换。

参考 PNG 只是原料。游戏以后只认导出的 JSON，不要按着预览再仿画一张。现役机体和 Boss（Eagle、黑曜等）还没有改去读这些文件。

路径 A · 左边一张零件 → 网格文件

  1. 点「载入示例」，或自己选一张 PNG。左边出现这张零件。
  2. 点「导出 .grid.json」得到网格文件：宽、高和每个格子的颜色编号。
  3. 零件满意后点「移入装配」，它会出现在右边的零件列表里。

「载入示例」是仓库自带的 8×8 样例，用来练手，不是游戏正式资产。

怎么验证：载入示例后，状态行应写「与 fixtures/sample.grid.json 一致」。右边的装配画布保持原样。

路径 B · 右边多张网格 → 装配文件

  1. 点「载入装配示例」，或把左边的零件「移入装配」。
  2. 点右边画布上的零件，或点列表。选中的描金边。
  3. 改角度、缩放（整数倍）、上移或下移图层。位移、轴心、水平翻转、受击框也在这一栏。
  4. 阶段选 folded、half、open，看翼动。左边的零件预览不动。
  5. 点「导出 .entity.json」。再用「装配文件」把刚导出的文件载入，阶段和零件还在。

装配文件是多张网格，加上每个阶段的位置、轴心、角度、整数缩放、水平翻转、层，以及可选的受击框。网格可以内联在同一份文件里。

「载入装配示例」是机身加一对翼的三个阶段，用来冒烟，不是现役黑曜。

「网格文件」读一份已经导出的 *.grid.json，加进零件列表。
