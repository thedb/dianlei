电雷像素化

本地工具。路径 A 把一张参考图收成网格文件；路径 B 把多张网格拼成机体。游戏以后只认导出的 JSON，不认参考图。

路径 A · 一张零件

把参考 PNG 收成一张调色板像素图，导出网格文件 *.grid.json。这是精灵锁定稿，不是再仿画一张。

「载入示例」打开仓库自带的 8×8 样例（透明角、黑边、青底、白心），用来练手，不是游戏正式资产。PNG 一栏是你自己的参考图，只作输入。

宽高和取样决定每个格子取参考图的哪一块。同一张图、同一组参数，导出的格子永远一样。

「导出 .grid.json」下载网格文件：宽、高，和每个格子的颜色编号。这是过门的锁定稿。游戏日后只 import 这份字节，不要按预览另仿画。

先点「载入示例」，或选一张 PNG。右边是这张零件。

路径 B · 装配

把多张网格拼成机体或 Boss 的几个姿势，导出装配文件 *.entity.json。一个阶段就是一个姿势。

「载入装配示例」打开 sample.entity.json：一块机身加一对翼，阶段是 folded（收起）、half（一边张开）、open（两边张开）。用来冒烟装配，不是现役黑曜。

「当前网格加入」把路径 A 正在编辑的那张网格，加进下面的零件列表。要先载入示例或自己的 PNG，这里才有东西可加。

「网格文件」读取一份已经导出的 *.grid.json（一张调色板像素图，像一张精灵锁定稿），把它加进零件列表。

「装配文件」读取一份 *.entity.json：多张网格，加上各阶段的位置、轴心、角度、水平翻转、层和可选受击框。网格可以内联在同一份文件里。选中后整份换上，用来核对导出再载入。

「装配预览」勾上后，右边画当前阶段的整架。取消后只画路径 A 的那一张网格。两种都可以对照。

「受击框」在零件像素上描出可受击的矩形。现役战斗仍用圆，这里只预览，还没接到游戏里。

「阶段」是同一架机体的一个姿势。示例里 folded 是收起，half 是一边张开，open 是两边张开。切换时右边的翼会动。

「导出 .entity.json」下载装配文件。这是过门的锁定稿。游戏日后只 import 这份字节，不要另仿画。现役 Boss 还没有改去读它。

零件按层从后往前排。点一个零件，再改位置、轴心、角度（这里是度，文件里是弧度）、水平翻转和层。

尚未装配。点「载入装配示例」，或把当前这张网格加进来。

右边是预览。不勾装配预览时是一张零件；勾上后是当前阶段的整架。底色和贴图规则与游戏相同。

使用说明

这个页面只在你自己的电脑上跑，不上传。参考 PNG 只是原料。游戏以后只认你导出的 JSON，不要按着预览再仿画一张。

现役机体和 Boss（Eagle、黑曜等）还没有改去读这些文件。现在导出是为了锁定同一份字节，并在这里核对预览。

路径 A · 一张零件 → 网格文件

你要做的：把一张参考图收成调色板像素。

  1. 点「载入示例」，或自己选一张 PNG。
  2. 看右边画布。它用的是游戏同一套贴图。
  3. 点「导出 .grid.json」。

你会得到网格文件 *.grid.json：一张精灵锁定稿，里面是宽、高，和每个格子的颜色编号。

「载入示例」打开的是仓库自带的 8×8 样例，用来练手，不是游戏正式资产。

怎么验证：载入示例后，状态行应写「与 fixtures/sample.grid.json 一致」。画布就是这张样例。导出的文件可以再用「网格文件」载入，零件会进装配列表。

路径 B · 多张网格 → 装配文件

你要做的：把几张网格摆成一个姿势，再做几个阶段（收起、半开、展开）。

  1. 点「载入装配示例」。
  2. 阶段选 folded、half、open，看翼的角度变。
  3. 勾上或取消「装配预览」：勾上画整架，取消只画路径 A 的那一张。
  4. 点「导出 .entity.json」。再用「装配文件」把刚导出的文件载入，阶段和零件还在。

你会得到装配文件 *.entity.json：多张网格，加上每个阶段的位置、轴心、角度、水平翻转、层，以及可选的受击框。网格可以内联在同一份文件里。

「载入装配示例」打开机身加一对翼的三个阶段，用来冒烟，不是现役黑曜。

「当前网格加入」把路径 A 正在看的那张网格，加进零件列表。

「网格文件」读一份已经导出的 *.grid.json，加进零件列表。

「装配文件」读一份 *.entity.json，整份换上。
