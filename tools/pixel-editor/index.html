电雷像素编辑器

装配工作台

按钮说明

白框是当前这套装配的编辑边界，中心在原点。拉伸、斜切、旋转、移动零件都不会改它的大小和位置，视图也不跟着零件缩放；只有「边界宽」「边界高」「框住零件」会改。局内逻辑画面是 360×640，那是游戏屏幕，不是这个框的默认大小。载入装配、载入示例或移入零件后，按零件包围盒外加 8 像素重算。手改宽高，或点「框住零件」，才写入 previewFrame；没改过不写。文件里若已有这个字段，载入时用文件里的数。战斗不读。

「对照尺寸」叠一个粉色虚线框，中心在原点：玩家机约 26×30（Jason）到 48×32（Mandy），Eagle 28×32；Boss 两百像素上下。只作对照，不裁切，也不写进文件。

「载入装配示例」打开 sample.entity.json：一块机身加一对翼，阶段是 folded（收起）、half（一边张开）、open（两边张开）。用来冒烟，不是现役黑曜。装配里一旦有零件，这个按钮和零件弹窗里的「载入示例」都不可点。点「清空装配」后恢复。点零件后，调参栏从画布右侧滑入，画布大小不变。

「网格文件」读取一份已经导出的 *.grid.json（一张调色板像素图，像一张精灵锁定稿），把它加进零件列表。

「装配文件」读取一份 *.entity.json：多张网格，加上各阶段的位置、轴心、角度、缩放、水平翻转、层和可选受击框。选中后整份换上，用来核对导出再载入。

阶段说明

「阶段」是同一架机体的一个姿势。示例里 folded 是收起，half 是一边张开，open 是两边张开。切换时装配画布上的翼会动，零件预览弹窗不动。

「导出 .entity.json」下载装配文件。这是过门的锁定稿。现役 Boss 还没有改去读它。previewFrame 只是预览边界，战斗不读。

一个姿态一个阶段。Boss 用 folded / half / open 这类阶段。玩家机点「侧倾 t0–t5」：t0 平飞是原稿，t1–t5 由 t0 加每帧参数（角度、横向拉伸、纵向拉伸、透视）算出，在装配下方的「侧倾对比」里调。左倾和局内一样由代码把右倾水平镜像，不进文件。改 t0，t1–t5 跟着重算；直接改某一帧的零件，那一帧变成手调，不再跟 t0。零件 id 在各阶段相同，「复制到阶段」按 id 对上。

「播放预览」在装配画布上连续播放，不改文件。可以选「阶段 A → B」「全部阶段依次」或「侧倾循环」。阶段之间按零件 id 对上，插值位置、角度（走近的那边）、缩放、拉伸和斜切；翻转、换网格、层和只在一边出现的零件在过渡一半时切换。侧倾循环是 t0 → 右倾 t1–t5 → t0 → 左倾（右倾镜像）→ t0。

选中零件

只调整当前零件。按 Esc、关闭，或点画布空白处退出选择。

「缩放」大于 0、不超过 16，可以填 0.5。绕轴心缩放，写进装配文件。1 仍是一格一像素，走整像素贴图。小于 1 时按最近邻缩小，不取平均。不是整数、或者转了角度时，边可以盖住半个屏幕像素，不吸附、不模糊。

斜切绕轴心，按 Fabric.js 的顺序：先缩放，再斜切，再旋转。「边点拖动」选「斜切」后，四个边点变成菱形：拖上下边点左右斜（斜切 X），拖左右边点上下斜（斜切 Y），1° 一档，Shift 15°。斜切写进装配文件的 skewX / skewY（弧度）；编辑器预览画出来，游戏里的贴图暂时还不读。

「上移」盖住后面的零件，「下移」被别的零件盖住。点过之后图层会重排成 0、1、2…

方形的 x、y 是左上角，宽高各自可调，所以可以不是正方。圆形是圆心加半径。两者都按精灵像素，可以比零件大，也可以偏到外面。可打画青色实线，仅阻挡画灰色虚线。选中的零件始终画粗线；勾上工具栏「受击框」则其余零件也画细线。战斗还不读。

锚点

相对轴心的点，按未翻转的精灵像素。尾焰喷口画黄橙闪烁方块，枪口画白色十字。随翻转、缩放和角度一起动。战斗还不读。

侧倾对比

和局内一样：只编右倾。t0 平飞，t1–t5 逐级向右倾。左边五格是代码把 t1–t5 水平镜像出来的，文件里没有左倾阶段，也不用画。点右边任一格（或它的镜像）调这一帧；点过之后 ← → 在格子之间切换。

按钮说明

「载入示例」打开仓库自带的 8×8 样例（透明角、黑边、青底、白心），用来练手，不是游戏正式资产。它只换弹窗里的这张零件，不改装配。只在弹窗里没有素材时可点：载入了 PNG 或示例之后它变灰，点「清空当前素材」后恢复。装配里一旦有零件，它和「载入装配示例」也一起不可点，点「清空装配」后恢复。自己的 PNG 随时可以换。

「清空当前素材」清掉弹窗里的参考图和网格，不动装配。

目标宽高是这件零件在机体里占的像素。局内玩家机整架约 26×30（Jason）到 48×32（Mandy），Eagle 28×32；小敌机 24×24；Boss 两百像素上下。只作提示，不强制裁切。宽高和取样决定每个格子取参考图的哪一块。同一张图、同一组参数，导出的格子永远一样。

「导出 .grid.json」下载网格文件：宽、高，和每个格子的颜色编号。这是过门的锁定稿。游戏日后只 import 这份字节，不要按预览另仿画。没有素材时不可点。

「移入装配」在这张零件预览好之后，把它加进装配零件列表，并关掉弹窗。没有素材时不可点，要先载入示例或自己的 PNG。

「参数预设」一次写好目标宽高、取样、量化、透明阈值、抖动和锁定源比例。取样 nearest 按格子中心对齐，box 按覆盖面积平均。调色板固定为游戏的 52 色，预设不能换。内置有 Eagle 28×32、Mandy 48×32、Jason 26×30、小零件 24×24、界面图标 16×16、地砖 16×16、Boss 零件（宽 64，锁比例）。「保存」只存在这台浏览器。「对照并排」左边是参考图，右边是当前网格，画法和单张预览一样；可以再对照另一套预设或另一份网格，勾「只标不同」标出格子不一样的地方。

批量量化

多张 PNG 用同一套参数收成网格。每张一个 *.grid.json，成功的打进一个 zip。字节和零件预览里导出的一样。勾着锁定源比例时，每张按自己的比例算高。调色板固定为游戏的 52 色。

先选文件，再点「开始」。

    使用说明

    主界面是装配预览，画布是 #asm-view。零件预览是弹窗，点页头「零件预览」打开，画布是 #view。两块画布不会互相替换。关掉弹窗后，屏幕上只留装配。局内逻辑画面是 360×640，那只是游戏屏幕。白框按载入的零件包围盒来，手改宽高才写入 previewFrame。受击框可以是方形或圆形，尺寸可以大于零件。

    参考 PNG 只是原料。游戏以后只认导出的 JSON，不要按着预览再仿画一张。现役机体和 Boss（Eagle、黑曜等）还没有改去读这些文件。

    路径 A · 弹窗里一张零件 → 网格文件

    1. 点「零件预览」，再点「载入示例」，或自己选一张 PNG。弹窗里出现这张零件。没有素材时「导出 .grid.json」「移入装配」是灰的；有了素材「载入示例」变灰，点「清空当前素材」可以重来。
    2. 点「导出 .grid.json」得到网格文件：宽、高和每个格子的颜色编号。
    3. 零件满意后点「移入装配」。弹窗关掉，它出现在装配的零件列表里。

    「载入示例」是仓库自带的 8×8 样例，用来练手，不是游戏正式资产。

    怎么验证：载入示例后，弹窗里的状态行应写「与 fixtures/sample.grid.json 一致」。装配画布保持原样。

    批量（P2）

    1. 零件预览里选「参数预设」再点「套用」。内置有 Eagle 28×32、Mandy 48×32、Jason 26×30、小零件 24×24、界面图标 16×16、地砖 16×16、Boss 零件（宽 64，锁定源比例）。取样 nearest 是格子中心对齐，box 是区域平均。调色板固定为游戏的 52 色。「保存」把当前参数存成自己的预设，只存在这台浏览器；内置的不能删。
    2. 页头「批量量化」：选一套预设，或「零件预览里的当前参数」。多选 PNG，或选一个文件夹。每张用同一套参数像素化，下面一行一个结果。成功的打进一个 zip，每张一个 *.grid.json，字节和单张导出一样。锁定源比例时，每张按自己的比例算高。
    3. 勾「对照并排」：左边参考图（最近邻放大到和网格一样大），右边当前网格（游戏同一条贴图）。「叠加」把网格半透明盖在参考图上。第二份可以是另一套预设，或另一份网格；「只标不同」标出格子不一样的地方，尺寸不同会写明。

    路径 B · 主界面装配 → 装配文件

    1. 点「载入装配示例」，或在零件弹窗里「移入装配」。
    2. 点装配画布上的零件，或点下方列表。选中的描金边，「选中零件」从画布右侧滑入，画布大小不变。再点空白处，这一栏滑出。
    3. 在这一栏改角度、缩放（大于 0，可以是 0.5）、上移或下移图层。位移、轴心、水平翻转也在这一栏。受击框选方形或圆形，尺寸可以大于零件。不用翻整页。
    4. 按 Esc、点「关闭」，或点画布空白处，退出调参。阶段选 folded、half、open，看翼动。零件弹窗不动。
    5. 点「导出 .entity.json」。再用「装配文件」把刚导出的文件载入，阶段和零件还在。

    装配文件是多张网格，加上每个阶段的位置、轴心、角度、缩放（大于 0，可以是 0.5）、水平翻转、层，以及可选的受击框。网格可以内联在同一份文件里。

    「载入装配示例」是机身加一对翼的三个阶段，用来冒烟，不是现役黑曜。装配里已有零件时，它和「载入示例」都不可点。点「清空装配」清掉零件后再启用。

    Boss（黑曜这类）

    1. 一个姿态一个阶段：先摆好 folded，点「复制阶段」得到下一个姿态，零件 id 不变，再改角度和位移。
    2. 只想改一件时，选中它，用「复制到阶段」按 id 送到别的阶段（同 id 替换，没有就新增）。多片刃用「复制一份」。
    3. 每件选「受击用途」：可打（青色实线）、仅阻挡（灰色虚线，挡子弹不掉血）、无。形状选方形或圆形，可以比零件大。
    4. 图层列表从左到右是从后往前画，按钮上写着 L 编号。「上移」「下移」调前后。
    5. 「播放预览」（P3）在装配画布上连续播放：「阶段 A → B」或「全部阶段依次」平滑过渡（位置、角度、缩放、拉伸、斜切插值，翻转和层在一半时切换），「侧倾循环」播 t0 → 右倾 → t0 → 左倾镜像 → t0。可调过渡、停留、缓动、倍速、循环、整像素，「播放 / 暂停」「停止」和进度条拖动定位，下方写当前是哪两个姿态、百分比和秒数。点画布或「停止」回到编辑。

    玩家机

    1. 做零件时看弹窗里的比例行：宽高比和参考图差太多会标黄。默认勾着「锁定源比例」。
    2. 看颜色统计：暗色占九成以上、或一种颜色占九成以上，会标黄提示，移入装配时状态行也会写出来。
    3. 工具栏「对照尺寸」选 Jason 26×30、Eagle 28×32 或 Mandy 48×32，画布上出现粉色虚线框，状态行写当前阶段大小和倍数。只对照，不裁切。
    4. 摆好平飞后点「侧倾 t0–t5」。和局内一样只编右倾：t0 平飞是原稿，t1–t5 逐级向右倾；左倾由代码把 t1–t5 水平镜像，文件里没有左倾阶段，也不用画。「清除侧倾」经确认后删除 t1–t5 和已有 bank 参数，但保留 t0、其他阶段、网格和装配零件；修改 t0 后再点「侧倾 t0–t5」，仍用同一套流程重新生成全部侧倾帧。
    5. 生成后装配下方出现「侧倾对比」：左五格是镜像，中间 t0，右五格是 t1–t5，和局内 11 帧一样排。点一格，装配画布也切到那一帧。
    6. 在对比里拖「角度」「横向拉伸」「纵向拉伸」「透视」，结果写回那一帧的零件。透视为正时，右侧（下沉的那边）更窄。改 t0，跟参数走的帧会一起重算。
    7. 想一件件细调某一帧，点「改成手调」，或直接在装配里改那一帧的零件（会自动变成手调）。「按参数重算」再回到跟 t0 走。单个零件也有「横向拉伸」「纵向拉伸」。
    8. 选中机身，加「尾焰喷口」和「枪口」锚点。坐标相对轴心，画布上闪烁。
    9. 选中零件后画布上有选框：拖白色角点拉宽高，拖边点拉一边，Shift 保持比例；拖顶上圆点旋转；拖内部移动。要斜切，在检查栏把「边点拖动」换成「斜切」，再拖菱形边点，或直接填「斜切 X」「斜切 Y」。白框不会跟着零件变。检查栏的数字跟着变。点一下装配画布再按方向键挪零件；焦点在「侧倾对比」上时，← → 切换格子，不挪零件。

    「网格文件」读一份已经导出的 *.grid.json，加进零件列表。
