# 电雷 (Dianlei)

《电雷》是一款致敬经典街机风格的竖屏像素飞行射击游戏。

## 项目架构

- **纯 TypeScript 游戏核心** - 无游戏引擎依赖，手写 Canvas 2D 渲染器
- **平台适配层** - 游戏核心不直接依赖 DOM 或微信 API，通过适配器接口访问平台功能
- **双平台外壳**：
  - **H5** - 基于 Vite 构建，用于浏览器和移动端 Web 测试
  - **微信小游戏** - game.js 入口，适用于微信开发者工具

### 核心特性

- 固定逻辑分辨率 360×640，竖屏
- 整数倍或最近邻缩放，保持像素清晰，按需加黑边
- 固定时间步长游戏循环（60Hz 更新），配合 rAF 渲染
- 锁定的 48 色调色板
- 多点触控支持（虚拟摇杆 + A/B 按钮）

## 本地开发

### 环境要求

- Node.js >= 18.0.0
- npm

### 安装与运行

```bash
# 安装依赖
npm install

# 启动开发服务器（H5）
npm run dev

# 打开浏览器访问 http://localhost:3000
```

### 可用脚本

| 命令 | 说明 |
|------|------|
| `npm run dev` | 启动 Vite 开发服务器 |
| `npm run build:h5` | 构建 H5 版本 |
| `npm run build:wx` | 类型检查微信版本 |
| `npm run lint` | ESLint 检查 |
| `npm run lint:fix` | ESLint 自动修复 |
| `npm run typecheck` | TypeScript 类型检查 |
| `npm run test` | 运行 Vitest 测试 |
| `npm run test:watch` | 测试监视模式 |

### 操作方式

**键盘（H5 测试用）**：
- 方向键 / WASD - 移动
- Z / 空格 - 射击（A 键）
- X - 炸弹（B 键）
- ESC - 暂停

首页菜单只有「开始游戏」和「设置」。没有 F1 / F2 / F3。调试不在设置页里：首页右上角 48×48 的区域在 2 秒内点 6 下，会打开调试面板（挑战 Boss、调试模式、武器测试、地图预览）。挑战 Boss 先选关卡（目前只有「1」），再选普通或困难，然后才进 Boss 战。调试模式只显示左下角叠层。武器测试是一块不卷轴的打靶场，P / T / M / B 改的是正式装填。M 是僚机 0 / 1 / 2：1 为左侧一架，2 为左右各一架，跟主炮一起打直射弹，伤害固定为基础主炮。P速 / P伤 / T速 / T伤 只在这一局里改主炮和 T 的射速、伤害，不改变僚机伤害。按住射击会打出主炮、僚机弹和 T 追踪导弹。死亡或暂停里的「返回标题」回到首页。

启动页是黑底，只显示「电雷」和加载条，没有开始按钮，点按也不会进游戏，1.5 秒后才到首页。启动页不画关卡。进入首页之后，背后才是静音的第一关演示（正式战斗场景，不是单独画的背景）。演示自机从 6 条路线里随机抽一条来飞，会按正式规则被击中并爆炸，爆炸后画面淡出到黑再从头循环，并换一条路线。标题按钮在淡出时仍可点。演示不写最高分，也不改设置。从战斗回到首页时，演示也是等标题场景进入后再开始。

**触摸**：
- 左半屏拖动 - 虚拟摇杆
- 右下区域 - A/B 按钮

## 微信小游戏开发

### 在微信开发者工具中打开

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开开发者工具，选择"导入项目"
3. 选择项目中的 `wx-shell/` 目录
4. 在 `wx-shell/project.config.json` 中填入你的小游戏 AppID
5. 点击"编译"运行

**注意**：P0 阶段的微信外壳是一个简化版本，仅用于验证基础功能。完整的游戏逻辑会在后续里程碑中集成。

## 技术说明

### 为什么不用游戏引擎？

- 保持包体小巧，适合微信小游戏 4MB 主包限制
- 完全控制渲染和更新循环
- 像素游戏不需要复杂的物理或场景图
- 便于在微信和 H5 之间共享代码

### 调色板设计

48 色调色板基于设计文档 §3.4 的色组分配，针对街机风格优化：

- 中性色（8 色）：描边、高光、烟尘
- 玩家色（6 色）：青白主色调
- 敌方空军（6 色）：暗红系
- 地面单位（5 色）：橄榄色系
- 地形（10 色）：草地、公路、混凝土等
- 水域（5 色）：海洋、河流
- 爆炸（4 色）：黄橙红
- 敌弹（4 色）：粉紫品红，高对比度

发光和粒子效果由代码生成，可使用半透明色，不受调色板限制。
